# 3D 探索素材来源

以下贴图使用 Poly Haven 的 CC0 素材。仓库内文件已针对 Godot 转码，模型、植被分布和山门结构由客户端生成。 [Poly Haven 许可](https://polyhaven.com/license)

| 本地贴图 | 使用方式 | 原始素材 |
| --- | --- | --- |
| `rock_color.webp`、`rock_normal.webp`、`rock_surface.webp` | 2K 岩石色彩与法线。色彩去饱和，1K 粗糙度和遮蔽从岩石原图亮度估算 | [Rock Face](https://polyhaven.com/a/rock_face) |
| `grass_color.webp`、`grass_normal.webp` | 2K 草地颜色和法线，沿世界坐标铺设 | [Leafy Grass](https://polyhaven.com/a/leafy_grass) |
| `litter_color.webp` | 1K 落叶与土壤，混入路径和湿岸 | [Forest Ground 03](https://polyhaven.com/a/forrest_ground_03) |
| `fir_bough.webp` | 768 像素针叶分枝，合并裁剪后的颜色与透明度 | [Fir Tree 01](https://polyhaven.com/a/fir_tree_01) |
| `forest_leaf.webp` | 单片阔叶，合并裁剪后的颜色与透明度 | [Island Tree 02](https://polyhaven.com/a/island_tree_02) |
| `wood_color.webp`、`wood_normal.webp` | 1K 木纹。颜色明度基底用于柱梁的红漆着色 | [Fine Grained Wood](https://polyhaven.com/a/fine_grained_wood) |
| `roof_color.webp`、`roof_normal.webp` | 1K 屋面明暗和细部法线，用在瓦坡和瓦脊网格上 | [Grey Roof 01](https://polyhaven.com/a/grey_roof_01) |
