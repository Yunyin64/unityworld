# 效果强度公式（Effect Score Formula）

## 核心公式

```
效果总分 = (Action.Score + Condition.Score + Trigger.Score) × Condition.Multiplier × Trigger.Multiplier
```

拆解：

```
         ┌─────────────── 加法池（基础价值） ───────────────┐
         │                                                  │
         │  Action.Score + Condition.Score + Trigger.Score  │
         │                                                  │
         └──────────────────────────────────────────────────┘
                                  ×
         ┌─────────────── 乘法链（放大系数） ───────────────┐
         │                                                  │
         │       Condition.Multiplier × Trigger.Multiplier  │
         │                                                  │
         └──────────────────────────────────────────────────┘
```

## 约束

- **一个效果 = 1 Trigger + 1 Condition + 1 Action**
- 不允许多 Condition 叠加，避免组合爆炸
- 一张卡可以有多个效果，卡牌总预算 = 所有效果总分之和

## 三大组件

### Action（做什么）

- Score 为正数，代表效果的基础强度
- 由 ParamDefs 中的参数选择决定具体分值
- 例：攻击+1 = 1分，攻击+3 = 3分，治疗+2 = 2分

### Condition（打谁 / 能不能触发 / 倍率）

Condition 是统一容器，包含三种子类型：

| 子类型 | 作用 | Score | Multiplier |
|--------|------|-------|------------|
| Filter | 限制触发（不满足就不执行） | 负数（补贴） | 1.0 |
| Selector | 选目标范围（打几个） | 0 或微正 | > 1.0（放大） |
| Scaler | 动态倍率（每有一张X） | 0 或微负 | > 1.0（放大） |

示例：

| Condition | Score | Multiplier | 含义 |
|-----------|-------|------------|------|
| 无条件 | 0 | 1.0 | 基准 |
| 目标低血时 | -2 | 1.0 | 限制触发，补贴2分 |
| 目标有Burn时 | -1.5 | 1.0 | 限制触发 |
| 所有武器卡 | 0 | 1.8 | 全体放大 |
| 所有伤势卡 | 0 | 1.3 | 放大（伤势卡少） |
| 每有一张武器卡 | 0 | 2.0 | 期望乘数 |
| 每有一张伤势卡 | 0 | 1.5 | 期望乘数（少） |

不同 Tag 的 Score/Multiplier 不同，反映"该类卡在场上的稀有程度"。

### Trigger（什么时候触发）

| Trigger | Score | Multiplier | 含义 |
|---------|-------|------------|------|
| 出手时 | 0 | 1.0 | 基准（主动打出） |
| 每tick | 0 | 3.0 | 持续触发，效果翻倍 |
| 受伤时 | -1 | 1.0 | 被动，不确定性 |
| 击杀时 | -3 | 1.0 | 很难触发，大补贴 |
| 战斗开始时 | 0 | 0.5 | 一次性，打折 |

## 计算示例

### 示例1："每次出手时，攻击+2"

```
Action.Score = 2, Condition = 无(0, ×1.0), Trigger = 出手时(0, ×1.0)
总分 = (2 + 0 + 0) × 1.0 × 1.0 = 2.0
```

### 示例2："每tick，对所有武器卡+1攻击"

```
Action.Score = 1, Condition = 所有武器卡(0, ×1.8), Trigger = 每tick(0, ×3.0)
总分 = (1 + 0 + 0) × 1.8 × 3.0 = 5.4
```

### 示例3："受伤时，每有一张伤势卡+2攻击"

```
Action.Score = 2, Condition = 每有伤势卡(0, ×1.5), Trigger = 受伤时(-1, ×1.0)
总分 = (2 + 0 + (-1)) × 1.5 × 1.0 = 1.5
```

### 示例4："目标低血时，攻击+4"

```
Action.Score = 4, Condition = 目标低血(-2, ×1.0), Trigger = 出手时(0, ×1.0)
总分 = (4 + (-2) + 0) × 1.0 × 1.0 = 2.0
```

### 示例5："击杀时，治疗+5"

```
Action.Score = 5, Condition = 无(0, ×1.0), Trigger = 击杀时(-3, ×1.0)
总分 = (5 + 0 + (-3)) × 1.0 × 1.0 = 2.0
```

## 设计原则

1. **Score 负数 = 补贴**：条件越苛刻/触发越难，负分越大，允许搭配更强 Action
2. **Multiplier > 1 = 放大**：群体/持续/倍率效果消耗更多预算
3. **Multiplier < 1 = 打折**：一次性/低概率效果预算便宜
4. **先加后乘**：Bonus 补贴会被 Multiplier 放大，弱效果+高放大组合天然被惩罚
5. **单 Condition 约束**：每个效果只配一个 Condition，避免乘法链组合爆炸
6. **ParamDefs 编码稀有度**：同一个 Condition 模板，不同参数值给不同分/乘数
