## 关键词与正式配卡

### Main Keyword

每张卡必须有且只有一种 Main。卡表和存档沿用 `Keywords`，`CardBaseData.MainKeyword` 按名称从中计算，顺序任意。模板预检和卡牌实例化共用 `CardKeywordRoles` 判定。`[Passive, GongFa]` 合法，`[GongFa]` 缺少 Main，`[FaShu, FaBao]` 的两个 Main 冲突。战斗 Lua 可以补普通词，初始化时会校验 Main 仍与装配时一致。 [主词判定](../../../../Scripts/Game/Domain/Object/Card/Data/CardKeywordRoles.cs#L20) · [卡牌数据](../../../../Scripts/Game/Domain/Object/Card/Data/CardBaseData.cs#L25) · [战斗初始化](../../../../Scripts/Game/Domain/Combat/CombatCard/CombatCardLuaFunc.cs#L19)

背包扫描负责末格、灵元、冻结和行发动额度。四种 Main 的 Lua `Lifecycle` 接收入场、阶段切换和末格结果，决定卡怎样发动、结算和响应事件。C# 固定四个主词名，Lua 定义每个主词的行为。普通 Mod 词可以在 Lua 注册，新增第五种 Main 还需要扩展 C# 的角色定义。 [扫描入口](../../../../Scripts/Game/Domain/Combat/CombatCard/CombatCardScan.cs#L10) · [生命周期派发](../../../../Scripts/Game/Domain/Combat/CombatCard/CombatCardLuaFunc.cs#L134) · [注册校验](../../../../Scripts/Game/Domain/!Global/Lua/LuaMgr.cs#L262)

### 指定格换位

`FindPlacement(card, replaceMana)` 找自动摆放位置，`Insert(card, replaceMana)` 按该结果插入新卡并更新布局和卡数据，伤口路径可替代灵元。`DealFieldChange` 执行入场和移除队列，会动卡的蓄灵及生命周期。战前 `PlaceBackpackCard(cardId, x, y)` 用 1 起始坐标，复制验证后提交战前布局，在战斗快照中不走这个编辑入口。 [CombatBackpack.FindPlacement、Insert、RemoveCard](../../../../Scripts/Game/Domain/Combat/CombatBackpack/CombatBackpackFunc.cs) · [CombatNpc.DealFieldChange](../../../../Scripts/Game/Domain/Combat/CombatNpc/CombatNpcCardFunc.cs) · [NpcSystemBackpack.PlaceCard](../../../../Scripts/Game/Domain/Object/Npc/Systems/NpcSystemBackpack.cs)

**指定格换位缺少战斗布局的原子操作。** C 需要核对两张卡以目标格为锚点时的完整形状、有效格、交叠/占用，以及固定主功法、待发卡、保留蓄灵和扫描边界的规则。比如 2 格横卡移去 1 格卡的右边界锚点会出界，整次交换应由新规则决定并保证失败不留下半套布局。旧 `Displace/Deploy/Recall` 立即拒绝。纳音设计提出了禁动固定和待发卡、禁止覆盖灵元、已过格不补扫，供 C 评审时追溯。 [纳音设计共用规则](../../../../Data/Card/NayinDesign.md) · [待迁移动作](现有TCA.md#保留的待接入动作)

四向滑移使用 `SlideCard(ctx,"Self","Right")`。方向传入 `"Random"` 时，从目标卡能滑动的方向中等概率选一个，事件返回实际方向。整张卡滑到边缘、无效格或其他卡之前。经过的灵元保留，终点覆盖的灵元让位。固定主功法、已定身卡和待发来源卡原地不动。滑到已扫过的区域时，本轮不能再次通过扫描获得发动机会。`TargetRandom` 在能实际移动的牌中抽。Lua 包装无返回值，`ctx` 的 `MovedCount` 是实际成功数量。任意成功滑移都发 `OnCardDisplaced`。移动异方卡时另发 `OnDisplaceOtherCard`，监听方用 `ctx:GetObject("MovedCard")` 取被推卡。两者的 Caster、SourceCard 含义见[触发目录](现有TCA.md#t--触发与生命周期)。 [滑移实现](../../../../Scripts/Game/Domain/Combat/CombatBackpack/CombatBackpackFunc.cs)
