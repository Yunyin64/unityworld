# 正式版入选十张

从 61 轮的 610 张候选里，我选这十张进入正式版首批卡池。经典程度看玩家能否一眼理解效果的用途，设定趣味看名字和画面能否解释触发，合理性看触发是否好判断、收益有没有相应的代价。表里的 X 留给数值实测，各处独立调整。 [卡牌设计原稿](卡牌设计.md)

| 卡牌 | 原案效果 | 经典程度 | 设定趣味 | 合理性 |
| --- | --- | --- | --- | --- |
| **[伏地诀](卡牌设计.md#伏地诀)** · 土系法术 | 此卡结算时，获得 X 点**坚甲**。 | 本轮每次受伤都减免固定值，是易懂的防连击手段。 | 修士扎稳脚跟，把一道道来劲引入地下。 | 越早结算，越可能覆盖多次受伤。效果随本方轮结束，摆在哪一行有实际差别。 |
| **[寒砚](卡牌设计.md#寒砚)** · 水系法术 | 此卡结算时，若右侧有共边功法，随机**冻结**一张未冻结且未耗尽的敌方主动卡。 | 冻住一张牌，下次扫完它时跳过主动发动。 | 功法像一封帖，借砚里的寒墨把术送出去。 | 功法左侧的共边格要留给寒砚。单张随机冻结能打乱节奏，命中对方核心牌仍靠随机。 |
| **[左架焰槌](卡牌设计.md#左架焰槌)** · 火系招式 | 此卡发动时，若左侧有共边友方卡，生成 X 点火系**打击**拼点。 | 借力重击，条件和回报各一句就能讲完。 | 左侧有东西抵住身形，右手的火槌才抡得开。 | 左邻既是支点，也可能先用掉同行的主动发动机会。玩家有理由拿被动卡当支点。 |
| **[立挡还针](卡牌设计.md#立挡还针)** · 金系法宝 | 己方作为防御侧结算后，对敌方造成 X 点伤害。 | 防守反击，给偏防御的阵容一个主动施压的理由。 | 护腕接住冲击，从侧缝弹针还手。 | 认实际分出胜负的防御侧结算，赢和输都能还针。阵容要持续打出防御拼点，才能反复兑现。 |
| **[穿隙楔](卡牌设计.md#穿隙楔)** · 金系被动 | 友方卡**直击**时，在其伤害结算前消除敌方至多 X 点**灵盾**。 | 先破盾，再让这一击吃到收益。 | 乌金楔先撑裂盾面，后面的攻击沿裂缝穿进去。 | 给玩家一个错开对拼、争取直击的理由。适合对付经常叠灵盾的敌人。 |
| **[续痕贴](卡牌设计.md#续痕贴)** · 木系被动 | 本方轮首，若此卡右侧有共边伤势卡，恢复至多 X 点 HP。 | 经典的持续治疗，条件来自背包里看得见的伤势。 | 把药贴直接贴在伤口旁，伤还在，药就继续起效。 | 留伤可以续血，也会继续占格。玩家要判断是再吃一轮治疗，还是尽早腾位置。 |
| **[净损余贴](卡牌设计.md#净损余贴)** · 木系法术，**消耗**、**灵活** | 此卡**耗尽**时，移除己方随机一张恰好 X 格的伤势卡。 | 有限次数的疗伤道具，用完才兑现清伤。 | 最后一张药贴揭走同宽的伤，空药匣也退出背包。 | 玩家可以通过摆位和供灵安排清伤时机。指定尺寸限制了收益，同尺寸多张伤势时由随机决定目标。 |
| **[残响鼓](卡牌设计.md#残响鼓)** · 火系被动 | 每有一张友方卡实际离场，对敌方造成 X 点伤害。 | 退场换伤害，消耗品和清伤都能成为进攻资源。 | 每撤下一张牌，空出来的位置就回响一声。 | 需要其他牌实际离场，触发是否发生能从背包变化看懂。数值要按一轮可能连续离场几张来定。 |
| **[扬潮左桨](卡牌设计.md#扬潮左桨)** · 水系法宝 | 己方成功补灵后，使此卡左侧共边卡向左**滑移**。 | 用补给触发换位，一张牌就能演示这套背包的动态布局。 | 灵元落格荡起水波，桨顺势把左邻推开。 | 推谁由摆位决定，滑多远由实际空间决定。留滑路会挤压摆牌空间，终点也可能盖掉格上的灵元。 |
| **[走格簧](卡牌设计.md#走格簧)** · 木系被动 | 友方卡成功**滑移**后，给己方背包**充能** X 个基准 Tick。 | 位移换行动进度，给搬牌构筑一个明确回报。 | 卡位带动簧片，簧片拨快扫描齿轮。 | 成功滑移才给进度，收益取决于离下一行还有多远。需要能移动的牌，也需要实际留出滑路。 |

## 放进同一个卡池后

- **留伤和清伤有两个时机。** 续痕贴让玩家有理由把伤留过一个轮首，净损余贴给了腾格的手段。残响鼓让主动退场也能转成输出。如果净损余贴清掉一张伤势，且自己随后因灵活离场，按原案应给仍在生效的残响鼓两次触发。 [消耗与灵活规则](../../../../openspec/specs/consume-stack/spec.md#requirement-到零触发耗尽并按灵活规则离场)
- **滑路本身有价值。** 扬潮左桨把补灵接到滑移，走格簧再把滑移接到扫描。举例，下一行还差 2 Tick 时，若一次滑移提供 2 Tick，就能当场推进到下一行。用同一个背包测摆满和留空两种排法，看提前扫到的卡能否改变一次对拼。 [背包扫描规格](../../../../openspec/specs/combat-backpack-scan/spec.md)

## 正式卡面需要说清的两处时机

- **穿隙楔**建议写成「友方卡进行攻击直击时，在伤害结算前……」。现有直击事件也会在防御待发时派发，成卡时需单独核对两种待发结果。 [触发定义](../../../../Data/TriggerDefines.json)
- **立挡还针**建议写明「己方以防御侧完成一次分出胜负的对拼后……」。这样防守方输掉对拼仍可反击，玩家也能预判平局的处理。 [触发定义](../../../../Data/TriggerDefines.json)

叩脉钉和走轨覆霜先留在候选池。叩脉钉把频繁对拼直接转成扣 MP，容易持续挤压对手的补灵。走轨覆霜会把连续滑移转成多次冻结，可能让对手一轮失去多张牌的发动机会。等首批卡能测出对拼和滑移的实际频率，再评估这两张。 [叩脉钉](卡牌设计.md#叩脉钉) · [走轨覆霜](卡牌设计.md#走轨覆霜)
