# 入选的随机 TCA 组合

每轮阅读全部 100 条，挑出 10 条。先检查事件、目标和前置条件，再看组合给摆放、灵元调度、对拼或卡组构筑带来的选择。效果数值用 X，各处独立调节。战斗题材和成卡入口在[卡牌设计](卡牌设计.md)中展开。

来源为[原始抽样](抽样记录/第01轮.txt)。保留了四种结构。

| 结构 | 入选效果 | 为什么值得做成卡 |

| T+A | 友方卡离场后，对敌方造成 X 点伤害。 | 给消耗品退场和清伤提供一个可构筑的进攻收益。 |

| T+C+A | 己方待发直击时，若来源卡下侧有共边招式，获得 X 层刺击强化。 | 让负责直击的卡给后续刺招搭桥。条件看的是发起直击的卡。 |

| A | 获得火灵供能 X 轮，每轮开始为可接收的场上法宝补至多 X 个火灵元。 | 搭配火需求法宝能改掉续不上被动的问题，领到的供能有明确对象。 |
