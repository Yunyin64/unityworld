# TCA 随机组合卡牌设计

从入选机制推导卡名、五行、类型与画面。不同位置的 X 可独立调整。已有关键词用粗体，触发条件和目标写在卡面上。 [入选效果与原始抽样](入选组合.md)

## 第 01 轮

### 伏地诀

- **描述**　土系，法术。将灵气沉到脚下，连环劲力便顺脚跟泻入地中。
- **效果与数值**　此卡结算时，获得 X 点**坚甲**。
- **卡图**　低机位看一名修士沉肩扎稳。碎石向外泛成几圈，每道袭来的刀风各留一条浅痕。

### 沉沙漏

- **描述**　土系，法宝。己方每接住一捧灵，漏中就有沙落向对阵之人。
- **效果与数值**　己方成功补灵后，给敌方施加 X 层**石化**。
- **卡图**　上半截沙漏亮起一簇己方入格灵元，下半截砂砾凝成扣住对方经脉的灰色壳。

### 残响鼓

- **描述**　火系，被动。撤下一符，鼓面便响一声。空出来的凹槽里还留着余震。
- **效果与数值**　每有一张友方卡实际离场，对敌方造成 X 点伤害。
- **卡图**　皮鼓一侧刻满卡位形状，褪下来的焦黄纸符飞向画外，鼓面红纹将震波送向对阵者。

### 寒砚

- **描述**　水系，法术。用功法作帖，寒砚里的水才知道该冻住哪边。
- **效果与数值**　此卡结算时，若右侧有共边功法，随机**冻结**一张未冻结且未耗尽的敌方主动卡。
- **卡图**　画面右侧是一卷功册，书脊和青砚紧贴。墨水延伸成冰棱，刺入对面排布中的一张卡。

### 引锋图

- **描述**　金系，被动。上势未遇拦截，便替下势画开一条刺路。
- **效果与数值**　友方卡**直击**时，若该卡下侧有共边招式，获得 X 层**刺击强化**。
- **卡图**　展开的剑谱上，压着一枚已飞过缺口的刻刀。谱页下方的刺路被金线逐道描亮。

### 松榫铃

- **描述**　金系，法宝。接下对方来势的一刻，铃声顺劲钻进敌人的装备接缝。
- **效果与数值**　己方作为防御侧结算后，敌方所有在场装备防御降低 X 点，持续 X 个敌方轮。场上招式绑定的装备也计入。
- **卡图**　近景是挂在护手下方的铜铃。远处对手的盾箍和护具铆钉同时松动，盾面还保留刚才的冲击痕。

### 借壁槌

- **描述**　土系，法术。借左侧物件挡住反劲，短槌才有余地砸出去。
- **效果与数值**　此卡发动时，若左侧有共边友方卡，生成 X 点土系**打击**拼点。
- **卡图**　握槌人的左肩抵住石匣，右侧短槌下压。构图留出一段清楚的共边，强调反作用力。

### 催势节

- **描述**　木系，法术。把鼓点贴着一式武艺钉下，整盘动作便抢前半拍。
- **效果与数值**　此卡结算时，若右侧有共边招式，给己方背包**充能** X 个基准 Tick。
- **卡图**　细竹节横放在某式刀谱左边，竹纹发出的波纹越过其余背包行格，远处扫描光带向前跳动。

### 横纹袍

- **描述**　木系，被动。衣纹顺着刀路织，外层裂过，里层仍能兜住刀锋。
- **效果与数值**　本方轮首获得 X 层**斩击抗性**，持续 X 个本方轮。
- **卡图**　旧袍有两组不同深浅的经纬线，一道横斩卷起外层布纹，内层的旧线仍拉紧。

### 温匣令

- **描述**　火系，法术。匣中火熬到下一轮，才够喂养法宝。
- **效果与数值**　此卡结算时，获得 X 点火系**法宝供能**，持续 X 个本方轮。
- **卡图**　打开的多格匣中悬着火珠，一道火丝从火珠牵向远处烧红的法宝，其余法宝保持暗色。

## 第 02 轮

### 叩脉钉

- **描述**　金系，法宝。两股力正要相撞，钉尖便沿着接缝叩断一截气脉。
- **效果与数值**　每次实际**对拼**比较前，敌方失去至多 X 点 MP。
- **卡图**　两道兵刃隔空相抵，一粒细长金钉悬在缝里，钉尖下方的蓝色经脉断开。

### 炼甲散

- **描述**　土系，法术，**消耗**、**灵活**。最后一撮药散烧完，在皮肤上留下一层陶纹。
- **效果与数值**　此卡**耗尽**时，获得 X 层**斩击抗性**，持续至战斗结束。
- **卡图**　打开的陶药盒只剩空格，沿指节蔓延的壳上能看见新挂上的刀痕。

### 伏轮钉

- **描述**　土系，法术。把钉暗扣在上方术式下，等对手重启气路时才扎住。
- **效果与数值**　此卡结算时，若上侧有共边法术，敌方在之后第 X 个轮首失去至多 X 点 MP。
- **卡图**　一枚暗黄钉子卡在两块相接的法帖之间，红线连向远处尚未亮起的轮盘刻度。

### 接流葫

- **描述**　水系，法宝。防下的余劲先全接进壶里，等次轮开口才倒回丹田。
- **效果与数值**　己方作为防御侧结算后，在之后第 X 个本方轮首回复至多 X 点 MP。
- **卡图**　水葫芦口向上一仰，护腕边散开的气流落进壶中，塞子下透出幽蓝。

### 蓄壳印

- **描述**　土系，被动。每回术式合印，都在下一面盾上多压一道暗纹。
- **效果与数值**　友方卡完成效果结算后，己方下一次匹配的**盾**型实际对拼提高 X 点，登记持续 X 个本方轮。
- **卡图**　已燃尽的纸符旁只剩印记。前景盾胚上新压出一道能看见厚度的方印。

### 解彩刃

- **描述**　金系，法宝。在战阵未撞到敌手时，反手削掉其身上的一缕彩气。
- **效果与数值**　友方卡**直击**时，若其前后至少有一张场序相邻卡，清除敌方至多 X 层五行增益。
- **卡图**　一刀擦着错开的武器飞过，敌人肩头的五色薄绸被挑开几缕，后方两张牌仍肩背相接。

### 缀皮披

- **描述**　木系，法宝。披片缝在松口上，皮下受创时才会绷到一起。
- **效果与数值**　己方实际失去 HP 后，获得 X 层**护甲**，持续至多 X 个本方轮。
- **卡图**　披肩侧面露出一道浅伤，木纤维正从两端勒紧，把分开的皮甲片拼拢。

### 收烬斗

- **描述**　火系，被动。退场腾出空隙，簸斗顺势簸起散落的余火。
- **效果与数值**　友方卡实际离场后，回收己方背包中至多 X 个未分配的火灵元，每个转为等量 MP。
- **卡图**　一张纸符刚从牌阵中抽走，铜斗倾斜着从周边格位捞起仍亮的火珠。

### 走槽舵

- **描述**　水系，被动。气水一涨一落，下面的物件就跟着沿槽滑。
- **效果与数值**　己方 MP 变化后，使此卡下侧的共边卡向左**滑移**。
- **卡图**　浅色水槽里一块浮板横移，暗色槽壁上的纵向刻痕表明舵的位置始终固定。

### 衔创针

- **描述**　水系，法术。创口尚留着冷气，针尖便能把这股冷意送出阵外。
- **效果与数值**　此卡发动时，若上侧有共边伤势卡，生成 X 点水系**刺击**拼点。
- **卡图**　银针悬在带裂纹的伤势牌下方，水汽沿针尖收细，聚成发亮的一线。

## 第 03 轮

### 抬阶箓

- **描述**　土系，法术。符边起一截石阶，把搭着它的物件托往上一行。
- **效果与数值**　此卡结算时，使右侧共边卡向上**滑移**。
- **卡图**　斜俯视阵盘，符纸右缘拱成几级砖纹，紧贴的木牌被一股土气推向画面上端。

### 断丝匣

- **描述**　金系，法术，**消耗**。匣底藏着一根断丝，压到最后才会弹出。
- **效果与数值**　此卡最后一次发动并结算时，给敌方施加 X 层**出血**。
- **卡图**　扁金匣内只剩末根细丝。匣口刚弹开，丝尾还牵在磨空的卡格上。

### 黏锋帘

- **描述**　木系，法宝。接下对方一招，帘上的湿藤就缠住他的后手。
- **效果与数值**　己方作为防御侧结算后，使敌方背包**减速** X Tick。
- **卡图**　一层淡绿藤帘贴住敌人的兵刃，远景中连着他的整条扫描光带，光带在藤结前减缓。

### 续痕贴

- **描述**　木系，被动。膏贴得紧挨伤口，草药醒来才知道往哪个方向长。
- **效果与数值**　本方轮首，若此卡右侧有共边伤势卡，恢复至多 X 点 HP。
- **卡图**　绿纸贴紧室内一张暗红裂纹牌，纤细根须从纸边钻出，只向右侧裂隙蔓延。

### 回痛弦

- **描述**　金系，被动。把伤口压在线旁，阵中每挪一物，都把那一下痛弹给对手。
- **效果与数值**　友方卡**滑移**后，若此卡右侧有共边伤势卡，对敌方造成 X 点伤害。
- **卡图**　一根琴弦系在正在移动的牌上，固定端右边压着裂口牌。飞出的震纹又尖又短。

### 接档尺

- **描述**　土系，法术。把木尺放在两式之间，谁先架住来势，谁就借到那一截尺劲。
- **效果与数值**　此卡结算时，选取场序前后相邻卡。X 轮内，第一张进入**格挡**实际对拼的选中卡，拼点提高 X。
- **卡图**　刻尺两端分别抵住前后阵位，一端正伸出清楚的棕金量线，另一端保持暗色。

### 翻池勺

- **描述**　水系，被动。添新水前先舀旧水，池底才不总剩同一色。
- **效果与数值**　己方基础补灵前，回收至多 X 个未分配灵元，每个转为等量 MP。
- **卡图**　浅水池边一柄木勺舀起几粒不同色泽的灵元，另一边空出来的石槽正等待新水流入。

### 破纹金帖

- **描述**　金系，法术，**消耗**、**灵活**。最后一道印痕褪去，背包里从此更常亮起金光。
- **效果与数值**　此卡**耗尽**时，己方**金亲和**提高 X，持续至战斗结束。
- **卡图**　金箔纸从中心烧空，飘开的灰烬几乎透明，远处阵盘上的金色落点反而变亮。

### 褪燎纱

- **描述**　水系，法宝。药水一沾皮肤，旧火才从纱孔里退出来。
- **效果与数值**　己方实际恢复 HP 后，清除己方至多 X 层火系减益。
- **卡图**　湿纱覆盖伤口，水珠聚在冷蓝边缘，原本黏住布纹的红色焦斑正成片褪落。

### 乘隙垂索

- **描述**　木系，法宝。占上风的一瞬松绳，旁边两手便有了换位的余地。
- **效果与数值**　己方**对拼**胜出时，使此卡场序前后相邻卡向下**滑移**。
- **卡图**　高处一根藤索被松开，两侧卡牌沿短槽往下错开。后景仍留着对拼胜出的火花。

## 第 04 轮

### 逆水轮

- **描述**　水系，法宝。水涨能拨轮，水落也能拨轮，两头都将下一刻推近。
- **效果与数值**　己方 MP 实际变化后，己方背包**加速** X Tick。
- **卡图**　一枚双向叶轮横架在两条回旋水道之间。上升和回落的水痕都指向轮轴同一转向。

### 缝月罍

- **描述**　土系，法宝。罍先记住裂痕，等过几轮才用陶泥翻成挡在身前的壳。
- **效果与数值**　己方实际失去 HP 后，在之后第 X 个本方轮首获得 X 点**灵盾**。
- **卡图**　细裂的祭罍悬在三重不等大的轮纹前，最远的一重轮纹已显出半片陶盾轮廓。

### 割垒梭

- **描述**　金系，被动。阵中有人换位，梭就借那段行程从敌盾边缘拉走一线。
- **效果与数值**　友方卡成功**滑移**后，消除敌方至多 X 点**灵盾**。
- **卡图**　金梭随着左侧木牌错位而拉紧丝线，另一端刮开敌盾的一层蓝色弧光。

### 伏焰扣

- **描述**　火系，法宝。迎面接住的每一下震动，都把熄着的扣眼往红里敲一分。
- **效果与数值**　己方作为防御侧结算后，获得 X 层**心火**。
- **卡图**　护腕被刀背击中，压在扣眼里的炭芯从中心亮起。用深黑背景突出红光。

### 左列坠

- **描述**　土系，被动。要有一式武艺镇在左首，坠石过夜才会把浊气压住。
- **效果与数值**　本方轮末，若左侧有共边招式，获得 X 层**载德**。
- **卡图**　深黄石坠贴着左边的剑谱悬住，细密土尘在阵盘将暗的一刻沉进石面。

### 叶夹

- **描述**　木系，法术，**消耗**。草叶夹在盾片间。新叶能护伤，叶少以后只剩盾片。
- **效果与数值**　此卡发动时生成 X 点**格挡**拼点。此卡作为防御侧结算后，若剩余消耗至少 X 次，获得 X 层**再生**。
- **卡图**　双层青木盾夹着一叠露尖的叶。外层盾吃住攻击，几滴新鲜药露从叶缘挤出。

### 拔圭术

- **描述**　土系，法术。左边术式替它稳住手，阵外未扎根的土灵就能被整块拔起。
- **效果与数值**　此卡结算时，若左侧有共边法术，移除敌方背包内至多 X 个未分配的土灵元。
- **卡图**　并排的法帖左侧发光，右侧一只泥手越过阵线，拔掉几枚尚未嵌入卡牌的方土圭。

### 侧芽铃

- **描述**　木系，被动。主攻手身边有人接势，铃缝里的毒芽才会顺着胜势伸长。
- **效果与数值**　友方卡在**对拼**中获胜，若它有场序相邻卡，给敌方施加 X 层**中毒**。
- **卡图**　插在阵角的小铜铃从裂缝吐出绿芽。远景中胜出卡与相邻卡仍排列在一条线。

### 叠潮册

- **描述**　水系，法宝。上方功册压住回潮，挡完一击正好把水收回。
- **效果与数值**　己方作为防御侧结算后，若此卡上侧有共边功法，回收己方至多 X 个未分配水灵元并转为等量 MP。
- **卡图**　线装功册压在卷起的青色水页上，水页下方有一面倒映着水光的护手。

### 晨灰幡

- **描述**　火系，被动。天光一过幡沿，昨晚存下的灰就落在对面。
- **效果与数值**　本方轮首，给敌方施加 X 层**灼烧**。
- **卡图**　暖灰色长幡立在冷清的清晨，幡尾掀起几片带亮边的火灰，落向对方阵地。

## 第 05 轮

### 走格簧

- **卡图**　错开的卡位带动一条细齿木轨，簧片在齿边绷出一道极细的亮线。

### 拔灯钩

- **描述**　金系，法术。用受伤处没散尽的劲扣住钩尾，对面的灯从根上拔得动。
- **效果与数值**　此卡结算时，若右侧有共边伤势卡，清除敌方至多 X 层火系增益。
- **卡图**　细银钩从红色裂纹牌边伸出，扣住敌阵里一盏摇晃的油灯灯柄。

- **描述**　土系，被动。功册贴在龛左，撞上来势的那一刻，龛门会合上一层护面。

### 涨脉丸

- **描述**　木系，法术，**消耗**。丸心先松开一截气脉，余药随后才慢慢走完。

- **卡图**　一枚药丸裂开青色内芯，光沿腕内血脉撑出新的轮廓，边缘几颗药丸尚未打开。

### 压弦签
