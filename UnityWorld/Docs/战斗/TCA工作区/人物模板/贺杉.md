# 贺杉

给守城队整修弩机。随身只有两只备用匣，愿意先试射一匣再决定何时换弹。

换匣弩在备用弹匣正上方。弩激活时才听得到下面的弹匣发动，给后排射击加点；弹匣自己另外结算补弹。弩彻底退出格子后，仍能按保留的装备记录出招。

弹匣可能提前开空。补不上弹时只有一轮火力加成，药散尽后没有额外防御。

## 功法

首次开轮为法宝补一枚金灵元。己方每轮首次有灵活卡实际离场时推进 5 基准 Tick。
