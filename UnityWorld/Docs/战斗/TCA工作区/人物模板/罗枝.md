# 罗枝

替果园嫁接寒枝。对敌时愿意把一轮灵元省下来，等木火齐备发一记重手。

交枝吃一木一火。两色都实际支付后，功法回 MP，合叉藤杖激活时再整一层护甲。错枝刺在同轮支付两种后多一点，横青架和火弹是没攒齐时的退路。

木火齐备才有主要收益。连冻多格牌或逼她一再使用架藤，会错开输出窗口。
