# 后端轮赛复跑

脚本调用现有程序集装配 NPC、运行独立战斗场景、读取表现事件。每个种子都跑同一配对的两个装配顺序。阵营也对调，双方同 Tick 到行时按 NPC ID 顺序扫描。结果的 firstScanned 保存这一情况下的优先者。每局创建新的 NPC 和卡牌实例，使用试战快照。

通用对战和新模板请使用项目技能[战斗模拟](../../../../../skills/combat-simulation/SKILL.md)。以下入口保留这批人物轮赛的历史参数与装配检查。

## 启动一次轮赛

在仓库根用 PowerShell 7.4 或更高版本的 x64 进程运行。每个批次用独立进程，避免承接前一批留在进程里的伤势实例。轮赛从工作区读取数据，同一批次结束后再改 Lua。逐局异常写入结果 JSON，进程返回 1。启动失败时查看终端报错。

~~~pwsh
dotnet build UnityWorld/Console/UnityWorld.Console.csproj
$md = 'UnityWorld/Docs/战斗/TCA工作区/人物模板/后端轮赛复跑.md'
$raw = Get-Content -Raw -LiteralPath $md
$run = [regex]::Match($raw, '(?ms)^~~~powershell\r?\n(.*?)^~~~').Groups[1].Value
$script = Join-Path $env:TEMP 'unityworld-roster.ps1'
$run | Set-Content -LiteralPath $script -Encoding utf8
pwsh -NoProfile -File $script -Scope All
~~~

按模板 ID 用 `-Only` 筛选配对。筛选会改变 NPC 的创建次序。精确复现整个批次时，保持参与模板、筛选范围、世界种子、战斗种子及顺序、装配顺序和 Tick 上限一致。

把以下命令放在一个新 PowerShell 7 进程中，可只测指定两人并延长 Tick 上限。和整张轮赛表相比，单配对模式会有不同的 NPC 实例 ID 和先天亲和。用同样的 Pair 和种子重复才能逐局核对。

~~~pwsh
& (Join-Path $env:TEMP 'unityworld-roster.ps1') -Pair 'roster_qu_ze','roster_shan_heng' -WorldSeed 17989 -Seeds 8111,1207,3169 -Limit 5000
~~~

排查耗灵长局时加 `-TraceResources`。它记录开战、每 250 Tick 和结算时双方的 HP、MP、护盾、SP 与扫描轮号。`pendingValues` 按卡牌 ID 和进入待发时的拼点统计次数。

核对法宝激活窗口时加 `-TraceArtifactPhases`。结果的 `artifactPhases` 按卡牌 ID、实际生效回调和生效时的阶段记数。可检查战斗事件效果是否都落在激活期，并区分激活光环与 `Flexible` 的离场生命周期。

如果 MP 和轮号显示对局仍在运转，同时加 `-TraceManaPair 'roster_liu_pan','test_npc_b'`。指定配对的轨迹会记录空格数量、各色闲置灵元、卡牌费用和蓄灵，以及各卡此时还可以接收的场上元素。用 `-Scope All -WorldSeed 41113 -Seeds 11701 -Limit 5000` 按当时的全表配对顺序复跑。

如果同组前面已有触顶对局，用 `-ExtendPair` 与 `-ExtendOrder` 单独延长目标局。前面各局保持原上限，目标局结束即停止。这样前局额外产生的伤势实例不会改变目标局。`-Limit` 填原上限，`-ExtendedLimit` 填目标局上限，世界、种子、筛选和装配顺序沿用原批次。原批次有多个种子时，另用 `-ExtendSeed` 指定目标局的战斗种子。

~~~pwsh
& (Join-Path $env:TEMP 'unityworld-roster.ps1') -Scope All -WorldSeed 160183 -Seeds 52253 -Limit 2500 -ExtendPair 'roster_duan_ying','roster_qu_ze' -ExtendOrder Swapped -ExtendedLimit 5000 -TraceResources -TraceManaPair 'roster_duan_ying','roster_qu_ze'
~~~

逐局归因时，用两个独立 PowerShell 进程对照。每个进程只运行一个 `-Pair`、一个战斗种子和一个 `-Order Forward` 或 `-Order Swapped`。批量测试共享世界卡牌 ID 分配。前一局多结算一次伤势会改动后续分配，直接比较两个批次的每局胜负会把实例差异也算进去。

## 轮赛脚本

~~~powershell
param(
    [int[]]$Seeds = @(1207, 3169, 5519),
    [int]$WorldSeed = 12345,
    [string]$Only,
    [string[]]$Pair,
    [ValidateSet('Roster', 'Baseline', 'All', 'Existing')]
    [string]$Scope = 'Roster',
    [ValidateSet('Both', 'Forward', 'Swapped')]
    [string]$Order = 'Both',
    [int]$Limit = 2500,
    [string[]]$ExtendPair,
    [ValidateSet('Forward', 'Swapped')]
    [string]$ExtendOrder = 'Forward',
    [Nullable[int]]$ExtendSeed,
    [int]$ExtendedLimit = 5000,
    [switch]$TraceResources,
    [switch]$TraceArtifactPhases,
    [string[]]$TraceManaPair,
    [string]$OutputPath = (Join-Path $env:TEMP 'unityworld-roster-results.json')
)

# 从仓库根运行，沿用首轮 24 人轮赛的名单规则、SP 检查与默认输出路径。
$PSBoundParameters['Scope'] = $Scope
$PSBoundParameters['OutputPath'] = $OutputPath
& (Join-Path $PWD 'skills/combat-simulation/scripts/run.ps1') @PSBoundParameters -HistoricalRoster
exit $LASTEXITCODE
~~~

## 更新全量轮赛文档

合并前确认各 JSON 抄录的是同一版工作区数据。这个命令重写《全量轮赛》。角色试打沿用各自 Markdown，阶段变化写入《工作总结》。

~~~pwsh
$md = 'UnityWorld/Docs/战斗/TCA工作区/人物模板/后端轮赛复跑.md'
$body = [regex]::Match((Get-Content -Raw -LiteralPath $md), '(?ms)^~~~python\r?\n(.*?)^~~~').Groups[1].Value
$env:ROSTER_REPORT_VERSION = '填写本次对战版本'
$body | python - unityworld-roster-full6-a.json unityworld-roster-full6-b.json unityworld-roster-full6-c.json
~~~

~~~python
import os,json,statistics,itertools,sys,hashlib,re
from pathlib import Path
from collections import Counter,defaultdict
base=Path('UnityWorld')
files=[Path(os.environ['TEMP'])/name for name in sys.argv[1:]]
load=lambda p: json.loads(p.read_text(encoding='utf-8-sig'))
docs=[load(f) for f in files]
names={n['ID']:n['DisplayName'] for p in (base/'Data/Npc').glob('*.json') for n in load(p)}
new={key for key in names if key.startswith('roster_')}
layouts=docs[0]['layouts']; assert len(new)==24 and set(layouts)==set(names),(len(new),set(names)-set(layouts))
results=[row for d in docs for row in d['battles']]
pair_counts=Counter(tuple(sorted([b['left'],b['right']])) for b in results)
assert set(pair_counts)==set(itertools.combinations(sorted(names),2)),(len(pair_counts),len(names))
assert min(pair_counts.values())>=3
roster_results=[b for b in results if b['left'] in new and b['right'] in new]
status=Counter(b['reason'] for b in results)
assert not status.get('Error')
wins,loss,draws=Counter(),Counter(),Counter()
by_pair=defaultdict(Counter)
effects=defaultdict(Counter);uses=defaultdict(Counter);wounds=Counter()
outcomes=Counter(); stalled=[]
for row in results:
    l,r=row['left'],row['right']
    for pos,key in (('left',l),('right',r)):
        state=row[pos+'State'];effects[key].update(state['effects']);uses[key].update(state['uses']);wounds.update(state['wounds'])
    if row['reason']=='AllDefeated' and row.get('winner') in (l,r):
        winner=row['winner'];loser=r if winner==l else l
        by_pair[l,r][winner]+=1
        if l in new and r in new:
            wins[winner]+=1;loss[loser]+=1
    else:
        by_pair[l,r][row['reason']]+=1
        if l in new and r in new:
            draws[l]+=1;draws[r]+=1
            stalled.append(row)
    if l in new and r in new: outcomes[row['reason']]+=1
ticks=sorted(b['ticks'] for b in roster_results if b['reason']=='AllDefeated')
print('TOTAL',len(results),'PAIRS',len(pair_counts),'MIN',min(pair_counts.values()),'max',max(pair_counts.values()),'STATUS',dict(status))
print('NEW',len(roster_results),dict(outcomes),'TICKS',min(ticks),statistics.median(ticks),round(statistics.quantiles(ticks,n=10)[8]),max(ticks))
print('WOUNDS',dict(wounds),'stall matchups',Counter(tuple(sorted([names[r['left']],names[r['right']]])) for r in stalled))
print('ROOM data',[(d['worldSeed'],d['seeds'],d['worldCardCountAfter']-d['worldCardCountBefore']) for d in docs])
for key in sorted(new,key=lambda id: wins[id]/max(1,wins[id]+loss[id]),reverse=True):
    print(names[key],key,wins[key],loss[key],draws[key],layouts[key]['SP'],layouts[key]['SPMax'],round(100*wins[key]/max(1,wins[key]+loss[key])))
coverage={}
for c in (base/'Data/Card').glob('Roster_*.json'):
    pack=[x['ID'] for x in load(c)]; owner=next(n for n in new if n in uses and (set(pack)&set(uses[n])) and any(k.split('/')[0] in pack for k in effects[n]))
    no_use=[p for p in pack if p not in uses[owner] and not any(k.split('/')[0]==p for k in effects[owner])]
    if no_use: print('NO EFFECT SAMPLE',names[owner],no_use)
data=hashlib.sha256()
for f in sorted((base/'Data').rglob('*')):
 if f.is_file() and f.suffix.lower() in ('.json','.lua'):
  data.update(f.relative_to(base).as_posix().encode('utf-8'));data.update(b'\x00');data.update(f.read_bytes());data.update(b'\x00')
print('DATA_SHA256',data.hexdigest())

md=base/'Docs/战斗/TCA工作区/人物模板/全量轮赛.md'
version=os.environ.get('ROSTER_REPORT_VERSION','全表基线')
ending=sum(wins.values())
normal_draw=outcomes.get('AllDefeated',0)-ending
nmin,nmax=min(pair_counts.values()),max(pair_counts.values())
span=str(nmin) if nmin==nmax else f'{nmin}–{nmax}'
def rank_key(id):return (-wins[id]/max(1,wins[id]+loss[id]),id)
def title(id):return f'[{names[id]}]({names[id]}.md)' if id in new else names[id]
lines=[
'# 全量轮赛','',
f'版本 {version}。当前数据指纹为 \x60{data.hexdigest()}\x60。', '',
f'24 位新模板加 3 位原模板，覆盖 {len(pair_counts)} 个配对。每对 {span} 局，共 {len(results)} 局。每组种子同时跑两个装配顺序。','',
f'新角色之间 {len(roster_results)} 局，{ending} 局决胜，{normal_draw} 局双败退，{outcomes.get("TurnLimitReached",0)} 局触顶。正常结束的对局中位 {statistics.median(ticks):g} Tick，P90 为 {round(statistics.quantiles(ticks,n=10)[8])} Tick。全表 {status.get("TurnLimitReached",0)} 局触顶，无执行异常。','',
f'实际入场伤势 {wounds.get("bp_wound_small",0)} 次轻伤、{wounds.get("bp_wound_wide",0)} 次重伤。正常胜负统计包含 SP 超限败退。','',
'| 世界种子 | 战斗种子 | 单局上限 | 原始文件（本机临时目录） |',
'| ---: | ---: | ---: | --- |']
for d,path in zip(docs,files):
    lines.append(f'| {d["worldSeed"]} | {", ".join(map(str,d["seeds"]))} | {d["limit"]} Tick | \x60{path.name}\x60 |')
lines+=['','## 新角色胜负','',
'胜率分母为有效决胜场次。原模板只作为功能参照。','',
'| 角色 | 胜 | 负 | 无胜者或触顶 | 胜率 | 起始 SP | HP / MP |',
'| --- | ---: | ---: | ---: | ---: | --- | --- |']
for id in sorted(new,key=rank_key):
    v=layouts[id]
    lines.append(f'| {title(id)} | {wins[id]} | {loss[id]} | {draws[id]} | {wins[id]/max(1,wins[id]+loss[id]):.1%} | {v["SP"]}/{v["SPMax"]} | {v["HP"]} / {v["MP"]} |')
lines+=['','## 每个配对','',
'<details>','<summary>展开 351 个配对</summary>','',
'| 左角色 | 右角色 | 左胜 | 右胜 | 双败退 | 触顶 |',
'| --- | --- | ---: | ---: | ---: | ---: |']
for (l,r), x in sorted(by_pair.items()):
    lines.append(f'| {names[l]} | {names[r]} | {x[l]} | {x[r]} | {x["AllDefeated"]} | {x["TurnLimitReached"]} |')
lines+=['','</details>','']
md.write_text('\n'.join(lines),encoding='utf-8')
~~~
