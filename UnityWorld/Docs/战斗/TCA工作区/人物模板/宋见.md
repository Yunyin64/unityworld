# 宋见

走浮桥送药，身上带一片醒春叶。越早找回出手节奏，越能少挨一轮打。

青苇行功让右邻木针发动后抢速。苇桥杖激活期听招式发动，气血低时给薄盾。伤势还在，扑苇刺多 1 点，醒春叶确实治进气血后，回纹签回复 MP。

留下了救命牌的占格和行额度。核心边上的卡被推开后，节奏收益立刻断掉。
