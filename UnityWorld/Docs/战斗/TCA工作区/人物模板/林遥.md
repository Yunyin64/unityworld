# 林遥

替驿站在山路上做藤缆陷阱。善于等对手攒到一半，再抽掉支撑下一步的一截。

两仪壶与沙藤钩都可能凑出木土实付。寄阵法在两色实付时剥灵，壶只在激活期间等沙藤钩实际支付两色，再清减益、回 MP。抽藤锋只剥木灵，藤囊芯给第一次点燃两色留盾。

剥离随机挑卡，可能打空。控不起两次连锁，敌方低费快攻能更早出手。

## 功法

己方每轮第一次实际支付至少两种灵元时，从敌方随机一张卡剥离至多 1 枚已点亮灵元。
