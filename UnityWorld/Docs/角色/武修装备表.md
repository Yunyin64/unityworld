# 武修装备表

## 装备与装配

每种装备形态带一组固定招式。同一个字共用一张卡牌定义，每张招式卡绑定提供它的那件装备。比如短剑和长刀都带「斩」，短剑的「斩」读短剑的攻击，长刀的「斩」读长刀的攻击。法宝本卡的激活效果由法宝卡自己定义。

**自带招式数量 = 法宝本卡的 Size + 1。** Size 为 1、2、3 的装备分别带 2、3、4 招。表中每个「口」代表一个待定招式位，「口、口」就是还有两招待定。

装配时，法宝本卡和每张自带招式都要排进背包，各按自己的占格计入 SP。例如长剑本卡占 2 格，带「斩、刺、格」三招。若三招各占 1 格，整套占 5 格，用 5 SP。

## 共用招式

<武器>指招式绑定的装备，包括盾、甲、靴等。<攻击>和<防御>取出招时的生效值。卡面只写本卡的动作和效果。Keyword 与基础对拼的结算见[拼点规则](../../openspec/changes/defense-contests-and-card-shapes/specs/combat-contest-scheduling/spec.md)。下表各招的 X 单独调。

### 基础招式

| 招式 | 出手类型 | 卡面效果 |
| --- | --- | --- |
| 格 | 格 | 按<武器><防御>格开来招 |
| 挡 | 挡 | 按<武器><防御>抵挡来招 |
| 闪 | 闪避 | 按<武器><防御>闪避来招 |
| 斩 | 斩击 | 按<武器><攻击>发起斩击 |
| 刺 | 刺击 | 按<武器><攻击>发起刺击 |
| 打 | 打击 | 按<武器><攻击>发起打击 |
| 射 | 射击 | 按<武器><攻击>发起射击 |

### 克制招式

这七招各克一种出手类型。对拼时看对手本次实际用的类型，碰上克制目标就先加 X 点，再比胜负。例如「截」克射击，既能截弓的「射」，也能截飞刀的「瞄」。其余对局按本招原有点数比拼。

| 招式 | 出手类型 | 克制目标 | 卡面效果草案 |
| --- | --- | --- | --- |
| 劈 | 斩击 | 刺击 | 按<武器><攻击>发起斩击，对上刺击时本招拼点加 X |
| 撩 | 斩击 | 斩击 | 按<武器><攻击>发起斩击，对上斩击时本招拼点加 X |
| 砸 | 打击 | 挡 | 按<武器><攻击>发起打击，对上挡时本招拼点加 X |
| 扫 | 斩击 | 闪避 | 按<武器><攻击>发起斩击，对上闪避时本招拼点加 X |
| 挑 | 刺击 | 打击 | 按<武器><攻击>发起刺击，对上打击时本招拼点加 X |
| 钩 | 斩击 | 格 | 按<武器><攻击>发起斩击，对上格时本招拼点加 X |
| 截 | 格 | 射击 | 按<武器><攻击>格开来招，对上射击时本招拼点加 X |

### 其他出招方式

「推」用防御出手攻击，与「截」用攻击出手防御相对。「瞄」「点」「转」的草案都由本卡直接出手。

| 招式 | 出手类型 | 卡面效果草案 |
| --- | --- | --- |
| 推 | 打击 | 按<武器><防御>发起打击 |
| 瞄 | 射击 | 敌方已有待发拼点时才出手，按<武器><攻击> + X 发起射击 |
| 点 | 刺击 | 按<武器><攻击>发起刺击，直击时本次基础伤害加 X |
| 转 | 闪避 | 按<武器><防御>闪避来招，对上打击时本招拼点加 X |

## 装备形态与自带招式

形态按器形、尺寸、重量或用途区分，材料独立于形态。攻防为首版试配值。短剑、长剑、重剑的占格和攻防沿用现有短剑、长剑、巨剑的数据，其余数值按这三把剑的量级起草。

震为足，靴归震。巽为股，腿甲归巽，表中的腿甲主要护大腿。坤取躯体与性命本源。镜、印、鼎是炼入体内温养、与自身性命相合的本命法宝。法身是修士以自身躯体为根基温养而成的形态。
