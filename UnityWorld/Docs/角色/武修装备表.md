# 武修装备表

每行是一种法宝形态。形态按器形、尺寸、重量或用途区分，材料独立于形态。装备后，自带招式绑定这件法宝，出招时按招式需要读取它的基础攻防。同一个字沿用同一张招式定义，比如刀、剑、双刀共用「斩」。法宝卡自己的激活效果由卡定义。

**占格**只算法宝本卡。2 格形态带 3 招，3 格形态带 4 招。自带招式各自占格，当前装配规则要求全部排进背包，并计入 SP。例如长剑本卡占 2 格，如果「斩、刺、格」各占 1 格，整套共占 5 格、用 5 SP。「格」是主动截开来招，「挡」是稳住承住来招。

攻防是首版试配值。短剑、长剑、重剑的占格和攻防沿用现有短剑、长剑、巨剑的数据，其余数值按这三把剑的量级起草。

震为足，靴归震。巽为股，腿甲归巽，表中的腿甲主要护大腿。

坤取躯体与性命本源。镜、印、鼎是炼入体内温养、与自身性命相合的本命法宝。法身是修士以自身躯体为根基温养而成的形态。

## 共用招式效果（首版草案）

<武器>指这张招式绑定的装备，包括盾、甲、靴等。<攻击>和<防御>取出招时的生效值。各行的 X 单独调。卡面只写招式自身的效果，Keyword 和基础对拼的结算见[拼点规则](../../openspec/changes/defense-contests-and-card-shapes/specs/combat-contest-scheduling/spec.md)。

| 招式 | 出手类型 | 卡面效果 |
| --- | --- | --- |
| 斩 | 斩击 | 按<武器><攻击>发起斩击 |
| 刺 | 刺击 | 按<武器><攻击>发起刺击 |
| 打 | 打击 | 按<武器><攻击>发起打击 |
| 射 | 射击 | 按<武器><攻击>发起射击 |
| 格 | 格 | 按<武器><防御>格开来招 |
| 挡 | 挡 | 按<武器><防御>抵挡来招 |
| 闪 | 闪避 | 按<武器><防御>闪避来招 |
| 扫 | 斩击 | 按<武器><攻击>发起斩击，对上闪避时本招拼点加 X |
| 撩 | 斩击 | 按<武器><攻击>发起斩击，拼赢后己方下一次刺击拼点加 X |
| 挑 | 刺击 | 按<武器><攻击>发起刺击，对上打击时本招拼点加 X |
| 砸 | 打击 | 按<武器><攻击>发起打击，拼赢或直击时，在结算伤害前打掉敌方至多 X 点灵盾 |
| 钩 | 斩击 | 按<武器><攻击>发起斩击，拼赢后敌方下一次防御拼点减 X |
| 推 | 打击 | 按<武器><防御>发起打击 |
| 点 | 辅助 | 敌方下一次攻击拼点减 X |
| 抛 | 射击 | 按<武器><攻击>发起射击，对上格或挡时本招拼点加 X |
| 掷 | 射击 | 按<武器><攻击>发起射击，轮末直击时本次基础伤害加 X |
| 瞄 | 辅助 | 己方下一次射击拼点加 X |
| 连 | 射击 | 按<武器><攻击>发起射击，若本轮这件<武器>已发动过「掷」，本招拼点加 X |
| 截 | 格 | 按<武器><防御>格开来招，对上射击时本招拼点加 X |
| 撑 | 辅助 | 获得等同于<武器><防御>的坚甲 |
| 卸 | 辅助 | 获得等同于<武器><防御>的卸力 |
| 转 | 辅助 | 己方背包扫描立即前进 X 个基准 Tick |

辅助招式照常消耗本行发动机会，发动时直接生效。

飞刀可以把「瞄」排在「掷」前一行，让投掷吃到加成。飞镖则适合把「掷」排在「连」前一行，两张牌各自蓄灵、各自出手。调数值时要留意软靴，按表中 0 攻试配，它的「打」起手也是 0 点。
