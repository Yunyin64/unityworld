# 武修装备表

## 装备与装配

每种装备形态带一组固定招式。同一个字共用一张卡牌定义，每张招式卡绑定提供它的那件装备。比如短剑和长刀都带「斩」，短剑的「斩」读短剑的攻击，长刀的「斩」读长刀的攻击。法宝本卡的激活效果由法宝卡自己定义。

**常规装备的自带招式数量 = 法宝本卡的 Size + 1。** Size 为 1、2、3 的常规装备分别带 2、3、4 招。法身是特例，本卡 Size 为 1，固定带「运、打、格、挡、闪」五招。表中每个「口」代表一个待定招式位，「口、口」就是还有两招待定。

装配时，法宝本卡和每张自带招式都要排进背包，各按自己的占格计入 SP。例如长剑本卡占 2 格，带「斩、刺、格」三招。若三招各占 1 格，整套占 5 格，用 5 SP。

## 共用招式

<武器>指招式绑定的装备，包括盾、甲、靴等。<攻击>、<防御>和<速度>按效果生效时读取。卡面只写本卡的动作和效果。Keyword 与基础对拼的结算见[拼点规则](../../openspec/changes/defense-contests-and-card-shapes/specs/combat-contest-scheduling/spec.md)。

### 克制招式

这六招各克一种出手类型。实际对拼时，碰上克制目标就读取<武器>当时的<速度>，加到本招拼点上再比胜负。出招后、对拼前的装备速度变化也会影响这次加成。对上射击时，六招都按原有点数比拼。

## 试配数值怎么读

基础攻击招读攻击，基础防守招读防御。克制招碰上对应类型时再加速度。蓄、振、点、瞄先花一次发动机会，各给下一次对应攻击加上与速度等量的拼点。若先强化，再用同类型的克制招对上目标，这一次既吃强化也吃克制。配重兵时要同时看平时出手和这个组合能打到的点数。

尺寸决定整套构筑的成本。若每招各占 1 格，Size 1、2、3 的常规装备整套依次用 3、5、7 SP，法身用 6 SP。按人物起步 20 HP、10 SP 试配，重型武器的常态攻击给 6～7，速度给 1～2。重甲则把主值给防御，「推」也能把这份防御打出去。[人物数值基准](../战斗/TCA工作区/资料/数值设计原则.md)

| 看哪一组 | 只算本件装备、一次强化时的表现 |
| --- | --- |
| 大刀与重剑 | 大刀直接斩是 7，先蓄再斩是 8，挡是 3。重剑直接斩是 6，先蓄再斩也是 8，格是 5。大刀值在第一刀，重剑能接更重的来招。 |
| 双刀与双钩 | 双刀先点再刺是 4 + 3 = 7。双钩先点再钩，通常是 3 + 3 = 6，钩到格再加 3，达到 9。若对手是长剑的 4 点格，基础伤害取胜差 5。 |
| 大锤与大斧 | 大锤先振再砸，对上斩击是 6 + 2 + 2 = 10。大斧先蓄再劈，对上挡是 7 + 1 + 1 = 9。两件只出基础招时，大锤打 6，大斧斩 7。 |
| 矛与长枪 | 矛平刺 4、挑到打击是 7，自带 4 点格。长枪平刺 6、先点再刺是 8，格降到 3，整套多占 2 SP。 |
| 重甲与软靴 | 重甲用防发「推」是 6，用攻发「打」是 4。软靴用防发「闪」是 4，用攻发「打」是 2，两件的攻防都有对应招式。 |

短刀和短剑在这版同为 4 攻。两件尺寸相同、都只有「斩、刺」，单看自带招式确实打出相同点数。
