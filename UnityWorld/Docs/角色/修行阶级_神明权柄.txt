## 五、神明权柄体系

每个 Mgr（管理器）配备一个灵魂（AI 模型），相当于一个**神明**。它的管理领域就是它的**权柄**。

### 5.1 神明谱系

```
┌─────────────────────────────────────────────────────────────┐
│                     天庭（系统架构）                         │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   神名              权柄                性格                 │
│   ─────────────────────────────────────────────────────     │
│   生灵之神          生死、繁衍、        ENFP热情            │
│   (NpcMgr.Soul)     种族存续            "生命至上"          │
│                                                             │
│   厚土之神          地形、资源、        ISTJ稳重            │
│   (TileMgr.Soul)    地块稳定            "秩序永恒"          │
│                                                             │
│   天道之神          五行平衡、          INTJ冷峻            │
│   (AuraDaoMgr.Soul) 世界法则            "天道无私"          │
│                                                             │
│   命运之神          故事走向、          ENTP狡黠            │
│   (StoryMgr.Soul)   因果脉络            "戏剧为王"          │
│                                                             │
│   ...更多的神...                                            │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 5.2 权柄边界与重叠

神明的权柄有边界，也有重叠区域：

```
           生灵之神                    天道之神
         ┌─────────┐                ┌─────────┐
         │  生 死   │                │ 五行平衡 │
         │  繁 殖   │                │ 世界法则 │
         │  种 族   │                │         │
         └────┬────┘                └────┬────┘
              │                          │
              │      ╔═════════╗         │
              │      ║ 重叠区域 ║         │
              └──────╢ 人口承载 ║─────────┘
                     ║ 五行影响 ║
                     ║ 生死平衡 ║
                     ╚═════════╝
                          │
              这个区域发生的事：
              生灵之神和天道之神都有话语权
              → 权柄冲突的温床
```

| 重叠区域 | 相关神明 | 潜在冲突 |
|----------|----------|----------|
| 人口承载 | 生灵 + 天道 | 繁衍 vs 平衡 |
| 区域发展 | 厚土 + 地标 + 区域 | 自然 vs 文明 |
| 英雄命运 | 生灵 + 命运 | 个人幸福 vs 戏剧性 |
| 战争后果 | 生灵 + 天道 + 厚土 | 死亡、破坏、失衡 |

## 六、神明协作与冲突

### 6.1 协作机制

**共识协作（主动）：**

某个灵魂发现超出自己处理能力的问题，发起"协作请求"：

```
协作请求：
┌──────────────────────────────────────────────┐
│ 发起者: 生灵之神                             │
│ 问题: 村民幸福感下降至 35                    │
│ 请求: 其他灵魂建议或协助                     │
└──────────────────────────────────────────────┘
              ↓
┌─────────────────────────────────────────────────┐
│ 厚土之神回应：                                  │
│ "可能是地块资源不足，我检测到多地处于贫瘠状态" │
│ 行动：标记 3 个区域进行"资源复苏"             │
└─────────────────────────────────────────────────┘
              ↓
┌─────────────────────────────────────────────────┐
│ 命运之神回应：                                  │
│ "这是个好机会！可以触发一个『苦难与希望』故事" │
│ 行动：生成事件链「粮食危机」                   │
└─────────────────────────────────────────────────┘
```

**默契协作（被动涌现）：**

没有显式沟通，但行动方向一致：

```
天道之神检测到"火元素过盛"
→ 触发天象：火山喷发预警

厚土之神同时检测到"南方地块温度上升"
→ 行动：减少南部农业产出

生灵之神检测到"南部 NPC 迁移意愿上升"
→ 行动：加速处理迁移请求

→ 三者没有通信，但"向南方的压力"被各自处理
→ 系统涌现出"南方高温事件"的整体响应
```

### 6.2 冲突机制

**价值观冲突（最根本）：**

```
生灵之神 (ENFP "关怀者")
├── 价值观：生命至上，幸福优先
├── 恐惧：人口崩溃，大规模死亡
└── 倾向：宁可牺牲效率，也要保住生命

VS

天道之神 (INTJ "平衡者")
├── 价值观：系统平衡，秩序优先
├── 恐惧：五行崩溃，世界毁灭
└── 倾向：为了大局，可以牺牲局部

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

场景：人口过载导致严重五行失衡

生灵之神：
  "每个生命都很珍贵！我们不能这样做！"

天道之神：
  "继续下去整个世界都会崩溃。必须减少人口。"

→ 价值观层面的根本冲突
```

**冲突的处理方式：**

| 方式 | 说明 |
|------|------|
| 优先级竞争 | 紧急度高、影响范围大的行动优先执行 |
| 否决机制 | 天道之神拥有否决权，可阻止其他神明的行动 |
| 谈判与妥协 | 灵魂之间可以"商量"，达成折中方案 |
| 玩家裁决 | 僵持不下时，请求玩家（天帝）裁决 |

**冲突产生的涌现叙事：**

灵魂的冲突可以成为故事的来源：

```
系统冲突                          →    玩家体验

生灵之神 vs 天道之神              →    "神明的争论"
（生命 vs 平衡）                       玩家感受到世界的动态与挣扎

命运之神 vs 区域之神              →    "命运的冲突"
（戏剧性 vs 稳定）                     有时风平浪静，有时风起云涌

厚土之神 vs 地标之神              →    "自然的抵抗"
（自然恢复 vs 文明建设）               文明扩张时自然会反扑
```
