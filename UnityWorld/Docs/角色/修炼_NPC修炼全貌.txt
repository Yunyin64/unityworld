### 5.2 凡人与修士

- 凡人在这个世界中存在，但不会出现在 NPC 列表中
- 游戏中需要的 500 个 NPC 全部是修士
- 不需要关心"凡人如何踏入修行的流程"

### 5.3 修炼生命周期

```
NPC 诞生（已是修士）
    │
    ▼
选择核心功法 → 确定道途
    │
    ▼
修炼功法（每 Tick 积累修炼点数）
    │
    ├─ 到达节点阈值 → 解锁 Card / BehaviorCard / Modifier / Story
    │
    └─ 同步积累境界进度
         │
         ▼
    境界进度达到阈值 → 突破到下一境界
         │
         ▼
    继续修炼 / 更换功法 / ...
```

### 5.4 未来扩展（本次不实现）

- 修炼速度计算（受 Tile 元气、天赋 Trait 等影响）
- 突破机制（概率、条件、突破事件）
- NPC AI 决策"当前修行功法"
- CoreEffect 的运行时执行
- Tag 驱动的功法生成
- **实战水平系统**：NPC 通过模拟推演优化卡组构建
  - 生成 K 种随机卡组方案
  - 每种方案与"标准模型"虚拟 NPC 对战 N 轮
  - 选战斗表现最优的方案作为 BattleDeck
  - K × N = SimulationDepth，是 NPC 属性，代表推演能力/战斗智慧
  - 推演次数越多，NPC 本质上战力越强——这是修为的体现
  - 战斗是离线模拟（同步跑完），架构上天然支持多次模拟
  - 本次不实现，当前使用随机选卡策略

## 七、系统决策记录

| 决策 | 结论 | 理由 |
|------|------|------|
| 道途用枚举还是 Define？ | 枚举（10 个值） | 数量已确定，不需要数据驱动扩展 |
| 境界共用还是道途独立？ | 每道途独立序列 | 更有沉浸感，不同道途讲述不同的成长故事 |
| 境界进度与功法的关系 | 独立核算，修炼功法时同步积累 | 允许多本功法共同推进境界，但不等价 |
| 功法来源 | 手配 + Tag 生成（未来） | 手配是经典传承，生成是语义涌现 |
| NPC 能否装备跨道途功法 | 默认只能同类型 | 其他跨道途玩法留给未来 |
| 完整度对体验的影响 | NPC 优先选高完整度功法 | 低完整度功法可能导致空窗期，体验差 |
| 凡人是否入 NPC 列表 | 不入 | 500 个 NPC 全部是修士 |
