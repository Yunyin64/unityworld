## 四、操作模式的演变

### 4.1 练气期：角色扮演

```
操作：控制单个角色，每 Tick 选择一个行动
├── 修炼 / 探索 / 采集 / 休息
└── 只能做"凡人能做的事"

界面：沉浸式视角，以自己为中心的周围环境
风格：类似传统 RPG
```

### 4.2 筑基期：角色扮演 + 卡组构建

```
操作：控制单个角色，但有更多选项
├── 战斗卡组系统
├── 社交系统（结交、维护关系）
└── 探索更远的地方

界面：沉浸式视角 + 卡组界面
```

### 4.3 金丹期：角色扮演 + 势力管理

```
操作：双轨制
├── 角色模式：仍然可以四处移动、探索
└── 管理模式：打开管理界面，处理势力事务

管理界面：
├── 势力地图（自己的地盘）
├── 下属列表
├── 资源调配
├── 任务分配
└── 建设规划
```

### 4.4 元婴期：战略视角 + 天庭参与

```
操作：全局战略
├── 整个世界地图可见
├── 可以"跳转"到任何位置
├── 可以发布"天道任务"给天下修士
└── 参与天庭议事，影响世界走向

界面：大地图战略视角
├── 整个世界地图
├── 势力动态
├── 事件流
├── 天庭议事厅
└── 自己的"道"推行进度
```

### 4.5 化神期：上帝视角

```
操作：棋盘下棋
├── 不再控制具体角色
├── 直接操作世界参数
├── 触发事件
├── 与其他神明协作/对抗
└── 以自己的意志影响世界

界面：看海模式
├── 世界全景
├── 数据仪表盘（所有快照）
├── 神明交互界面
├── 事件编辑器
└── 因果可视化
```
