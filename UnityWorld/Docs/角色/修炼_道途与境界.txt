## 一、设计哲学

### 1.1 世界观前提

这个游戏没有"玩家"，没有"主角"。所谓的玩家，只是获得了其中一个 NPC 的 AI 操纵权。

修士感知到了天地元气，于是出现了道途。修炼不是"经验条涨满升级"，修炼是一个生命体与世界的元气之间建立了某种关系。这种关系的不同，就是道途的不同。

### 1.2 三大体验闭环

叙事体验 → 创造体验 → 战斗体验 → 回到叙事体验

叙事证明创造，创造证明战斗，战斗证明叙事。三者缺一不可。

### 1.3 六种快乐

玩法要拥有六种快乐的手段：
1. 对知识的向外推衍：构建知识体系、计算优解与模型（深度的数值与 Build）
2. 对知识的向内获取：获得未知之物、体验未有之体验、生理快乐体验
3. 对物质世界的向外征服：建设世界创造产品、预知并改变未来（玩家对游戏世界的影响）
4. 对物质世界的向内控制：机械劳动、控制肉体（操作手感）
5. 对关系感情的向内接受：权力阶级关系、享受别人的服务、控制他人（强大带来的阶级体现）
6. 对关系感情的向外付出：满足道德、奉献、爱别人（社交、无限新的剧情与人物）

## 二、道途体系

### 2.1 道途总览

每个道途都是对同一个问题的不同回答——"你打算怎么和这个世界的力量相处？"

道修、脉修、异修等道途保留在世界观总览中。当今游戏主体是武修、灵修、魂修；上古三道与当今三法描述的是这次修行方法演变的主线。

```
                    天 地 元 气
                    ╱    │    ╲
                元气方向  肉体方向  灵魂方向
              ─────────  ─────────  ─────────
              灵修(存储)  武修(淬炼)  魂修(借物)
              仙修(引导)  脉修(共鸣)  神修(聚识)
              道修(改写)  荒修(融合)  异修(不可定义)
```

**元气方向——与元气的关系**

- 灵修：融灵入体，将灵气炼为灵元，修法术、神通与灵力。纳气炼元降低了对悟性与气感的要求
- 仙修：不存储元气，直接引导天地之力改造世界。最早的仙人们是道修中比较低级的人，运用"代码"做事。道修和仙修都没有固有元气，只是引导和使用
- 道修：看见了世界运行的规则本身（代码），甚至可以改写它。最开始只有道修。道修本质上可能是异修的一种

**肉体方向——与身体的关系**

- 武修：西方天朝开武道逆命之法。辨物定卦，纳五行之气淬炼，修技击、兵甲与体魄。人类从荒修遗留的思想中摸索出用灵气打磨身体的方法
- 脉修：激发远古血脉之力，模仿妖族，用自然进化的特征共鸣天地。温和的仙人们开智远古动物而来。妖荒之战后成为主流，但进入垄断
- 荒修：直接融合自然中的无生命物质（矿石、土地），让自己与天地合为一体。激进的仙人所创，妖荒之战后逐渐退出历史舞台

**灵魂方向——与意识的关系**

- 魂修：以外物为大，以物之性补自身之命，借丹药、法宝与本命之物补全性命，体悟神识、通晓命格，逆向构筑香火之道
- 神修：正神收香火、提炼正面意志，邪神收魂魄、提炼负面意志，皆化用万灵神识，以巨大神识掌御天地、洞察命格因果。旧稿关于神仙之战和神道断绝的说法，见第四节待衔接事项
- 异修：与道修从一开始就存在的神秘修行。每个异修都有独一无二的能力（如看见天道的底层代码），是气运系统之外的存在

**当前游戏主体：武修、灵修、魂修**（最常见的三种道途）

上古以荒修、仙修、神修为三道。当今武修、灵修、魂修三法兴起，沿着体魄、灵气、神魂三个方向，发展出更方便传授、对资质要求更低的修行方法，于是修道大兴。

三法分别侧重法身、法力、法术，对应地、天、人，对应精、气、神，最终都走向全性全命。落到游戏中，三道共用 HP、MP、SP 三个属性，分别保留招式对拼、灵元运转与释放、card 位置摆放与调配的玩法侧重。

### 2.2 上古三道

#### 荒修

荒修靠体魄吞噬天地，以强大的身体承受、吞纳天地之力。体魄是这条古道的重要门槛。

#### 仙修

古代仙道讲究感悟天地灵气，以悟性明悟天地流转。修士体内没有灵气，状似凡人，却能顺应外在天地间的灵气，在动态之间释放大神通、法术。

这条道路对悟性与气感要求很高。修为体现在对天地流转的理解，以及引动外气的能力上。

#### 神修

古代神修分为正神与邪神，两者都化用万灵之神识来掌御天地。

| 类别 | 收集之物 | 提炼之物 |
| --- | --- | --- |
| 正神 | 香火 | 正面的意志 |
| 邪神 | 魂魄 | 负面的意志 |

两类神修最后都以巨大神识为根本，洞察万物的命格与因果，并以香火、神魂干涉命运。

### 2.3 当今三法的兴起

当今三法逐渐降低了修行对先天体魄、悟性等资质的依赖，让更多人能够入道。资质仍会影响修行，但修士有了更明确、方便传授和逐步练习的方法。

#### 武修

西方天朝开武道逆命之法，传于天下。

武修尊物性之变，合八卦之位。万物本体乃至人身部位，都可以归入卦象，纳天地五行之气加以淬炼。修士由此修技击、修兵甲、修体魄。

与上古荒修依靠体魄吞噬天地的方式相比，武道发展出了辨物、定卦、纳气淬炼与技击相结合的修行方法。

#### 灵修

灵尊践行灵修之道，成就元婴，向天下宣告：非仙道亦可登仙。

天地之气被灵修一脉分为五气，五行之说由此确立。灵修尊五行，修法术、修神通、修灵力。

上古仙修顺应外在灵气，当今的纳气修法则融灵入体，将灵气炼化为灵元，再以灵元催动法术、法宝。吸纳、炼化与运用可以逐步练习，对悟性与气感的要求因此大幅降低。

这里需要区分两种状态：天地间充盈的是游离的灵气；修士纳气入体后，炼化为自身可以运用的灵元。

#### 魂修

魂修继承古代神道传承，推陈出新，讲究以外物为大，补全自身性命。

魂修结合武修的兵甲，纳五行之气，辅以古代丹、器、符、阵之道，以神魂驾驭外物。食用丹药、运用法宝、构筑本命之物，都是修行的组成部分。其根本是：以物之性补自身之命，体悟神识之本，通晓万物之命格，逆向构筑香火之道。

古代神修化用万灵神识，汇聚庞大神识，再洞察万物命格因果。魂修从借物补全自身性命入手，体悟神识、通晓命格，最终与古代神修殊途同归。

#### 古今修法对照

| 修行方向 | 上古三道 | 当今三法 |
| --- | --- | --- |
| 体魄 | 荒修靠体魄吞噬天地 | 武修辨物定卦，纳五行淬炼，修技击、兵甲与体魄 |
| 灵气 | 仙修以悟性明悟天地流转，引动外在灵气 | 灵修融灵入体，炼化灵元，催动法术与法宝 |
| 神魂 | 神修化用万灵神识，以巨大神识洞察命格因果 | 魂修借外物补全性命，体悟神识，通晓万物命格 |

### 2.4 天地人与八卦五行

天为至高之障壁。天地之间，充盈着游离的灵气。

五行之说在天位，用来分辨天地之气。八卦之说在地位，用来给有形之物分类、定其行位。人位与神识、性命及命格的修行相应。

#### 八卦与地位

每个“物”都有属于自己的八卦位。物可以是兵器、材料，也可以是身体部位；只要有实体存在，就有“地”之行位。

武学兵器与相关门类的八卦归属如下：

| 卦 | 对应的实体与武学门类 | 所取之义 |
| --- | --- | --- |
| 乾 | 刀、剑 | 刚、正 |
| 坤 | 躯体 | 本、源 |
| 坎 | 弓、盾 | 险、藏 |
| 离 | 甲、戈、枪 | 丽 |
| 兑 | 双持、医毒 | 折毁、口舌 |
| 艮 | 拳、掌 | 阻止、山守 |
| 震 | 重兵、腿法 | 决躁、足下 |
| 巽 | 身法、投掷 | 进退、奇风 |

物的分类与围绕物形成的武学门类，在这套卦象体系中相互关联。具体兵器、材料、部位的归属，需要落到具体的物上。

#### 五行与天位

五行是金、木、水、火、土，对应天地之气的五种分类。灵修一脉将天地之气分为五气，形成尊五行的修行体系。

三法都会接触五行之气：武修纳气淬炼实体，灵修纳气炼化灵元，魂修纳气并结合丹器符阵之道炼制、运用外物。

八卦说明物的地之行位，五行说明气的天位分类。二者共同参与修行，例如一柄归乾的剑，可以成为纳五行之气淬炼的对象。

### 2.5 精气神与三根基

三法的对应关系如下：

| 当今道途 | 天地人 | 精气神 | 着重修成的根基 |
| --- | --- | --- | --- |
| 武修 | 地 | 精 | 法身 |
| 灵修 | 天 | 气 | 法力 |
| 魂修 | 人 | 神 | 法术 |

这组关系说明三道的修行重心。武修从实体、体魄与技击入手，灵修从灵气与灵元入手，魂修从外物、神识与性命入手。

法术仍然是灵修所修的内容，法宝也会由灵修催动；魂修同样涉及兵甲、五行之气和有形之物。三根基的对应与这些具体修行内容可以同时成立。

### 2.6 游戏中的共用属性与玩法侧重

#### HP MP SP 的关系

神识为运用手段，灵元为资源，体魄为可承受的伤害，分别对应 SP、MP、HP。精气神落到这三个属性上，关系如下：

| 精气神 | 世界观中的对应 | 游戏属性 | 基本作用 |
| --- | --- | --- | --- |
| 精 | 体魄 | HP | 表示可承受伤害的能力 |
| 气 | 灵元 | MP | 表示可供调用的资源 |
| 神 | 神识 | SP | 对应运用、驾驭与调度力量的手段 |

武修、灵修、魂修的根本机制一样，都需要这三个属性。每名修士都需要体魄承受伤害、灵元提供资源、神识运用手段。具体行动如何调用这些属性，由相应机制与 card 规则决定。

现有战斗实现中，HP 是伤害缓冲，清零后产生伤势；神识所支撑的 SP 体现为可承担的卡牌总 Size 上限。MP 是资源储备，消耗后生成背包格上的五行灵元（Mana），灵元再经扫描分配给卡牌。SP 上限与背包有效格数分别约束驾驭能力和物理容量，设计数据要求 SP 上限不超过有效格数。

卡牌位置、扫描与灵元分配是三道共用的底层机制。魂修尤其重视位置与调配；三道的侧重落实在构筑与卡牌规则中，战斗中是否允许手动调配需要另定。

#### 三道各自的玩法侧重

| 道途 | 重点经营的机制 | 玩家主要考虑的问题 |
| --- | --- | --- |
| 武修 | 招式的对拼机制与数值 | 选什么招式参与对拼，规则如何结算，数值能否占优 |
| 灵修 | 灵元的运转与释放 | 灵元如何运转，什么时候释放，以什么方式形成效果 |
| 魂修 | 每张 card 的位置摆放与调配 | card 放在哪里，什么时候调整，怎样安排和调配 |

三道共享属性和底层战斗规则，各自把玩家的注意力引向不同的选择。设计道途特色时，要保留这些机制上的侧重，让不同道途在操作与构筑上形成差异。

#### 数值例子

假设三名修士的面板相同，都是 100 HP、60 MP、20 SP。这些数字仅用于说明共用属性与玩法侧重的关系。

- 武修重点考虑招式如何对拼，以及对拼数值是否有利。
- 灵修重点考虑如何安排灵元运转与释放。
- 魂修重点考虑各张 card 的位置，以及何时进行调配。

相同的三个属性，仍然可以支撑不同的战斗决策。道途特色需要落实到各自的机制与 card 规则中。

### 2.7 共同归途 全性全命

武修、灵修、魂修各有入手之处，分别侧重精、气、神与法身、法力、法术，最终都会走入全性全命的通途。

三法降低了入道的门槛，让修道能够广传天下；随着修行深入，三道共同追求自身性命的完整。

### 2.8 道途的核心感觉差异

每条道途的境界讲述不同的成长故事：

- 武修的境界感觉：每一步都是肉体的蜕变，很具体，很痛。"锻体→铜皮→铁骨"
- 灵修的境界感觉：每一步都是内在空间的构建，很抽象，很安静。"练气→筑基→金丹"
- 魂修的境界感觉：每一步都是意识边界的扩展，很诡异，很自由。"感知→御物→分魂"

### 2.9 道途技术说明

- 当前道途枚举 PracticePath 共 4 个值：None（凡人）、Wu（武修）、Ling（灵修）、Hun（魂修）。世界观总览中的其余道途尚未列入这个枚举
- 道途不需要额外的数据定义（Define），枚举即够用

## 三、境界系统

### 3.1 核心概念

境界不是等级条。境界是你和世界的关系深化到了一个新的层次，你对这种关系的理解产生了质变。

每个道途拥有独立的境界序列。不同道途的相同 Level 不要求名称或数值对齐。

### 3.2 境界与功法的关系

境界是独立的进度系统，修炼功法时同步积累境界进度。两者独立核算。

一般情况下，一本同级功法的修炼点数足以覆盖对应境界所需的进度。例如：
- 练气期需要 500 境界进度，一本练气级功法就有 500 修炼点
- 筑基期需要 3000 境界进度，一本筑基级功法就有 3000 修炼点
- 金丹期需要 12000 境界进度，一本金丹级功法就有 12000 修炼点

### 3.3 境界定义数据

每条境界定义包含：
- ID / DisplayName：唯一标识和显示名
- Type：所属道途类型
- Level：同一道途内的境界先后顺序（1 = 最低境界）
- ProgressRequired：从上一境界突破到此境界所需的境界进度总量
- LifespanBonus：突破到此境界后获得的额外寿元加成
- Tags：与 Tag 系统关联的标签

示例：
```
灵修：练气(Level 1, 500点) → 筑基(Level 2, 3000点) → 金丹(Level 3, 12000点)
武修：锻体(Level 1, 500点) → 铜皮(Level 2, 3000点) → 铁骨(Level 3, 12000点)
魂修：感知(Level 1, 500点) → 御物(Level 2, 3000点) → 分魂(Level 3, 12000点)
```

### 3.4 境界技术说明

- 境界定义使用 RealmDefine（继承 DefineBase），从 RealmDefines.json 加载
- RealmDefineMgr 提供按道途、按等级的查询能力
- NPC 的境界进度存在运行时数据中（由 CultivationMgr 管理），不在 NpcBioData 上

## 四、旧设定衔接与实现核对

以下核对记录以 2026-11-11 的文档、属性配置与战斗代码为依据。世界观补充与实现现状分别记录，待定事项保留待定。

| 事项 | 核对结果 | 衔接方式 |
| --- | --- | --- |
| 魂修偏辅助生产、不温不火 | 旧描述已不足以表达当今三法之一的定位 | 更新为借物补命、体悟神识、通晓命格；保留丹器符阵与御物作为修行内容 |
| 神仙之战后所有神明死亡、神道断绝 | 与古神传承如何延续到魂修之间，缺少历史说明 | 作为旧稿待衔接背景保留。需要区分古神死亡、旧组织消亡、修行方法失传各自的范围 |
| 上古三道与九大道途 | 可以并存，分别描述古今演变主线与更广的道途总览 | 保留道修、脉修、异修等背景；当前可用道途以实际枚举为准 |
| 道途枚举为 None 加九道 | 与当前代码不符，实际为 None、Wu、Ling、Hun | 已修正本篇技术说明 |
| HP 由体魄决定 | 世界观用体魄概括承伤能力；当前基础配置为 HpMax = QiXue × 2，TiPo 是另一个属性字段 | 保留世界观对应，具体字段是否调整另定 |
| SP 为 5 加意调整值、按 Cost 统计 | 当前基础配置为 SpMax = ShenShi，占用按运转池中卡牌 Size 汇总 | 按当前实现解释神识的驾驭能力；旧功法与战斗文档中的公式和 Cost 表述需要更新 |
| MP 转化到无位置灵元池、卡牌独立 CD 发动 | 早期机制已被格上灵元与背包扫描取代；当前为开场及本方轮末补灵 | 本篇使用当前机制解释资源和布局；旧战斗文档不能直接作为现行实现说明 |
| 三道玩法侧重与共同底层 | 位置、资源、对拼都可以参与三道战斗，三道共享 HP、MP、SP | 保留不同道途的玩法重心；战斗中手动调配的权限与时机另定 |
| 八卦分类与八维人物属性 | 当前八维属性与物的八卦分类属于不同层面的概念 | 保留现有属性，八卦如何关联具体属性尚未规定 |
| 神修之神与天庭管理器之神 | 旧修行阶级文档还把管理器及其权柄称为神明，与古代神修的关系未定 | 名称暂分别按各自语境使用，需要补足关系后再统一历史 |

按当前基础配置举例：气血为 10 时，HP 基础上限为 20；神识为 12 时，SP 基础上限为 12。这些是现有配置的例子，具体还受修正项影响。世界观中体魄与 HP 的对应，尚未决定是否改变 QiXue 和 TiPo 两个字段的分工。
