# 地图系统设计文档
### 世界的空间语言

> *"世界不是一张画，而是一套规律。地形是语法，区域是段落，地标是诗眼。"*

---

## 一、核心理念

地图系统的目标，不是提供一张好看的地形图，而是构建一个**有意义的空间世界**。

每一块地（Tile）都不只是贴图，它有五行浓度、地形类型、归属区域、地标存在。
这些属性共同决定了：
- 这里会发生什么事件
- NPC在这里会有什么遭遇
- 修士在这里修炼会得到什么加成
- 这片土地在叙事上意味着什么

**一句话原则：先有世界，再有生命。玩家来之前，世界已经是完整的。**

---

## 二、世界的空间层次

世界由四个层次构成，从大到小：

```
位面 Plane
  │  一张独立的空间地图（主世界 / 小世界秘境等）
  │  由大量区域拼合而成，边缝由无主地块平滑过渡
  │
  └── 区域 Region
        │  有叙事意义的连片地块集合（如"东荒火山带"、"北冥冰原"）
        │  占据一个长方形范围，内部有自己的地形分布和地标
        │
        └── 地块 Tile
              │  六边形网格的最小空间单元
              │  持有：地形类型、五行浓度、所属区域、所在地标
              │
              └── 地标 LandMark
                    地块上的特殊存在（自然奇观或后天建筑）
                    会改变地块的五行浓度，也是叙事事件的触发地点
```

---

## 三、地块（Tile）能有什么

每一块地包含以下信息：

```
Tile（地块）
  ├── 坐标          唯一标识这块地在世界上的位置
  ├── 地形类型      平原 / 丘陵 / 山地 / 河湖 / 海洋 / 荒漠 / 森林
  ├── 五行浓度      金 / 木 / 水 / 火 / 土 各自的浓度值（可动态变化）
  ├── 所属区域      这块地归哪个 Region 管（可以没有，则是"无主之地"）
  ├── 所在地标      这块地上有什么地标或建筑（可以没有）
  └── 修正源列表    当前作用于这块地的所有元气修正（地标、NPC、事件等）
```

**五行浓度的变化原理：**
每块地有一个「目标浓度」，系统会以一定速度让实际浓度向目标靠拢。
目标浓度 = 基础地形浓度 + 各类修正源的叠加。
这样设计的好处是：浓度变化是平滑的，不会瞬间突变。

---

## 四、地形类型（基础地形）

地形类型是地块最基础的属性，决定了这块地的**自然五行倾向**：

| 地形类型 | 五行倾向 | 叙事气质 |
|--------|--------|--------|
| 平原   | 均衡    | 适宜耕作，门派建立的首选 |
| 丘陵   | 土偏高  | 稳固，适合修建坚固建筑 |
| 山地   | 金偏高  | 矿脉丰富，多险峻宗门 |
| 河湖   | 水偏高  | 灵气流动，水系修士聚集 |
| 海洋   | 水极高  | 深不可测，危险与机缘并存 |
| 荒漠   | 火偏高  | 极端炙热，炼丹圣地或死亡之地 |
| 森林   | 木偏高  | 生机旺盛，脉修与妖族栖息 |

基础地形在世界生成时由噪声算法决定，保证分布自然连续。
地形类型是**固定的枚举**，不可由策划自由扩展（因为算法需要感知它们）。

---

## 五、拓展地形（ExtraTerrainDefine）

基础地形描述"这里是什么地貌"，但有些地方需要额外的**叙事标签**，
比如"这片山地是火山地带"、"这片平原是灵脉密集区"。

这类标签由策划自由配置，叫做**拓展地形**：

```
拓展地形定义（ExtraTerrainDefine）
  ├── ID            唯一标识（如 "volcanic_zone"）
  ├── 显示名称      如"火山地带"
  └── 描述          如"大地熔岩奔涌，火属性浓度极高"
```

拓展地形不参与地形生成算法，只作为**语义标签**使用：
- 事件系统可以说"只在火山地带触发此事件"
- NPC可以说"我讨厌火山地带"（通过Trait匹配）
- 地标可以说"只在灵脉密集区生成"

一个区域可以持有多个拓展地形标签。

---

## 六、地标（LandMark）

地标是地块上的特殊存在，分为两类：

```
自然奇观（IsNatural = true）
  例：天火圣柱、北冥冰眼、东荒灵脉、古树王
  ─ 在世界生成时就存在
  ─ 属于"原初世界"的一部分（快照记录自然奇观后的状态）
  ─ 不会消失（除非特殊剧情）

后天建筑（IsNatural = false）
  例：宗门山门、炼丹炉、渡口、驿站
  ─ 由NPC或玩家建造
  ─ 属于"后天改变"（不计入原初快照）
  ─ 可以建造、损毁、升级
```

**地标定义（LandMarkDefine）**告诉系统这种地标是什么、能生成在哪里、对地块有什么影响：

```
地标定义（LandMarkDefine）
  ├── ID / 显示名称 / Tags
  ├── 是否自然奇观    true = 世界原生 / false = 后天建造
  ├── 是否全图唯一    true则全世界只有一个
  ├── 生成权重        影响随机生成概率
  ├── 生成条件        需要什么地形、什么元气浓度才能生成
  └── 元气修正列表    这个地标对所在地块的五行浓度影响
                     （引用 TileModifierDefine 的 ID 列表）
```

**元气修正定义（TileModifierDefine）**是地标影响地块的具体数值配置：

```
元气修正定义（TileModifierDefine）
  ├── ID / 显示名称
  ├── 持续时间        -1 = 永久有效 / >0 = 有限时长（秒）
  └── 元气变化量      金 / 木 / 水 / 火 / 土 各自的修正量
                     （这是"目标偏移量"，不是每秒速率）
```

---

## 七、区域（Region）

区域是地图中**最重要的叙事空间单元**。
一个区域代表一片有名字、有气质、有故事的连续地域。

```
世界区域示例：
  "东荒火山带"  → 荒漠地形、火山地带标签、天火圣柱地标、火属性极高
  "北冥冰原"   → 山地地形、冰封大地标签、北冥冰眼地标、水属性极高
  "中州灵谷"   → 平原地形、灵脉密集标签、古树王地标、五行均衡偏木
```

**区域定义（RegionDefine）**描述这种区域的**生成模板**：

```
区域定义（RegionDefine）
  ├── ID / 显示名称 / Tags
  │
  ├── 【生成规则】
  │     ├── 是否必然生成    true = 世界必有此区域（宿命地点）
  │     ├── 最多生成数量    全图上限
  │     ├── 生成权重        随机生成时的概率权重
  │     └── 生成条件        需要什么环境才能落地
  │
  ├── 【占用大小】
  │     └── 宽 × 高         区域占用的长方形格数
  │              ※ 长方形中不在地形布局内的部分变为"无主默认地块"
  │
  ├── 【地形布局】
  │     └── 相对坐标 → 地形类型
  │         例：中心点右边2格 → 山地
  │             中心点下方3格 → 河湖
  │
  ├── 【拓展地形标签】
  │     └── 区域持有的语义标签列表（如 ["火山地带", "古战场"]）
  │
  ├── 【元气倾向】
  │     └── 整体五行浓度偏向（如 火+50，会叠加到区域内所有地块）
  │
  └── 【地标布局】
        └── 相对坐标 → 地标定义ID
            例：中心点 → "天火圣柱"
                右上方5格 → "熔岩祭台"
```

**区域与地标的优先级规则：**
区域的地标布局是**固定位置配置**，不参与随机竞争。
也就是说，如果区域里配置了"天火圣柱"，它就一定会在那个相对位置生成，
不受地标定义里的生成权重影响。

## 八、世界生成的五个步骤

世界从无到有，按固定顺序生成：

```
第一步：填充空白地块
  创建所有坐标位置的地块，初始状态为"平原、五行均衡"

第二步：基础地形生成
  用噪声算法在地图上分布七种地形类型
  根据地形类型赋予每块地基础的五行浓度偏向
  （山地的金浓度会高于平原，森林的木浓度会高于荒漠）

第三步：区域落地
  先放置所有"必然生成"的宿命区域
  再按权重随机放置其他区域
  每个区域：
    → 占据一个长方形范围，按地形布局覆盖其中地块的地形类型
    → 将区域内地块标记为"属于此区域"
    → 在配置坐标上生成地标

第四步：散布地标
  在没有区域归属的"无主地块"上
  按地标定义的生成条件和权重，随机散布独立地标

第五步：拍摄原初快照
  忽略所有"后天建筑"类地标的影响
  记录此刻的五行浓度状态作为"原初快照"
  （自然奇观已计入原初，后天建筑是对原初的改变）
```

---

## 九、原初快照：世界记忆的锚点

原初快照是世界自然状态的记录，是天道感知失衡的基准。

```
原初快照 = 地形生成 + 自然奇观 之后的五行浓度状态

当前状态 > 原初状态 → 该元素偏多（涌现"去火"类事件）
当前状态 < 原初状态 → 该元素偏少（涌现"补火"类事件）
```

后天建筑（宗门、城市、工坊）会改变当前状态，
天道会感知到这种改变，并通过事件系统做出世界级别的回应。

这就是"**修士改变世界，天道回应修士**"的底层机制。

## 十、策划配置流程

策划工作按以下顺序进行：

```
1. 配置 ExtraTerrainDefine（拓展地形标签）
   → 定义世界上存在哪些特殊地域类型

2. 配置 TileModifierDefine（元气修正模板）
   → 定义各类影响对元气的具体数值

3. 配置 LandMarkDefine（地标定义）
   → 定义世界上存在哪些地标，各自的元气影响和生成规则

4. 配置 RegionDefine（区域定义）
   → 定义世界上存在哪些特色区域
   → 在区域中引用地标，指定固定位置
   → 区域会优先保证其配置的地标能够生成

5. 调整主世界 PlaneDefine 的大小
   → 决定主世界是多少格，影响区域密度
```

---

## 十一、一句话总结

> 地形是基础，区域是叙事，地标是诗眼，五行浓度是血液。
> 策划配置的是"模板"，世界生成的是"命运"，天道感知的是"变化"。
> 玩家改变的，是已经存在了千年的原初平衡。
