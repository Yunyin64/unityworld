# 《山门一脉》立项口径

仙道昌盛，天下仍在发展。玩家扮演宗门意志，注视一名角色建立宗门，通过修身、齐家、治国、平天下不断扩大经营范围。采用轻叙事 SLG，事件提供选择和结果。先读 [总案](01_gdd.md)，细节见 [完整规则](02_core_loop_and_systems.md)、[数值](03_numerics.md)。

## 已明确的方向

- 初期首徒和几名弟子高资质、起手与成长偏固定，约二十四岁筑基。开宗只有中央山门，外围六格从无主开始，额外培养六名筑基分别驻守才能占满一圈。原型仍暂用首徒加前六名招收弟子作为初始班底。
- 一次培养只做一个境界，突破或潜力耗尽就结束。本段结束后返回人物安排界面，下一境界需要单独开启。
- 练气角色须在六十岁以前筑基，达到六十岁仍未筑基则失去这次晋阶希望。练气基础寿命三百岁，多种延寿道具支持长期保留人物。潜力耗尽者可以成为后方人员。
- 常规培养结束后等待本段培养年数对应的现实时间，用户已选定按本段年数计。初调每年一小时，十六至二十四岁培养对应八小时。等待结束才能把结果角色用于经营、领地或下一段培养。
- 前期免等待是复合规则，要共同考虑现实开服时间、金丹出现进程和最多人数。具体阈值、人数口径和金丹范围尚未确定。
- 修身重点是每个弟子的事件、行动和卡牌构筑。齐家重点是培养结束后的后方人物经营。治国包括领地、资源、科技、功法、影响力和人口。平天下面向希望投入更多时间和组织能力的争霸玩家。
- 前期修士战使用固定 NPC。常规培养保留每四年一次同龄同境对局，后期可接入异步快照。真人与 AI 宗门使用相同权限、时长和资源规则。
- 练气局限本格且不能占地，筑基可耗时移动并占无主地，金丹一回合一格并能攻有主地，元婴可以镇守核心城池和奇观。
- 大境界绝对压制，只有同境界的修士进入实际战斗。同境金丹、元婴的领地战把战斗耗时计入现实时间，地权僵持期间下级弟子可以临时占据。城池和奇观还要看金丹战线，守方金丹取胜时可以凭大阵保住据点。

## 本稿补充的方案

| 事项 | 本稿口径 | 状态 |
|---|---|---|
| 免等判定 | 入段时同时检查开服窗口、金丹进程、人数预算，原子记录资格并锁定本段。下一段重新检查 | 提案。阈值、人数归属和金丹看本宗或全服均待定 |
| 等待状态 | 结果锁定后开始计时，同一角色在培养和等待期间占用唯一身份，到时变为可用。各角色等待并行 | 提案，防止同一人同时任职和升级 |
| 时间 | 培养年、现实等待、战略回合分别记录。经营侧自然老化暂定每现实二十四小时一游戏年，等待期年龄冻结 | 后两项为初调。培养操作不会给全世界加岁 |
| 高阶潜力与寿命 | 筑基、金丹、元婴的潜力线和寿命分别配置，元婴突破到化神后仍可参与经营 | 练气六十与三百为用户要求，高阶数字为初调 |
| 后方人事 | 岗位能力、性格偏好、合作关系共同影响任职，单人只占一个持续岗位 | 初调，用短事件和结果反馈表现人物 |
| 科技和功法 | 科技提升产能与培养条件，藏经解锁可选培养内容和战力上限，生效版本在入段时锁定 | 初调 |
| 人口与资质 | 影响力扩大可接触人口，人口增加候选样本，高资质个体有更多被发现的机会 | 初调，保留个人资质本身的分布 |
| 后期争霸 | 联盟、前线和天下要地作为高投入玩法，计分周期与胜负门槛单独设计 | 待定，日常培养经营持续运行 |

平台先沿用现有 Godot 桌面端，中文、鼠标键盘。商业模式、正式战区规模和结算间隔待定。策划配置放在本包 configs，全部标记 initial；它们需要接入与试玩验证。

## 参考方向

| 用户指定的参考 | 本案取用的设计方向 |
|---|---|
| 背包乱斗、大巴扎、杀戮尖塔 | 一段可完整结束的策略培养，事件选择、构筑调整和战斗反馈 |
| CK3 | 人物进入后方后仍有能力、性格、关系和长期任用价值 |
| 钢铁雄心4 | 多地块经营、产能建设、科技、战线、资源与调度 |
| 三国谋定天下、三国志战略版 | 高投入玩家的联盟协作、领土争夺和天下目标 |

参考作品用于定位体验，具体规则按本案设计。《杀戮尖塔》的官方介绍强调卡牌与 roguelike 结合，《CK3》与《钢铁雄心4》分别提供人物王朝、国家大战略的参考背景。[杀戮尖塔](https://store.steampowered.com/app/646570/Slay_the_Spire/) · [CK3](https://store.steampowered.com/app/1158310/Crusader_Kings_III/) · [钢铁雄心4](https://store.steampowered.com/app/394360/Hearts_of_Iron_IV/)
