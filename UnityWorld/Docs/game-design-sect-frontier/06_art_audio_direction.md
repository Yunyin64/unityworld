# 界面、美术与音频

仙道昌盛的背景用成熟的修行器具、多个宗门和完整建筑体现。玩家以宗门意志安排人物与地图，界面优先显示能改变决策的信息，事件使用短文字与物件图标。

| 界面 | 内容与布局 | 首先看清什么 |
| --- | --- | --- |
| 修身 | 背包与事件选择居中，年龄、当前境界、修为、潜力线在侧；战报能定位出招 | 当前构筑、下一次修士战、本段能否继续突破 |
| 入段确认 | 展示本段免等资格、可用功法与科技效果 | 确认后锁定本段资格与效果，下一段重查 |
| 培养结算 | 结果卡列开始年龄、结束年龄、经过年数、突破或潜力耗尽、现实等待剩余时间 | 结果已经锁定，何时可任职、地图行动或进入下一段 |
| 齐家 | 人物名册与岗位并列，选人后展开能力、性格、关系、预期输出与剩余寿命 | 这个人能否上岗，换人会让哪些产出变化 |
| 治国 | 地图与资源、建设、科技、功法收藏并行，显示战略回合进度及候选样本量 | 岗位与研究每回合结算，人口发展扩大候选发现机会 |
| 平天下 | 自选战区与联盟入口，前线、赛季目标、领战与接防人员并列展示 | 参与目标、接防资格、原岗位损益 |

寿命与突破潜力使用独立文字和数值。潜力耗尽的人物保持正常存活头像，按实际状态显示可任职。培养与等待中的人物显示状态标识和剩余时间，培养结果在可用（ready）时显示已应用到宗门。进入下一段培养时，旧岗位展示空缺或接替人，地图按实际在岗者显示。

地图沿用左上方柔光、矿物色地形与墨绿浅铜边界面。己方圆顶旗、中立方纹章、对手缺角旗、无主文字共同区分归属。开宗只给中央一格己方标识，外圈在修士真实到位后逐格变化。[项目探索素材清单](../art/exploration_asset_manifest.md)

| 首批资产（initial） | 验收 |
| --- | --- |
| 功法、木剑式、护身符、青纹草、灰狼图标与两名固定 NPC 头像 | 能认出资源供给与攻击先后，20 岁和 24 岁对手独立 |
| 突破、潜力耗尽、现实等待、可任职四种状态标 | 色觉弱化后仍能读出人物可用状态 |
| 执事、研究、药圃管理、藏经整理岗位图标，能力/性格/关系提示 | 换岗位的输出差异有文字与数值解释 |
| 三种延寿道具、寿命上限变化提示 | 显示延长年数和使用后的寿命上限 |
| 资源建设、科技进度、功法收藏、人口与影响力图标 | 各自能追到影响哪项培养供给或候选变化 |
| 中央山门、资源物件、守将名牌、前线标和元婴镇守印 | 未占地收益 0；攻取、接防、持守分别可查 |

音效用翻页、叩玉、擦鞘与落印反馈具体操作。培养结算和等待完成各用短提示，任职与调任使用轻点击，延寿显示数值变化。静音时文字仍能说明完整结果。

地图支持键盘选格和缩放，背包支持先选物件再选落点，岗位支持键盘比较候选。减弱动效改用逐行描边，低配模式静态显示地块和守将。小窗保留年龄、潜力、寿命、等待时间和确认后果。用灰度、静音、长姓名与低特效走完“培养结束→等待→任职→延寿→再次培养卸任→地图接防”验收。
