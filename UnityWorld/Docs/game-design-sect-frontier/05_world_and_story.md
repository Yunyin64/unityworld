# 世界与玩家身份

仙道昌盛，天下仍在发展。玩家扮演宗门意志，先注视一名角色建立宗门，再持续安排弟子的培养、后方任职、领地经营与天下争夺。

| 层次 | 玩家体验 | 叙事需要提供的信息 |
| --- | --- | --- |
| 修身 | 为每名弟子选行动、事件和卡牌构筑，走完一个境界的培养 | 人物的年龄、资质、选择与实际战果 |
| 齐家 | 把结束培养的人安排到后方岗位，利用能力、性格和关系 | 谁适合什么工作，与谁协作更顺畅 |
| 治国 | 经营多格领地、建设和科技，收藏功法，发展影响力与人口 | 地块归属、资源去向、研究成果与招徒候选变化 |
| 平天下 | 为高投入玩家提供长期 SLG 争夺，组织进攻与接防 | 前线、核心城池、奇观的战略价值和控制状态 |

培养到潜力耗尽的人仍有自己的寿命，等待结束后可以在合适岗位服务宗门。练气角色到 60 岁失去筑基潜力，基础寿命为 300 岁，可在山门承担后勤。延寿能延长其在世时间。突破到化神的角色也继续参与宗门发展。

后方岗位和经营按战略回合结算，培养修炼按角色经历的游戏年结算。功法和科技效果在入段时锁定，培养结果到可用（ready）时才用于宗门。人口与影响力扩大候选样本量，增加发现高资质人物的机会。

事件只提供选择与后果。弟子性格和关系以人物信息、岗位预览与简短结果展示。一次调任、一项科技完成、一位守将到位，都会形成可回看的经营记录。

例如一名弟子未能筑基，结果锁定并完成现实等待后，玩家根据他的管理能力任命为执事。另一名筑基弟子到矿地驻守，新增资源投入功法整理与培养。地图、名册和资源记录共同呈现宗门发展的过程。
