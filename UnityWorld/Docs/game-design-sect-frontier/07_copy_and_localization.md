# 文案与本地化

**暂定标题** 《山门一脉》。

**一句介绍** 作为宗门意志，从一名修士起家，养成弟子、经营宗门、扩展领地，争取天下要地。

**商店短文案草案** 仙道昌盛，天下仍在发展。选择弟子的事件与卡牌构筑，安排结束培养的人任职，建设领地、研究科技、收藏功法，再组织金丹与元婴争夺核心城池和奇观。

**商店长文案草案** 修身，为每名弟子走完一个境界的培养。齐家，根据能力、性格和关系安排后方岗位。治国，用资源建设、科技和功法收藏扩大培养能力，让影响力与人口扩大候选来源，增加发现高资质人物的机会。平天下，为愿意投入更多精力的玩家提供持续的 SLG 攻守。弟子潜力耗尽后仍可承担宗门工作，延寿道具能让合适的人在岗更久。

| 用词 | 含义 |
| --- | --- |
| 未培养（untrained） | 新招人物先进行首段培养，结果到可用后才能承担宗门人力 |
| 一段培养 | 当前境界内的培养过程，突破或潜力耗尽时结束 |
| 突破潜力线 | 到达对应年龄后无法继续突破该境界，按该段规则结束培养 |
| 寿命上限 | 人物可在世的年龄上限，可使用延寿物品增加 |
| 结果锁定、等待、可用（ready） | 等待期间显示结果，到可用时一次性应用到宗门并开放人物用途 |
| 修士战（同龄试剑） | 每四年的同龄对局，前期固定 NPC，后续按提案开放玩家快照 |
| 任职、驻守、镇守 | 后方岗位工作、普通领地在岗、核心目标在岗分别使用对应词语；僵持窗口内的临时占据可获取实际收益，战役结算时撤销，正式地权按战役条件判定 |
| 修身、齐家、治国、平天下 | 个人培养、后方人物经营、多格经营、SLG 争霸的界面层级 |

姓名、地名、年龄、潜力、寿命、等待时间与岗位输出使用带名占位符，整句读取。时间显示明确区分角色经历年数与现实小时。人物状态和操作后果完整可读。多语言试排使用约 1.5 倍中文文字宽度（initial），检查状态标、岗位比较、等待说明和按钮。
