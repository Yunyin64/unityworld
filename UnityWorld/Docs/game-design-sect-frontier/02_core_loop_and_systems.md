# 培养、等待、任职与领地经营

玩家扮演宗门意志，人物有独立身份、年龄、能力、境界、潜力与寿命。宗门持续经营，可以同时有正在培养、等待到岗、后方任职和前线驻守的人物。所有用人操作都读取同一人物状态。

## 一名弟子的完整流程

| 状态 | 可以做什么 | 怎样进入下一状态 |
|---|---|---|
| untrained，尚未完成培养的新人 | 查看起手、资质、预定资源和本段规则，开启练气段；尚不参与岗位和地图事务 | 入段确认后进入 cultivating |
| cultivating，培养中 | 选择本段事件、行动和构筑，完成妖兽、模板或同龄修士战 | 突破或潜力耗尽后锁定结果 |
| pending，等待中 | 查看本段战报、结果与可用倒计时 | 到 ready_at 自动成为 ready；符合本段免等资格则时长为零 |
| ready，可用 | 后方任职、按境界移动驻守或领战；有下一段资格时可再开启培养 | 进入下一段培养前结束当前岗位并安排接任 |
| deceased，死亡 | 查看宗谱记录 | 只有实际寿命耗尽等明确死亡规则才产生，潜力耗尽正常回到可用流程 |

这里的可用状态包括闲置和任职，岗位另记。人物处于培养或等待状态时，岗位、产出、驻防与地图命令均不可用。培养完成取得的新牌、新境界和本段角色奖励随这份结果一起等待，到时提交为宗门侧可用成果。

例如练气弟子从十六岁养到二十四岁，筑基成功后锁定结果，常规等待八小时。到时既可以任职、去占地，也可以选他开始筑基段。该人物的练气段已经结束，下一段重新选择资源和行动路线。

已经筑基的守将在继续培养前先卸任。若原地无人接防，普通地按空岗规则释放。培养期间没有可以继续守地的旧版本角色。退出培养界面保存当段进度，回来继续同一段；重播战报和重复结算复用原记录。

## 培养段与截止条件

一次培养只覆盖一个大境界。段开始时记录人物当前实际年龄、境界、资质、功法、入段资源和规则版本，入段结束后再决定下一段安排。创派者与初始弟子的早期培养按固定事件和高资质配置推进，默认十六岁到二十四岁完成练气段。二十四岁是成长结果，实际突破按修为判断。

本段的每次行动推进角色自己的游戏年龄。普通修炼、探索和历练分别给修为、牌和材料，构筑决定自动战斗表现。首徒和早期半固定弟子每年的基础修炼包含穿插事件，顺利修炼时以每年八修为试算。功法点决定节点，阶段修为决定冲关，两者分别记录。

修士战在本段年龄跨过四年节点时触发，前期二十岁和二十四岁使用对应固定 NPC，其余前期节点按年龄、境界路由到固定模板。后期快照开放条件另配，前期模板是正常对手来源。对战锁定双方阵容与规则版本。战败结算把战斗产生的伤口卡带回当前培养弟子的卡组，战报列出留下的伤口。同一场战斗只结算一次。调整背包后，仍须面对卡组里的伤势。

弟子可以带伤继续修炼或迎战，伤口会妨碍修行并削弱战斗力。选择「疗伤」能处理伤口，这个行动消耗本段培养时间，年龄照常增长。比如弟子二十岁试剑受伤，下一步先疗伤，就会推迟原本安排的修炼。疗伤耗时、能处理哪些伤口和修为受影响的幅度留待试算。

**先检查本段潜力截止，再处理到龄战和冲关。** 练气要求实际年龄小于六十岁才有筑基机会。角色在五十九岁达标可突破；行动使他达到六十岁且仍在练气，就以 potential_exhausted 结束，不再借该年龄节点补一次冲关或同龄战奖励。其他境界的潜力线按配置，具体年龄是初调。

成功突破以 breakthrough 结束该段，角色在结果里升入下一境界，获得下一段资格。潜力耗尽时境界保留，关闭这次晋阶机会，个人已获得的战斗构筑与后方专长保留。延寿只增加寿命，不能重新打开已关闭的潜力。潜力耗尽的同一境界段不能重开刷奖励。

元婴段成功突破化神仍按同一结算、等待、可用流程处理。化神角色可以继续经营和任职，化神后的培养内容另行设计。后方工作与自然变老不自动触发每四年一次的培养模式修士战。

## 潜力与寿命

练气基础寿命为三百岁，延寿道具叠加到实际寿命上限。高境界基础寿命另配，突破后的新上限保留此前已经生效的延寿量。身份、资质和潜力状态不会因为延寿道具自动改写。

例如一个六十岁、潜力耗尽的练气修士，仍有二百四十年基础余寿。使用增加三十年寿命的道具后，上限为三百三十岁。管理专长好、合作关系稳定的人员可以持续消耗延寿资源留任。每次用药扣除真实库存并记录，重复提交同一操作只生效一次。

培养开始前展示当前年龄、潜力截止、寿命上限和本段目标。角色已经达到本段潜力截止时，关闭该段培养入口，继续使用现有身份任职。经营期临近实际寿限时给出提示，玩家可投入延寿资源。潜力耗尽、等待完成和寿命耗尽使用不同结果和文案。

## 三种时间

培养时间只影响正在操作的这一段。每完成一次代表一年的行动，就更新该角色段内年龄。其他人的年龄和全图战线不会因这次点击一起推进。

现实等待按以下公式确定，全部数值记录到同一次结果中。

- 培养年数 = 本段结束年龄 − 本段开始年龄。
- 常规等待小时 = 培养年数 × 每年对应现实小时，首测倍率为一。
- ready_at = 服务端确认本段结算的时间 + 锁定的等待时长。
- 本段免等待资格成立时，等待时长为零，仍执行相同的结果提交过程。

例如十六至二十四岁对应八小时，二十四至四十二岁对应十八小时，十六至六十岁潜力耗尽对应四十四小时。后续阶段只计算自己这一段，较早的培养年份已经结算。等待从提交时开始，反复退出、回看、登录与更改客户端时钟均不重置它。

各角色等待并行。培养与等待期间用段内年龄，等待本身不重复增加培养年数。到 ready_at 即逻辑恢复可用，经营侧自然老化从该时刻开始计算，即使玩家离线稍后打开界面也是如此。首测经营老化先用现实二十四小时对应一游戏年，按经过时间累计余量，避免重进重复计龄。这个倍率属于待调参数。

战略回合负责地图移动、岗位收益、建设、科研和攻守结算。回合现实长度另配，角色一段培养的游戏年数不能当成已经过去的战略回合。驻守和收益从真正可用并任命生效的时点开始，离线到时的角色不会倒补未曾任职的产出。

## 前期免等待政策草案

用户已要求现实开服时间、金丹出现和最多人数共同决定。先把三类条件独立配置，具体阈值和统计口径留待平衡推演。

| 条件 | 判定需要什么 | 仍需确定什么 |
|---|---|---|
| 开服窗口 | 当前服务端时间减所在服的开服时间 | 窗口持续多少小时，晚进入者是否另有方案 |
| 金丹进程 | 指定范围内的金丹出现记录 | 看本宗、全服或复合进度，出现多少名时关闭 |
| 人数预算 | 指定范围内已占额度的不同人物 ID，包含正在培养的保留额度 | 人数上限、额度归属范围 |
| 适用培养段 | 此段开始时的境界 | 初调只考虑练气与筑基段，范围仍可调 |

暂拟入段时三类条件同时满足，才为本段锁定免等待资格、政策版本和人物额度。额度原子占用，避免同时开几个人超过人数上限。同一个人在额度里开启下一段时，可沿用这个人物占用的人数，但仍需重新检查开服窗口、金丹进程和适用境界。中途关窗或出现金丹不追扣已锁定段的等待，下一段按新的条件判定。

例如测试夹具设窗口七十二小时、额度七人、金丹进程看本宗。窗口内本宗尚未出金丹、还剩一人额度时，两名新人同时入段，最多一名锁定免等。这个例子只检验复合条件和并发，正式方案没有把七十二小时、七人或本宗范围定下来。初始人物有六名偏固定弟子的配置，也不能据此推导免等额度必为六或七。

## 齐家的人物经营

可用角色可以担任执事、研究人员、药圃管理者、藏经整理者，也可以作为地图守将。每人只有一个持续岗位，岗位能力、性格偏好和相关合作关系在任命前展示。潜力耗尽者与突破成功者都可参与后方工作，具体岗位按能力要求选人。

人物在培养事件中形成专长和偏好，后方任用继续积累贡献与关系。关系只记录实际发生互动的人，简短事件提供换岗、协调、资源分配等选项。后果是岗位产出、研究速度或合作状态的变化，玩家能追溯造成变化的人员安排。

例如一名练气弟子有较高管理能力，与药圃负责人合作融洽，可以负责山门后勤。另一人研究能力高，适合整理新功法。让研究人员继续冲关，会空出研究岗位且经历培养和等待，玩家需要估算何时值得调走他。练气人员的后方工作局限所在格，外地岗位仍须由能移动的人到位。

后方结算采用岗位基础产出、人物能力与关系修正。数值首测见 03，界面同时列出基础项和具体修正，避免只显示一个无法解释的总分。培养中的战斗构筑用于未来作战，后方专长用于宗门经营，两类成果都在结算页展示。

## 治国的经营循环

领地提供基础资源与建设位置，驻守者负责维持归属。建设、科研和功法整理各占用真实资源与工作进度，按战略回合推进。人物和资源的安排会改变下一批培养条件。

| 系统 | 玩家投入什么 | 实际改变什么 |
|---|---|---|
| 地块建设 | 已占领地、灵石、工程与岗位人手 | 资源产量、储备或后勤能力 |
| 宗门科技 | 研究人员、灵石与研究进度 | 产能、资源效率、培养支持、军务供给等具体节点 |
| 功法收藏 | 探索、争夺、研究取得的功法，整理人员与进度 | 可选培养路线、修炼节点、能使用的卡牌与战力上限 |
| 影响力 | 已控制区域、稳定经营、对外关系和行动成果 | 可接触人口、招募范围与候选量 |
| 人口 | 影响范围内可接触的人群与招募安排 | 更多候选样本，让高资质个体更容易被发现 |

例如首个资源科技节点可用二十灵石和二十研究进度升一级，让对应地块基础产出提高百分之二十。两点基础产出变为二点四，资源账保留小数或定点数，显示取整不能损失累计收益。此为初调样例。

取得新功法后先整理解析，达到门槛再开放相关培养选项。入段时锁定当时可用的科技、功法版本及资源投入，已在进行的培养和等待结果沿用原输入。下一段可使用新成果。实际获得哪些牌和节点仍取决于该段行动。

扩大人口池提高发现人才的机会。若一名候选成为高资质的概率是百分之一，查看十名时至少有一名高资质的概率约百分之九点五六，查看一百名时约百分之六十三点四。每个候选的资质生成规则相同，人口扩大的是选择数量。候选批次按招募周期和种子保存，反复打开界面沿用同一批。

建设培养条件、发现人才、培养并等待到岗、获得更多经营与军事实力，再扩展领地和人口，形成长期循环。人口、科技节点和影响力的正式增长曲线留待首轮经营模拟调整。

## 地块与战争权限

开宗只建立中央山门。原型出生位置要有六个可开拓邻格，这六格持有人为空，宗门收益为零。筑基及以上人物完成培养、达到可用时间并走到目标后，才可登记驻守。一个人只守一格，山门加外圈六格要有七名不同的合格人员。

| 地块状态 | 归属与收益 | 改变条件 |
|---|---|---|
| 山门 | 本宗固定所在地与基础收入，空岗仍能维持招徒 | 合格同门到位接守，初版山门保留保护 |
| 无主普通地 | 无宗门产出 | 从本门连通边界派可用筑基及以上到位占领 |
| 正式普通领地 | 合格人物驻守时产生资源，可继续向外扩展 | 换防无缝衔接；撤人、进修或死亡导致无人接防时回到无主并停产 |
| 地权僵持 | 保留原所有权，单独记录临时占据者和临时收益 | 同境金丹或元婴领地战开始后进入僵持，持续到本次攻守结算 |
| 核心城池与奇观 | 合格修士接防后取得正式镇守资格 | 攻方元婴取胜，守方金丹未击败攻方金丹，且有元婴及以上到位接防 |

练气仍在本格活动。筑基邻格移动暂用两个战略回合，金丹和元婴一回合一格。途中保留真实位置和进度，到达前不能靠目标格产出。元婴与更高境界继承金丹领战能力。

**大境界绝对压制。** 双方是修士时，仅同大境界进入牌组战斗。若必须裁定跨境遇敌的结果，高境界直接胜出。例如筑基遇练气直接判筑基胜，练气的构筑与筑基的伤势都不改变这一结果。同一大境界内再比较构筑、伤势和战斗表现。这个规则也用于领地争夺和临时占据中的交战判定。战斗胜负和占地资格分别检查，例如筑基能压制练气，有主地的正式宣战仍要求金丹及以上。

有主普通地由金丹及以上领战。每次进攻需从相邻己方连通位置出发，支付实际进场成本，取得胜利并接防才易主。同回合多人争同地，按战区规则选一组进场，其余申请退还预留成本。参战者锁定到本次争夺结束，守方离线使用锁定阵容。等待中的人物无法出战、临时占据或接防。

### 现实耗时与临时占据

同境金丹或元婴领地战开打后，将战斗耗时折算到现实时间，地权进入僵持。战报生成后，仍要到实际结算时间才能结束僵持。关掉界面、跳过战报或重看都沿用同一结算时间。折算比例与最短窗口待试算。

僵持期间，比主战修士境界低且具备移动与占地资格的弟子，可以到场争夺临时控制。同一地块同一时刻只有一方临时占据。临时占据者可以利用此地取得窗口内的资源或战术位置。正式归属继续保留，核心镇守与正式持守贡献仍查正式地权。临时收益按实际控制时段记账，同一段产出只记一次，具体产量与可用的战术权限待定。

战役结算时结束临时占据，按主战结果和接防资格裁定地权。攻方败、战平或无人接防时，地块交还原主。此前已取得的临时收益保留。例如派较弱的金丹拖住对方强者，再调强筑基到矿上争取临时占据。哪怕我方金丹最终落败，强筑基也可以在窗口内替宗门取得一笔矿产。

### 核心城池与奇观的两条战线

核心争夺同时检查元婴主战与金丹战线。攻方需要赢下元婴战。守方有金丹助守时，攻方也要派金丹应战，两场都完成结算后，守方金丹未取胜才允许攻方接防。正式占领需要元婴及以上到位接防。

如果攻方元婴胜、守方金丹也胜，守方金丹凭大阵挡住攻方元婴，守方元婴虽败仍可留在原据点。大阵在这里决定能否入城和换防，双方分别在自己的境界交战。暂按金丹战已结算的平局视为守方未取胜，金丹战尚在进行时继续僵持。守方无金丹助守时，按元婴战果和接防条件裁定。

## 平天下与长期竞争

平天下提供高投入玩家参与的战区与联盟目标。金丹承担出征与机动，元婴承担核心城池、奇观的镇守，资源供给、前线轮换、盟友协同与可用人员的到岗时间共同影响战局。战争准备要把正在培养与等待的人排除在当下兵力之外。

战区按独立真实结算周期记录控制与贡献，具体赛季长度、积分和胜利条件待定。重复战报和培养年数不能生成额外持守分。争夺目标、参战安排与日常宗门经营可以并行，玩家选择参与程度。

AI 宗门按相同接口招募、培养、等待、任职、建造和作战，使用相同的复合免等政策。地图中立势力可以使用预置守军模板，人物状态和可接管资格仍由统一规则验证。
