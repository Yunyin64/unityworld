# 验收与试玩

这份用例用于原型和后续版本验收，尚待实测。玩家以宗门意志持续经营，注视角色建宗，再通过培养、后方人物任职、领土科技人口经营和高阶修士竞争推进修身、齐家、治国、平天下。先验培养段的结果与交付，再验人物能怎样参与宗门。

新招弟子先处于 untrained，仅可开启首段培养。随后按“培养中 → 结果等待 → 可用”转换，同一人物贯穿各状态。等待系数为每个培养年龄差对应一现实小时，成功与潜力耗尽均适用。免等采用复合条件提案，开服现实时间窗口、金丹进程门槛与不同人物人数预算须同时允许。正式阈值、金丹检测范围及人数预算范围仍待定，验收须保存测试配置与入段判定。其余首调数值标为 `initial`。

## 先跑通人物交付

用新档分别走真人和 AI 开局，记录匿名人物 ID、分段 ID、培养开始龄、结束龄、潜力状态、寿命、服务器提交时刻、可用时刻和岗位。固定种子复现同一开局，再换种子检查名字、外观与初期偏固定成长范围。计时可用受控服务器时钟做边界验证，并留一次跨真实断线恢复的记录。

| 环节 | 怎么测 | 通过条件 |
|---|---|---|
| 自修与固定事件 | 从 16 岁开始取得功法，自修、采药、遇兽，打 20、24 岁固定 NPC 修士战 | 事件与胜负可复现，正常早期培养在 24 岁达到 64 修为，提交成功结果后进入锁定的等待处理 |
| 等待与首次建宗 | 普通配置中观察 8 小时等待，再切到明确标记的复合条件免等测试档；两种路径都重复提交 | 按各自入段规则计算到时。人物实际可用后才能担任山门岗位；开宗奖励和库房只结算一次，状态和倒计时说明一致 |
| 初始班底与占地 | 用普通招徒按钮招出初期弟子，从 16 岁培养、结束等待，再派往无主邻格 | 到任前该地给本宗收入为 0。实际可用的额外筑基到达并驻守后才开始产出；原人物在名册、岗位和收益记录中一一对应 |
| 潜力耗尽与后方任职 | 把一名练气角色培养到 60 岁潜力耗尽，正常等待 44 小时后安排山门后勤 | 角色仍存活，练气突破窗口已关闭，能承担匹配当前能力的后方工作。境界、移动和占地资格继续受原规则约束 |

## 关键规则逐条验

| 编号 | 准备与操作 | 观察结果 |
|---|---|---|
| P01 | 首徒和初始班底从 16 岁自修探索。先尝试将新招弟子直接任职、出征或产出，再开启首段，分别让 20 岁、24 岁固定 NPC 战获胜或战败。补测 23 岁使用 8 份辅材 | 新招弟子为 untrained，仅能开启首段，不能跳过培养变为 ready 或提供岗位产出。早期年度基础修炼为 4 × 资质 2 = 8（initial），每年计一次。顺利修炼组在 20 岁有 32 点，23 岁 56 点加辅材仍不足 64，24 岁达到 64。战败组核对伤口卡是否随弟子回到培养卡组，复看战报不会重复加卡。分别尝试带伤修炼、带伤再战和疗伤，核对伤口对修行和战力的影响，并确认疗伤实际占用了可修炼的时间。突破提交后进入该段锁定的等待流程，人物身份沿用 |
| P02 | 给未开放快照的宗门放满合法真人和 AI 快照，再清空池，让初始班底及常规弟子参加修士战 | 前期始终按年龄与境界读固定 NPC。20、24 岁有对应模板和版本，池中人数不改变前期来源。玩家能从战报读出对手身份与来源 |
| P03 | 锁定模板战后更新模板；锁定快照战后让原人物换装、晋阶或任职，再重复观看战报 | 已锁定对局沿用原盘面与版本，修士战奖励在培养内只结算一次。快照对局不使原人物获得领土、岗位、人口或世界资源，当前世界身份与战报互不替代 |
| P04 | 为寿命 300 岁的练气角色准备 59 岁达标、恰到 60 岁达标和 60 岁仍未达标三档；按实际年龄提交结果，完成等待后再用延寿道具 | 59 岁仍可筑基；60 岁起练气突破窗口关闭，两种 60 岁档均先以潜力耗尽结束培养，当岁不再进行突破或修士战领奖。人物仍在世，按本段年龄差等待，结束后可留在山门做后勤。延寿增加生命期限，练气潜力耗尽标记继续有效 |
| P05 | 按筑基、金丹、元婴各段配置，分别到达突破条件和潜力上限，并走完等待；对成功化神者尝试后续任职 | 每段只由突破或潜力耗尽结束，等待完成才可调用人物。潜力耗尽保留人物及适配职权。元婴成功达到化神后人物继续存在，按资格任职，实际死亡单独依寿命结算 |
| P06 | 对已可用的练气、筑基、金丹分别下相邻格移动命令，再把同角色置于培养中和等待中重试 | 可用练气留在本格，筑基两战略回合走一格、金丹一回合一格（initial）。培养与等待中的人物均不能行军。途中不能提前登记守将，重复命令不能跳过路径 |
| P07 | 在相同服务器时间点连续结算多个战略回合，另推进一人的培养年龄，再检查其他人的年龄。随后让服务器实际经过 24 小时，并在等待中重连 | 战略回合不统一增加人物年龄。培养中的年龄只由段内行动推进；等待期间年龄冻结，本段年龄差只入账一次；仅可用人物按独立经营时钟老化，初调为 24 现实小时折 1 游戏年 |
| P08 | 在普通无主地上分别尝试可用练气和筑基占地。再让两名合格修士同时到达 | 练气占地被拒且不扣费。筑基到达并驻守才取得正式控制，同时抵达按主案裁决，一格只有一个归属和一次产出 |
| P09 | 开宗后空放六邻格，再派六名已可用的额外筑基。占领后撤回一人，再派另一宗合格修士抵达空岗地 | 外圈初始无主、给本宗收益为 0。守满山门及原始六邻格需七个不同的可用守将。无人接防即转无主停产，后来的修士按无主地规则占领 |
| P10 | 用可用筑基尝试正式攻取有主资源地，再用高大境界与低大境界人物分别作为合法交战双方；给低境人物更强牌组。另让同境金丹、同境元婴各发起领地战，在实际战斗结束前后检查地权 | 正式争夺有主地仍须符合领战资格。跨大境界直接由高境界胜，卡组强弱不改变裁定，也不进入打牌流程。同境金丹或元婴领地战占用实际时间，过程中地块僵持、原所有权保持；战斗结束才处理临时权释放、胜负与合格接防，不能提交命令就立即易主 |
| P11 | 按实际战区或联盟争霸配置的计分周期派合格人物镇守核心，测试同周期重复提交、交接、撤守、死亡和开始培养。让其他人物在同段现实时间内推进多个培养年，再检查分数 | 持守按真实战区计分周期和有效驻守人数判定，同周期只记一次。培养年数和战报次数不增加持守分。已可用化神仍按资格接任。赛季分数与胜利门槛待定，验收采用测试配置；一场可选争霸结算后，普通宗门仍可继续培养与后方经营 |
| P12 | 将初始招募序号停在 0、5、6，分别让全宗人物实际死亡且余额不足，再靠山门收入恢复。重复提交同一招徒事务 | 山门仍按经济配置产出，余额够对应招徒费用时能再招人。招募扣费与生成人物原子提交，取消、失败和重放不多扣费或推进序号。死亡不重置初始招募记录，人物可用转换也不生成第二个人 |
| P13 | 让真人和 AI 同时尝试调用培养中、等待中、潜力耗尽及已可用人物，分别发任职、行军、占地和战争命令 | 双方受同一状态、境界和岗位规则约束。AI 没有额外免等或潜力窗口。潜力耗尽者仍按当前境界做可承担的经营事务，练气继续受单格限制 |
| P14 | 抽空合法探索池、重复奖励事件，保存后重进；再把潜力耗尽的练气人物送回同段 | 培养仍有合法修炼动作可推进到结果，已揭示结果不可刷新。该人物已结束的练气段不能重开来再领卡牌、材料或重复贡献培养收益 |
| P15 | 从库房 8 石开始，按允许的招募周期成功招满六人，再招第七人。同周期反复重开按钮并检查候选与价格 | 初始六次各收 2 石、偏固定高资质，后续收 8 石并使用随机人物池（initial）。同一按钮按实际生成序号切换，所有招徒共用经营配置的周期人数上限。培养结算与等待完成不占用新的招募序号 |
| P16 | 建两个宗门，仅一宗完成六名初始弟子筑基、等待结束并驻满原始山门六邻格；另一宗用外围其他地凑七格。之后让合格宗门失地 | 按首调门槛，只有原始第一圈全员到位的宗门永久开放快照。仍在等待的筑基不能充当守将，任意七格不能替代原始第一圈。失地后资格保留，已锁定战报不换对手 |
| P17 | 在已开放宗门匹配池放入年龄不符、境界不符、本宗、版本不兼容和一个合法快照，再移除唯一合法快照 | 有合法快照时按同龄同境匹配并排除本宗，合法池为空时才用模板兜底。每场记录来源。未开放宗门继续读固定模板 |
| P18 | 准备潜力窗口内未满 24 岁但已满足修为条件的人物，以及满 24 岁但未达标者。另让已可用人物在经营侧老化至下一段潜力截止线，再尝试入段 | 突破由潜力窗口与修为材料条件决定，24 岁只是早期标定结果，固定事件数量不额外卡住突破。新段入场以经营侧当前实际年龄核验潜力窗口，不能沿用上一段的旧年龄绕过截止线 |
| P19 | 请玩家说明持续掌管的对象。先让创派者潜力耗尽并完成等待，再观察后勤任职；另用寿命到期档观察实际死亡后的宗门操作 | 玩家能理解宗门意志持续经营。潜力耗尽者还活着并可做适配后方工作；实际死亡才入死亡记录、释放岗位。弟子、库房与经营延续，玩家可转而培养其他人 |
| P20 | 关闭免等，分别从 16 岁培养至 24 岁成功、24 至 42 岁成功、16 至 60 岁潜力耗尽，提交结果 | 等待时长严格等于本段结束龄减开始龄，再乘 1 现实小时。三个结果分别等待 8、18、44 小时；从服务端接受结果的时刻起算。界面显示本段开始龄、结束龄、结果和可用时间 |
| P21 | 结果提交后断网，在另一设备改本地时间并登录；在可用时间前后各检查一次。另令人物到时后继续离线 24 小时，再登录任职。重复发送原结果和重复领取 | 首次提交时刻与 ready_at 保持不变，离线继续计时，本地钟不能缩短等待。到 ready_at 逻辑上自动成为 ready，经营老化从该时刻开始；按初调，之后离线 24 小时已长 1 岁。点击领取不延后老化，重放不重启等待或复制人物。岗位以实际任命时刻生效，到时后未任职的离线时段不能追补岗位或领地收益 |
| P22 | 使用显式测试夹具，开服窗口为 72 小时、不同人物预算为 7、本宗首次金丹关闭免等；三项都允许时入段，再分别令时间届满、出现本宗金丹和预算耗尽。接着改用全服进程或预算配置测试另一宗、另一服 | 夹具数值与本宗范围只用于测试，正式阈值与范围待定。三项同时成立才免等，任一不满足即正常等待。跨宗、跨服按所选检测与预算范围隔离，不能借切换界面或复制存档跨范围取得额度。入段判定记录条件与政策版本 |
| P23 | 让已任职角色开始培养，测试先交班与无人接班两种情况。培养中及结果等待中尝试任职、驻守、战争和开启下一段；到时再重试 | 入段先处理原岗位，培养与等待全程独占同一人物。原岗位按实际接班情况结算，该人物不能同时提供经营加成或攻守。只有转为可用后才能任职，突破成功者届时才可重新核验潜力窗口并开启下一段 |
| P24 | 对可用的练气潜力耗尽者使用不同类型的合法延寿道具，同一使用事务重复提交，再令库存不足并重试。检查潜力状态与实际寿命 | 每种道具按其配置增加寿命与消耗库存，不同种类可依规则续命。同一事务只扣一次、增加一次，失败不扣资源。寿命延长后人物继续活着，潜力关闭状态保持，无法重新开启耗尽的培养段 |
| P25 | 固定候选资质分布与随机源，分别提高影响力和人口，只改变对应规模变量。多轮生成招徒候选并查看单个属性 | 影响力带动人口与可供挑选的人才数量，人口增长提升候选数量。候选个体的资质仍按原分布生成，不能直接乘人口或影响力加成。大候选池可能更易挑出高资质者，应在统计中区分数量与分布变化 |
| P26 | 进入培养段时记录宗门科技、功法可用范围与版本。培养中、等待中和结果已锁定后分别升级科技或修改功法配置，再开启另一名角色的新段 | 当前培养段沿用开始时锁定的科技、功法规则版本，已锁定结果与等待时长保持。新开的段可采用新版本，升级支出与研究完成各结算一次，战报能追回本段采用的版本 |
| P27 | 在潜力仍有余地且未突破时尝试主动结束、关闭界面、保存退出和重开，之后尝试把人物派到后勤岗位 | 关闭或暂存只保留培养进度，人物仍处于培养中。系统只接受突破或潜力耗尽作为段结束结果，未达终止条件无法交付可用人物，不能提前刷出低成本工具人 |
| P28 | 将人数预算只留最后一个额度，并发让两个新人物入段。另让已占额度人物在窗口内开启后续段、重复提交，再在窗口关闭或金丹条件变化后开新段；读回已有入段快照 | 入段按不同人物原子占额，reserved 状态已计入预算，最后额度只有一个新人物拿到。同人后续段可沿用已有的人数占位，但每段都重检时间与进程条件。途中条件关闭不追扣既有段，后来新段按新判定执行。已锁存档保留原资格，重放不再占额 |
| P29 | 对核心城池与奇观分别组合元婴线、金丹线结果。先让攻方元婴赢而金丹线仍未结束，再分别让守方金丹胜、守方金丹未胜。另测攻方元婴未胜，以及满足战线条件但接防者远离或仍在等待中 | 双线尚未结算完时保持僵持与原所有权。只有攻方元婴胜、守方金丹未战胜攻方金丹、合格接防者实际到位，才易主。守方金丹获胜时，大阵阻拦攻方元婴，已落败的守方元婴仍留在守位。金丹线守方未胜按已有合法结果判断，不能额外收紧为攻方金丹必须胜 |
| P30 | 甲宗弱金丹与乙宗强金丹在乙宗资源地交战，甲宗强筑基在双方僵持时到达并临时占领。让资源结算发生在实际临时占领期间，随后让弱金丹落败，再重复提交最终战报。另用同样流程让甲宗最终获胜且有合格接防者 | 两名金丹按同境牌战耗时交手，僵持中乙宗原地权保持。甲宗筑基的临时占领记录与正式地权分别可查，期间获得实际资源收益。乙宗胜后临时权释放并恢复原有控制，后续收益不再归甲宗；甲宗胜且完成接防时按战果登记新地权。重放不会重复发临时收益或再次改旗。此例验证弱金丹争取时间、强筑基趁僵持取得收益的配合，不预设战斗时长和收益硬数值 |


## 试玩主持稿

先请玩家自己操作。主持人记录停在哪里、按了什么、以为会发生什么。卡住后给最小提示，并标记需要提示的节点。

1. **首徒档。** 告诉玩家“你以宗门意志注视这名年轻修士，带他筑基，再让他与后来者共同经营宗门”。分别记录 16 至 20 岁、20 至 24 岁的操作时间。提交结果后，请玩家读出结束原因、等待时长及何时可以安排人物。免等测试档须明确说明当前采用的复合条件、检测范围和测试参数。
2. **普通弟子交付档。** 给一个已完成 16 至 24 岁培养、还有倒计时的角色。请玩家先找一项其他宗门事务，再在可用后安排岗位。记录玩家是否把“已经筑基”直接理解为“已可派出”。
3. **潜力耗尽档。** 给寿命 300 岁、60 岁练气潜力耗尽且等待完成的人物。请玩家解释余寿与潜力，再选后勤岗位。使用一种延寿道具后，再确认角色是否能重新培养练气段。
4. **宗门经营档。** 给后方职位、可扩人口地块、科技研究和待占资源格。请玩家选择先加强哪一处，解释影响力、人口、候选数量和单人资质之间的关系。进入新培养段时查看继承的科技功法版本。
5. **高阶竞争档。** 给弱金丹和强筑基，要求利用同境金丹交战的僵持期争取资源，随后说明临时权何时结束。再给核心目标两条战线的战报，请玩家解释守方元婴落败后为什么可能仍守住城池。接着用已可用化神角色验证其继续参与宗门。
6. **复盘。** 问“等待期间你实际做了什么？”“这名没突破的人还能帮宗门做什么？”“人口多了以后，你期待候选人数还是每个人的资质改变？”记录选择与原话。

## 调优与可访问性

| 验证问题 | 指标、样本与首轮判断方式 |
|---|---|
| 玩家是否理解人物状态 | 首轮观察 10 名玩家（initial），目标至少 8 人能在未培养、培养中、等待、可用各阶段正确指出人物当前可以做什么。分别统计误点任职、误开下一段与读不懂倒计时的次数 |
| 潜力与寿命是否混淆 | 观察玩家能否解释 60 岁练气仍能活到 300 岁、延寿后仍无法重开已耗尽的练气段。记录潜力耗尽后的后勤任用率，单列实际死亡 |
| 等待是否可接受 | 按 8、18、44 小时及其他实际时长分组，记录返回查看、完成可用转换、首次任职和中途离开情况。免等与正常等待分开统计，以实际时长评估后方经营是否承接等待期间的决策 |
| 初始班底能否接上常规培养 | 分首徒、初期班底和随机弟子统计突破率、潜力耗尽率、实际等待及首次任职。免等窗口、金丹门槛与人数预算作为试验参数保留，观察从免等过渡到正常等待的理解与留存 |
| 四层玩法是否互相影响 | 用培养结果改变后方职位安排，再用后方产出支持科技、人口和领土，最后验证高阶人物争地。逐笔追踪角色与世界收益，确认快照战报没有直接复制世界产出 |
| 经济能否对上 | 逐笔核对期末余额等于期初加收入减支出。重点覆盖招徒、研究、延寿、战争和到任后产出，失败及重复提交不能多扣或多发 |
| 界面能否完整读出 | 测试桌面最低规格、窗口尺寸、键盘焦点、大字号、长地名和色觉模拟。未培养、潜力耗尽、实际死亡、培养、等待、可用分别有文字状态；等待显示时区或本地可用时刻，重连后与服务器一致 |

## 埋点与交付证据

事件及字段见同目录的 `tables/telemetry_events.csv` 与 `configs/telemetry_config.json`。人物 ID 跨培养段保持，分段 ID、段结果提交号和等待号可相互追溯。培养开始记录年龄、潜力窗口、科技功法版本及免等的条件判定、人数预占与规则版本。结果记录突破或潜力耗尽；实际死亡使用独立事件。等待同时记录计算值、免等后实际值、服务端首次提交时刻和可用时刻，重传保持事件实例键。招徒序号只在生成成功后推进，等待完成只改变原人物的可用状态。

交付一段从自修到培养结束、等待、任职或占地的记录，一套覆盖潜力边界、断线计时、版本锁定、续命和易主的存档与流水，以及按样本量列出的试玩观察。原型先修人物重复交付、状态越权、年龄重复增长和资源重入账，再根据试玩调整经营内容与复合免等参数。
