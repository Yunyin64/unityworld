# 统一卡牌系统设计

## 核心理念

**所见即所得** —— 功法、物品、行为、技能，都是一张 Card。

玩家和策划面对的只有一种实体：Card。一张卡的能力取决于它身上挂了什么实例（组件），而不是它的 Type。

---

## 架构总览

### Define 层：各领域独立，通过 CardRef 关联

各领域 Define 保持独立，各管各的专业知识。CardDefine 只负责"战斗面"。

```
┌─── 各领域 Define（各自独立）──────────────────────────────┐
│                                                           │
│  CultivationDefine "玄天剑法"                              │
│    ├── 道途、境界、修炼节点、核心效果...                     │
│    └── CardRef: "xuantian_combat_01"  ──→ 指向 CardDefine  │
│                                                           │
│  BehaviorCardDefine "探索"                                 │
│    ├── BehaviorId、OnStart、OnTick...                      │
│    └── CardRef: "explore_passive_01"  ──→ 指向 CardDefine  │
│                                                           │
│  ItemDefine "九转回春丹"（将来）                             │
│    ├── 价值、重量、丹毒、配方...                             │
│    └── CardRef: "pill_jiuzhuan_01"    ──→ 指向 CardDefine  │
│                                                           │
└───────────────────────────────────────────────────────────┘

┌─── CardDefine（只管战斗面）───────────────────────────────┐
│                                                           │
│  CardDefine "xuantian_combat_01"                          │
│  {                                                        │
│    "cooldown": 5,                                         │
│    "effectIds": ["slash_01"],                              │
│    "manaCost": { "金": 2 },                                │
│    "size": 1                                              │
│  }                                                        │
│                                                           │
│  CardDefine 就是"这张卡在战场上是什么"                      │
│                                                           │
└───────────────────────────────────────────────────────────┘
```

### 运行时：Card 持有各领域实例

```
┌─── Card 实例（运行时，有状态）────────────────────────────┐
│                                                           │
│  Card (Id=42, DisplayName="玄天剑法")                      │
│  │                                                        │
│  ├── ── 战斗面（从 CardDefine 来，所有卡都有）──            │
│  │   Cooldown=5, EffectIds=[斩击], ManaCost, Size, Tags   │
│  │                                                        │
│  └── ── 世界面（各领域实例，可选）──                        │
│      GongFa?  / ItemInstance?  / BehaviorData?   │
│                                                           │
│  Card 是个容器，里面装了什么就是什么                         │
│                                                           │
└───────────────────────────────────────────────────────────┘
```

### 持有者 + 槽位系统

```
┌─── Npc ──────────────────────────────────────────────────┐
│                                                           │
│  List<Card> AllCards          ← 统一卡池                   │
│  │                                                        │
│  ├── Card "玄天剑法"                                       │
│  │    ├── (战斗面) CD=5, Effects=[斩击]                    │
│  │    └── GongFa { CurrentPoint: 230 }           │
│  │                                                        │
│  ├── Card "九转回春丹"                                     │
│  │    ├── (战斗面) CD=10, Effects=[回血]                   │
│  │    └── ItemInstance { Value: 500, Stack: 3 }           │
│  │                                                        │
│  ├── Card "探索"                                          │
│  │    ├── (战斗面) CD=-1, Effects=[战斗结束获战利品]        │
│  │    └── BehaviorData { BehaviorId: "Explore" }          │
│  │                                                        │
│  └── Card "寒铁剑"                                        │
│       ├── (战斗面) CD=3, Effects=[劈砍]                    │
│       ├── ItemInstance { Value: 200 }                     │
│       └── ModifierData { 攻击+10 }                        │
│                                                           │
│  SlotData                     ← 槽位系统                   │
│  ├── Deck           [42, 33, ...]   战斗牌组              │
│  ├── GongFaSlots    [42, 57]        激活的功法             │
│  ├── EquipSlots     {武器: 33}      装备                  │
│  └── BehaviorSlot   88              当前行为              │
│                                                           │
└───────────────────────────────────────────────────────────┘
```

### 实例化流程

```
addCultivation("xuantian_sword")
  → 读 CultivationDefine，拿到 CardRef
  → 读 CardRef 指向的 CardDefine，填充战斗面
  → new Card { GongFa = new GongFa("xuantian_sword") }
  → npc.AllCards.Add(card)

addItem("pill_jiuzhuan")
  → 读 ItemDefine，拿到 CardRef
  → 读 CardRef 指向的 CardDefine，填充战斗面
  → new Card { ItemInstance = new ItemInstance("pill_jiuzhuan") }
  → npc.AllCards.Add(card)

所有 add 操作最终都是 add 一张卡。
```

## 双面卡设计

每张 Card 天生都有"战斗面"和"世界面"，像一张实体卡的正反面。

**战斗面 = 固有属性**，每张卡都有，哪怕很弱（CD=-1 纯被动，EffectIds 为空）。

**世界面 = 挂载的领域实例**，决定卡在世界中的身份。

```
         ┌─────────┐
         │         │
    世界面│  Card   │战斗面
    ─────│         │─────
   功法？ │         │ CD
   物品？ │         │ Effects
   行为？ │         │ Size
   增益？ │         │ ManaCost
   诅咒？ │         │
         │         │
         └─────────┘
```

策划配数据的心智模型：**各领域 Define 管世界面，CardDefine 管战斗面，通过 CardRef 连起来。**

## 组件（可选实例）列表

| 组件 | 含义 | 带来的能力 |
|------|------|-----------|
| GongFa | 功法 | 可修炼、有进度、解锁节点 |
| ItemInstance | 物品 | 可交易、可掉落、可拾取、有价值 |
| BehaviorData | 行为 | 使用时触发行为（探索/修炼/社交） |
| ModifierData | 增益/诅咒 | 给持有者挂被动效果 |
| ... | 未来扩展 | ... |

**组件决定能力**：

- 有 ItemInstance → 可以掉落、拾取、商店交易、放在背包里
- 没有 ItemInstance → 绑定在持有者身上，不能流动（如功法、天生行为）

## 槽位系统

NPC 持有一堆卡（AllCards），通过"槽位"决定哪些卡被激活/装备/上场。

**一张卡可以同时出现在多个槽里**：

```
"玄天剑法" 同时在：
  ├── GongFaSlots  ← 作为功法激活着，给被动加成
  └── Deck         ← 作为战斗卡，能打出招式

"寒铁剑" 同时在：
  ├── EquipSlots   ← 作为装备，加攻击力
  └── Deck         ← 作为战斗卡，能劈砍
```

对玩家来说：
- 学了一个功法 = 获得一张功法卡
- 激活功法 = 把功法卡放进"功法槽"
- 装备武器 = 把武器卡放进"装备槽"
- 开始修炼 = 把行为卡放进"行为槽"

全部都是"拿卡放槽"这一个操作，心智模型统一。

## Deck 与战斗

**所有 Card 天生可以上战场**，只是有些上了也没什么用。

NPC/玩家选择把哪些卡放进 Deck（战斗槽位），这本身就是决策：

| 卡 | 本职（世界层） | 战斗中的被动/效果 | 值得放进 Deck？ |
|---|---|---|---|
| 玄天剑法 | 功法，加内力 | CD=5，主动打出斩击 | 必放 |
| 九转回春丹 | 丹药，可交易 | CD=10，回复10血 | 看情况 |
| 探索 | 触发探索行为 | 被动：战斗结束获得战利品 | 贪心就放 |
| 炼体术 | 功法，加体质 | 被动：受伤-5% | 防御流可放 |
| 修炼 | 触发修炼行为 | 被动：每回合回1灵元 | 经济牌 |
| 内伤 | 负面状态 | 被动：每回合掉血，Size=2 | 不想放但赖着不走 |
| 破铜烂铁 | 垃圾物品 | CD=1，扔出去伤害1 | 垃圾牌 |

**负面卡（内伤/诅咒）= 塞进牌组的垃圾卡**，占空间拖节奏，除非治好（移除这张卡）。

## 数据归属原则

- **Card 持有所有运行时状态**（功法进度、物品数量等可变数据都在 Card 挂载的实例上）
- **Mgr 只负责逻辑**，不持有状态（Mgr 是动词，Card 是名词）
- **NPC 只持有 Card 的列表 + 槽位引用**
- **各领域 Define 独立存在**，CardDefine 只管战斗面，通过 CardRef 关联

## 现有概念的变化

| 现有概念 | 统一后归宿 |
|---------|-----------|
| CardDefine | 保留，专注于战斗面定义 |
| CultivationDefine | 保留，新增 CardRef 指向 CardDefine |
| BehaviorCardDefine | 保留，新增 CardRef 指向 CardDefine |
| ItemDefine（将来） | 新增，带 CardRef 指向 CardDefine |
| GongFa | 保留，变成 Card 上的挂载实例 |
| BehaviorCard | 变成带 BehaviorData 的 Card |
| NpcGongFaData | 由 SlotData.GongFaSlots + AllCards 查询替代 |
| NpcCardData | 由统一的 AllCards 替代 |
| NpcInventoryData | 由 AllCards 中有 ItemInstance 的卡替代 |
