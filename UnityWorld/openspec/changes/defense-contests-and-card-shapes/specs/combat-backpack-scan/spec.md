# 异形卡的扫描时机

## MODIFIED Requirements

### Requirement: 完整扫描与资源满足是发动必要条件
主动 Main SHALL 在存活且正在参战的使用者完整扫过卡牌末格时，检查满灵、冻结、本行额度、卡牌待发状态和 Main 的专属条件。末格按实际占格和扫描顺序确定。会产生拼点的发动还须有空的本方待发槽。冻结卡在末格 SHALL 跳过本次发动并解除冻结。法宝的激活到期处理 SHALL 在末格执行，独立于本次是否成功续期。

#### Scenario: 跨行卡等待最后占用行
- **WHEN** 正式卡使用 `SizeShape` 配成横跨第 1 至第 3 行的形状，资源充足但仅扫完第 2 行
- **THEN** 须等到第 3 行扫过该卡最后一个实际占格才有发动机会，并使用第 3 行的额度

#### Scenario: 资源不足不能使用
- **WHEN** Size 3 卡完整扫描时仅有两个匹配灵元
- **THEN** 保留已有点亮和行额度，继续扫描。该卡若被冻结，此次仍解除冻结

#### Scenario: 唯一候选满足全部条件
- **WHEN** 唯一候选卡完整扫描、满灵、未冻结，本行额度未用且其他发动资格满足
- **THEN** 卡按 Main 成功发动，产生的拼点进入待发槽，法宝激活或续期

#### Scenario: 冻结检查不能被早退绕过
- **WHEN** 完整扫描冻结卡时本行额度已用
- **THEN** 该卡本次跳过发动，仍解除冻结并处理到期的法宝激活
