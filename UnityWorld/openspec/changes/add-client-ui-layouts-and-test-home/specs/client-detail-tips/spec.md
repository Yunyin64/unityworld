# Spec Delta

## Purpose

让 UI 制作者分别编辑卡牌详情和状态详情的外观，并让多个页面复用同一份布局。玩家指向哪个对象，当前窗口就展示该对象的可用信息，提示跟随实际版面尺寸，避免遮挡操作或显示过期数据。

## ADDED Requirements

### Requirement: 两种详情可作为独立场景修改

客户端 SHALL 分别提供 `CardTip.tscn` 与 `BuffTip.tscn`。双击任一文件可看到由真实控件组成的完整预览并调整宽度、容器、图标区域、标题与正文。运行时使用该场景实例；各调用方共享其布局，允许按内容换行或伸高。

#### Scenario: 只改 CardTip 后验证两个入口

- **WHEN** 把 CardTip 设计宽度从 320 调到 420 像素，把卡图从标题上方移到左侧，保存后分别悬停模板卡库和战斗背包里的卡
- **THEN** 在有足够空间的窗口，两处都采用修改后的宽度与图文顺序。BuffTip 仍采用自己的设计。

### Requirement: 根据当前命中对象绑定详情

卡库、模板背包和战斗背包 SHALL 按悬停目标显示同一个 CardTip 的相应内容。目录卡展示定义信息，有实例时增加该实例真实可用的字段。战斗中可见的各条 Buff SHALL 可分别悬停，使用实际状态快照填入 BuffTip。缺失字段按界面规则隐藏或标示不可用。

#### Scenario: 悬停多格卡或同名卡

- **WHEN** 鼠标从一张多格卡的首格移到另一占用格，再指向另一张同名卡
- **THEN** 同一张卡的各占用格指向同一实例；移到另一实例时及时更新冻结、点亮、使用次数等已有数据。目录卡不显示虚构的战斗数值，空格不沿用上一张卡的详情。

#### Scenario: 同一角色有多个状态

- **WHEN** 鼠标依次悬停两个不同 Buff，随后其中一个被移除
- **THEN** 每次显示所指状态的真实名称、层数和可用的时长信息。状态消失后不残留其提示；暂停时悬停不改变层数、剩余时间或战斗 Tick。

### Requirement: 当前窗口统一显示并回收悬浮实例

每个游戏窗口 SHALL 在自己的悬浮层动态挂载这两种详情。按绑定后提示的实际尺寸和窗口可用区域定位；临近边缘时换侧或调整位置，空间不足时约束排版。展示和关闭不得抢走触发控件的点击、拖放、滚轮或焦点。

#### Scenario: 屏幕边缘与缩放

- **WHEN** 将鼠标停在窗口右下角的目标上，再调整窗口大小或移向另一目标
- **THEN** 提示在窗口内重新定位，文案可读；旧目标的提示被更新或关闭，底层命中和拖拽错误提示仍有效。

#### Scenario: 两个可见窗口分别悬停

- **WHEN** 编辑器正开着独立试战窗口，用户在各自窗口中悬停卡牌，随后关闭战斗或切换页面
- **THEN** 提示显示在触发它的窗口中，离开、移除目标或关闭页面都会清理对应实例，不在另一窗口或首页残留。
