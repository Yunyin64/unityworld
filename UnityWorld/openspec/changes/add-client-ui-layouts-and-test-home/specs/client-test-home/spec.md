# Spec Delta

## Purpose

给手动测试提供固定的 Godot 启动页，使测试人员可以在同一个窗口反复进入地图或编辑角色模板。保留开发者直接运行单个场景的入口，使调布局和自动验证都可以沿用原有流程。

## ADDED Requirements

### Requirement: 首页只提供两个同窗工具入口

普通启动和 F5 SHALL 打开可在 Godot 里编辑的测试首页，恰好显示「地图测试」和「角色模板编辑器」两个工具入口。首页空闲时 SHALL 不创建、推进地图或战斗世界。点击入口 SHALL 在原游戏窗口打开对应工具。

#### Scenario: 连续进入两项工具

- **WHEN** 测试者按 F5，点「地图测试」后返回首页，再点「角色模板编辑器」
- **THEN** 全程只有同一个可见游戏窗口，两次都出现对应的可操作工具。首页始终只有上述两个入口。

### Requirement: 工具可以安全返回首页

地图和模板工具 SHALL 提供可见的「返回首页」操作。离开地图时结束本次地图测试，释放该页持有的世界、定时器和订阅。模板有未保存修改时 SHALL 使用既有的保存、放弃、取消流程。返回成功后可再次打开任一工具。

#### Scenario: 地图行走中返回

- **WHEN** 地图已安排下一次自动续行，测试者返回首页，再次进入地图
- **THEN** 上一次的续行不在首页或新地图触发，新会话只有一个世界所有者，地图可再次选格和行走。

#### Scenario: 未保存模板返回

- **WHEN** 测试者修改模板后点击「返回首页」
- **THEN** 取消会保留当前草稿、选中项和编辑页；保存成功或明确放弃后才切换到首页，保存失败仍可修正或重试。

### Requirement: 直接启动与显式运行模式继续可用

首页 SHALL 保留地图、模板、战斗观察器从编辑器 F6 或现有命令行直接启动的能力。显式模式、案例输入、验证参数与核心烟测 SHALL 继续交给原有宿主；互斥参数继续给出诊断。

#### Scenario: 绕过首页调试

- **WHEN** 测试者分别 F6 运行三个正式场景，或运行现有带场景路径和宿主参数的命令
- **THEN** 三者各自进入可用的真实页面，不停在首页或空根节点。只传既有探索参数也能直接进入地图。

#### Scenario: 运行核心烟测

- **WHEN** 使用现有无画面核心烟测命令启动项目
- **THEN** 烟测按原约定输出结果并退出，不依赖首页按钮。
