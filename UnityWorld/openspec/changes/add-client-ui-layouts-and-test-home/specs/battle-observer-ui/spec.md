# Spec Delta

## MODIFIED Requirements

### Requirement: 观察操作清晰且可重复验证

界面 SHALL 提供可播放案例信息、播放、暂停、单步一个逻辑步、重开当前案例和结果展示，显示案例 ID、世界/战斗种子与逻辑步。重开 SHALL 说明本次动作的实际影响。独立窗口会重启该战斗窗口，当前窗口仅重开本场战斗并提供返回调用页的操作。初始化、结束或异常状态下禁用不合法操作，未适配的控制台案例不能伪装为可播放。

#### Scenario: 暂停单步
- **WHEN** 用户暂停后点击一次单步
- **THEN** 当前逻辑步准确增加一并保持暂停，背包、属性及本步记录一起更新

#### Scenario: 结果或错误后继续点击
- **WHEN** 战斗已经正常结束或发生异常
- **THEN** 播放与单步不可继续推进，用户仍可阅读记录或重开

#### Scenario: 检查两种重开提示

- **WHEN** 在独立窗口和当前窗口分别查看重开按钮，并执行重开
- **THEN** 独立窗口明确说明该战斗窗口会重启；当前窗口明确说明只重开本场战斗。实际发生的行为与提示一致，当前窗口的返回操作仍然有效。
