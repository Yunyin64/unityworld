# Design

## Context

男女角色已有 18 根骨骼、22 个插槽和同名动作。两份 Spine 4.2 JSON 是仓库里可导入的工程源。美术的原姿势拆件缺少被挡住的完整边缘，外套带有重复画进去的袖片。

## Decisions

- 把旧骨骼一一对应到人形命名，补 `Chest`、`Neck`、左右 `Clavicle` 和 `Foot`。镜头近侧是角色左侧，持武器的远侧是右侧。原有扩展骨骼仍参与动作，旧动作轨道随骨骼迁移。保留旧插槽 ID，新增分开的胫部护具插槽。
- 画稿按衣装分套。衣身、上臂、前臂、手、衣摆、护腿、鞋和披风各自画完整。图集打包只收紧独立图形的透明边缘，游戏通过基准旋转中心和绘制顺序装配。
- 缺省袖片优先使用相邻衣装的内置匹配款。明确填写的独立插槽继续优先，外部部件仍可使用各自的声明。
- 将正式骨架、可独立导入的部件图和命名说明交给后续作者。3D 动作还需要针对本项目的二维投影和实际比例调整。

## Risks / Trade-offs

骨骼名称是导入动画的接口。旧名称及新名称需要一份对照，新导出保持同一套名字。已装配外观保留原资源地址，根据版本核查识别更新后资源。
