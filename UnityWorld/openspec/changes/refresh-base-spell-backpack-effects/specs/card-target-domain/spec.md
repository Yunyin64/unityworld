# 战斗选牌范围规格增量

## ADDED Requirements

### Requirement: 流动随机下滑一张可移动敌卡

流动 SHALL 占 2 格并消耗 2 水。结算时从当前对手场上能向下滑动的卡中随机选一张，按既有滑移规则移动至障碍或边界前。主功法、定身、待发以及下方被阻挡的牌 SHALL 不参与选择。

#### Scenario: 随机选择能下滑的牌

- **WHEN** 敌方有一张被挡住的卡和两张能下滑的卡
- **THEN** 随机使两张可移动卡中的一张向下滑动并派发一次位移事件

#### Scenario: 没有卡可以下滑

- **WHEN** 对方场上没有能下滑的卡
- **THEN** 场上卡的位置保持原样
