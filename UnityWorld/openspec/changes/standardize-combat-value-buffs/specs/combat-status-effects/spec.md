# 伤害数值 Buff 与有符号层数

## ADDED Requirements

### Requirement: 数值变化 Buff 支持有符号层数

拼点、出伤和入伤数值变化 Buff SHALL 以有符号整数层数记录变化量。相同定义、同一叠层期限的实例按代数和叠加，同一实例净值为 0 时立即移除，施加 0 层无效果。首次施加和后续叠层均按配置的最大层数限制绝对值。有限时长的正负实例均按配置到期。现有五行状态及其他普通层数 Buff 继续沿用原有生命周期。

#### Scenario: 正负叠层与归零

- **WHEN** 角色先获得某一拼点变化状态的 -3 层，同一实例再获得 +1、+2 层
- **THEN** 依次可查询到 -3 层、-2 层，最后状态立即移除

#### Scenario: 对称限幅与超大输入

- **WHEN** 同一状态定义的最大层数为 99，角色获得 -120 层，或从 +90 层追加 +20 层
- **THEN** 两种情况分别得到 -99 层和 +99 层，累计不会因整数回绕改变符号

#### Scenario: 负层持续到期

- **WHEN** 角色获得持续 30 Tick 的单次刺击弱化 -2，且 30 Tick 内没有生成刺击
- **THEN** 到期前持续可查，到期后移除，后来生成的刺击无此减值

### Requirement: 伤害变化按出伤与入伤分别结算

系统 SHALL 为出伤和入伤分别提供全部、斩击、刺击、钝击、射击、金、木、水、火、土十种范围。每种方向和范围均有持续版和单次版，共 40 个定义。每一阶段 SHALL 将当次匹配的有符号层数相加，结果最低为 0。出伤在来源侧结算，入伤在目标侧结算，两者依次在护甲、坚甲、灵盾之前生效。

#### Scenario: 同一伤害匹配物理与五行

- **WHEN** 8 点火系斩击在出伤阶段同时匹配斩击出伤 +2 和火出伤 -1，目标具有火入伤 -2、护甲 1 和灵盾 3
- **THEN** 出伤为 9，入伤为 7，护甲消耗后为 6，扣 3 灵盾与 3 HP

#### Scenario: 伤害范围读取实际伤害分类

- **WHEN** 先后结算没有火属性的斩击、有火属性的刺击、没有物理类型与元素的伤害
- **THEN** 第一笔匹配斩击范围，第二笔匹配刺击和火范围，第三笔只匹配全部范围

### Requirement: 下次伤害 Buff 以匹配的正向伤害消费

持续伤害 Buff SHALL 在有效期内每次匹配时生效。下次伤害 Buff SHALL 在其阶段首次收到大于 0 的匹配伤害时应用全部层数并移除该实例。阶段入口的零伤害不触发该阶段的数值 Buff。匹配并生效后，即使伤害被减到 0 或被灵盾完全吸收，也视为已消费。

#### Scenario: 不匹配的伤害与灵盾全吸收

- **WHEN** 角色有单次火入伤 -2，先受到木伤害，再受到 3 点火伤害且灵盾足以吸收余量
- **THEN** 木伤害保留该状态，火伤害在入伤阶段降为 1 并消费该状态，灵盾吸收 1 点

#### Scenario: 出伤归零后保留入伤状态

- **WHEN** 2 点火伤害在出伤阶段被减为 0，目标仍有单次火入伤 +3
- **THEN** 本次保持 0 点伤害，目标的单次火入伤 +3 保留

#### Scenario: 旧斩击抗性兼容

- **WHEN** 旧卡「兽皮」通过旧 Buff ID 施加 1 层斩击抗性
- **THEN** 持有者对匹配的斩击伤害仍获得每层 1 点减免，使用新旧 ID 施加同一个抗性时进入同一叠层状态
