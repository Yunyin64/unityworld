## MODIFIED Requirements

### Requirement: 2D 地图辨识同格多地标

2D 地图 SHALL 先按观察规则筛出可见地标，再按 `DrawType` 选择 `Icon`、`TerrainMask`、`Shader`、`Atmosphere` 或 `None`，默认 `Icon`。图标模式沿用图片和缺图规则。区域编辑器地形图复用相同表现规则。同格图标按空间排列，数量提示只统计可感知但未显示的项目。地点详情 SHALL 可查看同格其他可感知地标名称。

#### Scenario: 选中带多个地标的地块
- **WHEN** 一个 Tile 包含一个可见主地标和两个可见附加地标，三者都为图标模式
- **THEN** 地图在空间允许时显示三项，有图项直接使用透明 PNG，缺图项用字标
- **AND** 缩小时提示剩余可感知数量，地点详情可查看两个附加地标名称

#### Scenario: 可知的无绘制地标
- **WHEN** 某地标 `DrawType` 为无绘制，`IsHide` 为关闭
- **THEN** 该地标没有地图图形及可见性替代字标，但地点详情可显示其名称

#### Scenario: 隐藏地标不泄露数量
- **WHEN** 某可见格有一个隐藏地标和一个可见附加地标
- **THEN** 地图及详情只呈现可见附加地标，数量、名称、缩略图和后备图标均无隐藏地标信息

#### Scenario: 遮罩与氛围使用所配表现
- **WHEN** 可见的地标配置地形遮罩、Shader 或氛围绘制
- **THEN** 地图采用该类型对应的表现，地点详情仍能辨认地标名称
