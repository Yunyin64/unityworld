# Spec Delta

## MODIFIED Requirements

### Requirement: 定义基础地形枚举

系统 SHALL 以稳定字符串 ID 标识可配置的同级地块类型，不再把七值枚举作为完整地块类型集合。每种定义 SHALL 具有名称、说明、显示标识、标签、环境适配条件、基础填充资格与权重、邻接条件、通行属性、移动消耗及初始五行浓度。山地、林山、荒山、火山、雪山 SHALL 能分别定义、引用和查询；共同的山类标签不改变它们的同级关系。旧枚举仅保留作显式迁移的输入。

#### Scenario: 枚举值完备
- **WHEN** 导入旧七值地形数据
- **THEN** `Plain=0`、`Hill=1`、`Mountain=2`、`RiverLake=3`、`Ocean=4`、`Desert=5`、`Forest=6` 分别映射为 `plain`、`hill`、`mountain`、`river_lake`、`ocean`、`desert`、`forest`
- **AND** 新的地块定义集合不受七类数量限制

#### Scenario: 山的变体作为同级类型
- **WHEN** 配置普通山地、林山、荒山、火山和雪山五种不同 ID 的地块
- **THEN** 每种类型能独立设置资源引用、通行、适配及元气数据，并能共同携带山类标签
- **AND** 生成器不需要把其中一种变体降为其他类型的附加标签

### Requirement: 地形与五行浓度基础对应

系统 SHALL 从最终地块类型定义读取初始五行浓度，并在生成完成前按地块独立复制；地区偏移及自然地标的一次性初始偏移随后叠加，运行时每秒速率不作为初值。旧七类的迁移默认值 SHALL 保留以下顺序为金、木、水、火、土的数值：plain=(1,1,1,1,1)，hill=(1,0.8,0.8,0.8,1.5)，mountain=(2,0.5,0.8,0.8,1.2)，river_lake=(0.8,1.2,2.5,0.5,0.8)，ocean=(0.5,0.8,4,0.3,0.5)，desert=(1,0.3,0.3,2.5,1.5)，forest=(0.8,2.5,1.2,0.5,0.8)。

#### Scenario: 获取地形基础元气
- **WHEN** 读取迁移后的 `mountain` 地块定义的基础元气
- **THEN** 得到金=2.0、木=0.5、水=0.8、火=0.8、土=1.2

#### Scenario: 同类地块元气互不共享可变数据
- **WHEN** 两个地块使用同一类型定义，随后修改其中一个地块的当前元气
- **THEN** 另一个地块及类型定义内的基础浓度保持不变

### Requirement: Tile 持有地形类型

每个对外发布的地块 SHALL 持有一个有效的地块类型 ID。基础填充模式创建的地块默认使用 `plain`；大陆生成中的未赋值状态 SHALL 仅存在于生成草稿内。未知 ID、缺失定义及不合法的旧枚举值 MUST 显式报告，不能静默替换成平原并宣告生成成功。

#### Scenario: Tile 创建后地形默认值
- **WHEN** 通过基础填充模式创建新地块且未指定其他类型
- **THEN** 地块类型 ID 为 `plain`，并且该定义存在

#### Scenario: 大陆完成后无未赋值类型
- **WHEN** 大陆生成成功并对外发布
- **THEN** 全部 40000 个地块的类型 ID 均能解析到已加载的定义

## ADDED Requirements

### Requirement: 地块填充资格和硬条件

系统 SHALL 先按填充资格、环境硬条件、邻接硬条件及水系连接约束筛选候选，再组合基础权重、环境适配权重和邻接权重。未获基础填充资格的类型 MUST NOT 用于补空隙；权重为零的候选 SHALL 不参加随机选择。没有合法正权重候选时 SHALL 报告当前位置与被拒原因，由有界生成流程重试或失败。

#### Scenario: 特殊类型仅供地区使用
- **WHEN** 火山定义禁止基础填充，某空格环境与火山匹配
- **THEN** 该空格的基础填充仍不能选择火山，但固定地区模板可以显式使用它

#### Scenario: 权重不能越过硬条件
- **WHEN** 某类型基础权重很高但不满足当前格的水系或环境硬条件
- **THEN** 该类型被排除，不能因高权重而被选中

### Requirement: 地块类型数据迁移和校验

系统 SHALL 为旧枚举、地区布局和地标落地条件提供同一份显式映射，输出迁移结果及无法转换的引用。迁移 SHALL 保留原有文件以便核对，并报告 ID 重复、引用缺失、非法数字、非有限数值及负权重；存在错误的数据 MUST NOT 进入大陆生成。类型数据 SHALL 不依赖运行时枚举顺序。

#### Scenario: 旧数字布局迁移
- **WHEN** 地区某相对坐标的旧地形值为 `2`
- **THEN** 该坐标迁移为类型 ID `mountain`，坐标和其他格子保持一致

#### Scenario: 未知旧值拒绝迁移
- **WHEN** 旧布局包含未在迁移表内的数字 `99`
- **THEN** 校验报告文件、地区及相对坐标，不将其转成任意默认类型

#### Scenario: 新增变体无需扩展枚举
- **WHEN** 新增一个具有合法唯一 ID 和完整数据的雪山变体定义
- **THEN** 地区和基础填充可以按其配置使用该类型，无需追加固定枚举成员
