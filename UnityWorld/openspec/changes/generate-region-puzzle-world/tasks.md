# Tasks

实施依据为同目录 proposal、design 和 12 个 delta specs。下列任务均为待实施；本次提案不代表已有运行结果。每组同步落地相应校验与说明，最终组只做跨模块集成验收。

## 1. 规范结构与数据模型

- [ ] 1.1 仅归一化本变更涉及的九个主能力的标题、Purpose、Requirements 结构，保留原条文正文；用 requirement/场景清单前后对比及 `openspec show <id> --type spec --json --no-scenarios` 验证可读、无丢失。
- [ ] 1.2 新增同级地块类型定义及加载器，表达标签、初值、填充资格/权重、环境与邻接条件、通行/移动消耗、水文能力；用旧七类和山类五变体夹具验证独立 ID、未知引用拒绝及初始元气深拷贝。
- [ ] 1.3 扩展 RegionDefine、LandMarkDefine 与主大陆生成配置：实际 Axial 布局、MinCount/MaxCount、固定边界、预算、环境、水系、关键地点组和独立地标初值；用非法数量、重复坐标、地标超出 footprint、NaN/负权重夹具验证严格失败。
- [ ] 1.4 编写批量审计/迁移工具，统一旧 0..6 枚举映射、地区实际占地、必出数量、地标过滤及 schema 版本；验证检查模式不写源数据、未知值有精确诊断、转换可复验且重复执行不二次转换，形成字段迁移说明。

## 2. 坐标、归属与候选世界

- [ ] 2.1 扩展 Tile 的类型 ID、来源及关联，新增 Region/RegionMgr 的实际占地与位面查询；验证按类型与按标签区别、孔洞不归属、不同位面同坐标隔离。
- [ ] 2.2 建立候选生成上下文，隔离占位、地区/地标计划、唯一性预留及诊断；注入候选失败，验证全局位面/地区/地标查询看不到草稿且计数未增长。
- [ ] 2.3 实现固定边界装载和保护，使用 Offset 配置与 Axial 相对拼图定位；验证完整 200×200 外框、奇偶行锚点、四角越界、四角重复配置及西墙全能力阻断。
- [ ] 2.4 为地图阶段建立稳定种子派生与独立 Rng，固定候选/定义遍历顺序并隔离 NewId；以打乱定义加载顺序、预先分配实体 ID 和同进程连续调用验证地理随机结果一致，并记录种子规则。

## 3. 环境底图与水系骨架

- [ ] 3.1 实现六边形连续环境采样、温湿宏观趋势和固定边界向内过渡；通过固定 seed 的环境摘要、相邻采样夹具及非法数值测试验证确定性和范围。
- [ ] 3.2 实现锚点、关键格和占地整体比例的硬条件及软适配评分；验证山谷关键格允许低海拔、软低分仍可选而硬失败不参加选择，并补配置示例。
- [ ] 3.3 实现源头到海域/明确湖泊终点的有向水系骨架，处理等高流向与洼地；用汇流、合法内陆湖、闭环及无合法出口夹具验证有终点无悬空。
- [ ] 3.4 实现地区显式局部环境修整的预算、记录与预检回滚；验证修整不触碰边界/孔洞，破坏水流方向时整块候选失败且恢复原值。

## 4. 固定地区拼装

- [ ] 4.1 实现 footprint、边界/占位、环境、间距、数量和水系接口的候选检查；验证固定朝向、完整布局、涉水端口冲突拒绝以及无水文能力地区不能阻断骨架。
- [ ] 4.2 实现包含固定地标预留的地区原子提交/撤销，地标缺引用或 singleton 冲突使整块失败；通过失败注入验证地区、类型、环境、元气计划和占位均无残留。
- [ ] 4.3 实现必需地区排序、候选选择、有界局部回退和整图重试；验证 MinCount 必须满足、MaxCount 按位面限制、无解终止且报告地区缺口和预算。
- [ ] 4.4 实现可选地区加权选择、覆盖率计算与停止规则；验证分母排除固定边界、按实际 footprint 计数、最后整块可越过软目标、目标不足仅警告。
- [ ] 4.5 制作普通山地、湿润林山、干燥荒山、涉水山谷四类验证地区及不规则/孔洞样例；逐格核对模板落地结果，更新 `Docs/世界/地图设计.txt` 的地区作者配置说明并标注样例非正式世界设定。

## 5. 基础地块补空

- [ ] 5.1 实现前沿交错填充、最少候选优先、环境/双向邻接/水文筛选和乘积权重选择；用禁止 Fill、零权重及高权重硬冲突夹具验证选择遵循配置。
- [ ] 5.2 实现候选前瞻与有界 Fill 回退，填充失败返回坐标和冲突条件；验证没有隐式平原兜底、没有改写边界/地区、预算耗尽能终止。
- [ ] 5.3 实现最终邻接审计及允许的 Fill 修整，并记录来源/修改前后值；验证成功主大陆 40000 格全有有效类型，修整前后所有固定拼图逐格相同，并补权重配置说明。

## 6. 水系连接与静态通路

- [ ] 6.1 将骨架落实为最终地块连接，验证六方向互为对侧、内部边/地区端口匹配、下游单一及合法终点；格内溪潭夹具不被误报为断流。
- [ ] 6.2 实现仅限 Fill 的有界水系修补；用必须改写主峰/边界才能接通的失败地图验证正确拒绝，合法修补后重查地势、端口及无环。
- [ ] 6.3 实现按配置移动能力和关键地点组的静态可达性检查；验证徒步不可渡河的阻断、有合法绕路的通过、有意隔绝岛屿的允许与西墙绝对阻断。
- [ ] 6.4 在地图设计文档补充跨格接口、河流终点、通行组及失败案例；用文档中同一套示例数据跑过水系与通路测试，确认无需运行角色行为或推进 Tick。

## 7. 地标、元气初值与快照

- [ ] 7.1 补齐地标占位、双向关联、引用校验、singleton 及来源清理，沿用整数实例 ID；验证固定地区地标忽略散布过滤仍完整生成，独立散布仅在无地标 Fill 格遵循过滤，地区/边界不追加随机内容，失败不部分挂载修正。
- [ ] 7.2 修复 TileModifier 实例构造的定义/来源/时长/剩余时间与速率深拷贝，校正相关说明为每秒速率；用分段 deltaTime、永久/有限时长、多来源清理验证既有更新公式保持。
- [ ] 7.3 实现地块初值＋地区一次偏向＋自然地标初值、自然快照、人工地标初值的顺序；验证每格至多一个地标、两格自然/人工对照、重试不重复叠加、查询不改写原初值、生成不 Tick。
- [ ] 7.4 将原初定位改为位面＋坐标并保留主世界单坐标查询，接入销毁/End 注销；验证两位面同坐标不同初值、独立余额、重复登记拒绝及清理不影响另一位面，并补元气初始化说明。
