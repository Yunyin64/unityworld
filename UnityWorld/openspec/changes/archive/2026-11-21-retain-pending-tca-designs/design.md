# 保留 TCA 设计

## Context

现行触发与 Lua API 已对齐。候补部署、召回、位移及部分旧触发和选择器还缺对应的战斗规则或模板接入。

## Decisions

- 三种配置共用 `Ready` 和 `Pending`。已有条目省略状态时按 `Ready` 读取。待实现条目保留现有 ID、原始文字、参数和评分权重，并记录缺口。
- Lua 广播映射只收录 `Ready` 触发。策划资料与定义管理器可查完整目录。接口参考列出触发的状态。
- 旧的对象型全选、按方向选卡和随机 CD 选择保留原 ID。现有按 Domain 全选、场上顺序邻接使用各自的 ID。
- 保留所有已接入的 Lua 兼容入口。位移和候补动作继续沿用当前的待实现行为。
