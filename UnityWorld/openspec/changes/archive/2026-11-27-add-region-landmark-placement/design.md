# Design

## Context

`LandMarkLayout` 和 `Tile.LandMarkId` 原本只描述单一地标。区域候选及地标生成分自然、原初快照、人工三个阶段。现有地标编辑器负责创建地标定义，本工具负责编排这些定义。

## Decisions

1. 保留 `LandMarkLayout` 作为每格主地标的来源，使用可选 `AdditionalLandMarks` 保存同格其余地标的相对坐标和定义 ID。配置读取、风险校验、候选提交和回退都包含两者。删除主地标时将列表下一项提升为主地标。
2. 只有区域模板生成进入地标成组放置。独立运行时 `Place`、随机散布和绝对坐标地标仍沿用原有占位判断。自然地标保持快照前阶段，人工地标保持快照后阶段。运行时保存作者顺序，继续用 `LandMarkId` 读取主地标。
3. 区域右栏提供可筛选地标库及选中格列表。可拖入或作为画笔放置。地形擦除保留未经确认的地标引用，作者可单独移除，正式保存拒绝残留的空格引用。事件页只提供预留提示。
4. 画布与 2D 探索地图标出主地标和额外数量。右栏选中格列表及探索地点详情提供其他名称。地标图共用现有 `ClientAssets` PNG 缓存。

## Migration Plan

旧 JSON 继续读取原来的 `LandMarkLayout`。只有使用同格多个地标的模板才写入附加字段。
