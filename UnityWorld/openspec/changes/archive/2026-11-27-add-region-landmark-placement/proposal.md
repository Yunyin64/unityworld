# Proposal

## Why

区域模板编辑器已有地形画布。策划需要在同一视图编排地标、管理同格地标的组合，并为之后的区域事件内容保留明确入口。

## What Changes

- 右栏增加地形、地标、事件页签。地标可以搜索、拖入已有地块、选格查看和逐个移除。事件页展示预留状态。
- 区域模板可以为同一格编排多个不同地标。旧的单地标字段继续表示主地标。
- 生成、运行时索引和 2D 探索显示完整的同格地标关系，保留唯一性、元气阶段及现有独立放置规则。

## Capabilities

### Modified Capabilities

- `region-template-editor` 增加地标和事件页签及可视化地标编辑。
- `region-system` 支持同格多个模板地标。
- `landmark-system` 支持由区域模板建立的多地标关联。
- `exploration-map-view` 显示同格额外地标。

## Impact

涉及区域定义、生成计划、运行时 Tile、编辑器和 2D 探索地点详情。事件定义和触发器沿用现状。
