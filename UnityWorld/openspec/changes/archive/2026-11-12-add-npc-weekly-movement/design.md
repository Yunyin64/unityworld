# Design

## Context

本设计按用户最新纠正重写，替代上一版独立 Movement 层。现有 Plane 持有地块和NPC，已有 Data/System 目录；NpcSystemPosition 已存在，必须承担真实位置工作。上一版完成记录不作为这次重做验收依据。

## Goals / Non-Goals

Goals：沿 World -> Plane -> Tile/NPC 的归属组织代码；复用 NPC 位置、行为、属性系统；保留随机移动和必要的只读输出。

Non-Goals：不建立策略interface、选择器类、世界参与登记、准备提交计划、局部地图服务或通用事务框架；不改战斗、Lua、地形生成或Godot。

## Decisions

### 1. Plane 使用 Data/System

规则：PlaneTileData 保存唯一地块集合，PlaneNpcData 保存唯一NPC成员集合及下一个出生序号。PlaneSystemTile 处理已有地块的通行和范围查询；PlaneSystemNpc 处理随机落点、出生及按稳定顺序遍历本位面NPC。系统是 Plane 自身的组成，不另建独立世界实体。保留原 Plane 查询、增删方法，内部委托到相应数据和系统。

数字例子：Plane 内有20个NPC就处理20个，不再登记到第二个World名单。

### 2. 位置系统维护实际归属

规则：NpcPositionData 保存已落地标记、位面、坐标和位面内稳定出生序号。NpcSystemPosition 的放置与到达入口同时维护这些字段和 Plane 成员集合。位面系统只调用这个入口，不自行改 NPC 坐标。普通Birth及临时模板不自动落地。注销及位面／世界结束时解除真实成员。

数字例子：坐标字段默认为(0,0)但未落地时不参与；成功放进Plane后才参与。失败不消耗出生序号，也不残留实体数据。

### 3. 移动归行为与位置

规则：NpcSystemBehavior.OnWeek 管理空闲决策和主行为；MoveBehavior.AdvanceWeek 累积自身进度并请求位置系统到达换格。旧秒构造保持，周行为不被秒Tick推进。候选由位置系统结合 Plane 通行返回，正速度为自身加合法六邻格，零速度只有自身。其他主行为忙碌时跳过。

数字例子：50 -> 25 -> 0 -> 25 的速度变化让进度依次50、75、75、100，最后一周到达；150的速度只完成一格。

### 4. 策略只留注释空方法

规则：在NPC行为系统留 SelectMoveTargetByStrategy 的空方法体，用注释写明未来根据NPC和合法候选填写目标；当前不填写任何值，由独立随机方法等概率选格。不定义interface、实现类、注入属性或上下文实体。未来填入目标后仍经过已有候选校验。

数字例子：空方法保持目标未指定，当前从7个候选均匀抽取；两格非法后从5个抽取。测试通过真实启动移动与受控地图验证，不用策略注入搭测试框架。

### 5. WorldMgr 统一过周

规则：WorldMgr 保存当前结算的保护状态，预检配置／周数，快照位面与其NPC，纯周历推进一次，再调用各位面系统。完成结果和通知保留，单NPC已知错误独立返回，提交后的内部故障明确标记未完整完成并禁止重试。纯周历通知仍只观察日期，完整世界读取使用完成结果。

数字例子：两个Plane分别有12和8人，一次调用仍只加1周。新年／除夕沿用既有空月相。

### 6. 属性与范围直接复用

规则：共享JSON不变，位置系统在消费边界验证定义和最终值后调用StatBlock.GetReadOnly，不保留ExplorationStats。范围查询由位置系统提供中心和半径，委托PlaneSystemTile筛选真实Tile并返回独立Tile观察副本，不复制出NPC版地图模型。只读结果不携带活动Modifier引用。

数字例子：5圈91格，6圈127格，5.9取5，0只中心，超大半径最多查询实际地块；缩放125%不改变查询范围。

## Risks / Trade-offs

- 位面成员与位置分裂：全部位置更新集中NpcSystemPosition，并验证跨位面和注销。
- 随机受历史实体ID影响：PlaneSystemNpc 内部用世界种子、位面稳定输入、位置出生序号和周序派生Rng；不另建随机管理器。
- 旧秒Tick重复移动：保留明确周模式与交错验证。
- 日历通知早于位置完成：保留时间／世界完成两种观察边界，禁止回调修改世界。
- 旧公开可写容器：继续单线程和观察只读约定，内部故障明确报告，不增加通用事务层。

## Migration Plan

先更新Plane的Data/System及位置归属，再将移动执行收回行为，最后由WorldMgr接入；移除旧包装和interface引用后更新控制台、测试与文档。复验移动、真实演示、纯周历、地图运行时和模板清理。无存档迁移，不自动归档。
