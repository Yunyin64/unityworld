# Design

## Context

地图生成第一版把 `AssetRef` 定义为可空的预留字段。2D 探索随后以 Tile ID 查询独立的图集配置，包含已有三张图集的裁切和变体。区域编辑器只尝试从 `AssetRef` 加载单图，内置定义一直省略该字段。

## Decisions

1. 内置 Tile 使用 `atlas:<条目 ID>` 引用现有图集。例如河流使用 `atlas:river`。裁切和变体坐标留在原展示映射，三张 PNG 通过现有资源链以 `terrain/<文件名>.png` 挂载。内容包也可以直接提供 `AssetRef` 对应的 PNG。
2. 共享地形读取逻辑由客户端资源缓存持有。探索继续按世界种子、位面及世界坐标选择变体。模板使用相对坐标稳定选择变体，库用主裁切。不完整的覆盖图集会尝试后续可用来源。
3. 默认显示「地形图」，画布工具栏可切换「字标」。两种模式使用同一套六边形描边、命中判定、空洞和引用标记，切换只重绘当前控件。

## Risks / Trade-offs

裸 PNG 由提供者控制构图，最终仍按六边形裁切。图集对替换图片的最小尺寸有要求，加载器记录不合格的来源。

## Migration Plan

为 26 个内置 Tile 补齐图集引用，保留省略 `AssetRef` 的旧定义和缺图回退。沿用地图配置版本和既有素材文件。
