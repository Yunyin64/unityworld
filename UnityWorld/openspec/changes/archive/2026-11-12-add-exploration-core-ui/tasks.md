# Tasks

素材、真实会话和地图输入的已完成工作见第 1～5 组。第 6 组更新已确认行程的自动／手动推进及窗口锚点，按当前操作实机验收。

依赖 `add-world-calendar` 与 `add-npc-weekly-movement` 的现有实现。属性文件 `UnityWorld/Data/Stat/NpcExplorationStat.json` 及对应规格由后端负责。若要支持玩家主动指定本格等待一周，先报告所需指令和影响。现阶段本格用于查看。

## 6. 自动／手动续行和窗口尺寸适配

- [x] 6.1 开局默认自动。第一次点格预览，第二次点击已选合法邻格才提交首周。仅为这段已确认的行程延时逐周继续，到达、失败、目标失效或进度不增加时停止；等待期间不自动再选下一格。
- [x] 6.2 可在行程中切换模式。切到手动取消待执行的自动续行，此后只由右下「继续」一次推进一周；切回自动为当前行程重新安排延时。两种模式下，途中点图都只查看。
- [x] 6.3 缩放与模式贴窗口右下，仅手动显示「继续」，移除「回到角色」。按实际视口锚定顶部标题／日期、左侧面板及右下操作组，在不同分辨率、宽高比及运行时调整窗口后核对位置、可见性和点击。
- [x] 6.4 实机对照自动两周抵达并停住、途中切手动后等待与地图点击均不续行、按「继续」只过一周。核对使用说明和 HUD 文案与实际操作相符。
