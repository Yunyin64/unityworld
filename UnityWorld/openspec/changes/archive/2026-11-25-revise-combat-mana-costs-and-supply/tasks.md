# 实现与验收任务

## 1. 第 2 项 · 基础补灵与耗尽伤口

- [x] 1.1 配置 1 格的「灵力耗尽」，指定 `Passive + Wound + Temp` 并清空卡牌自身效果，接入现有伤口入场、事件和 SP 流程。用独立战斗样例验证实际占 1 格、增加 1 SP，普通 HP 清零的随机轻伤池不会抽中该定义。
- [x] 1.2 在开场和之后的本方轮首复用实际落格、扣费逻辑，按应补量与扣费前 MP 的严格大于关系发一张伤口。验证计划 5、空格 3，MP 分别为 3、2、0 时，实际补量依次为 3、2、0，伤口张数依次为 0、1、1。
- [x] 1.3 通过实际轮次验证零计划、满盘、连续两轮不足与额外抽灵。核对开场首扫前和后续轮首的伤口入场时点，卡上余灵可继续使用，MP 归零本身不会产生伤口，SP 超限仍按既有流程判负。

- [x] 1.4 注册普通 Keyword `Temp`，验证「灵力耗尽」只有 Passive 一个 Main，另一张法术也能独立使用 Temp。验证伤口导致的 SP 超限先判负，战后清理不触发治愈。
- [x] 1.5 验证战斗中新伤入场时没有世界实例。用临时法术和「灵力耗尽」验证下一 Tick 与战末的销毁清理。用一张旧伤、两张普通新伤验证战中治愈一张旧伤和一张新伤时，正式结算仍保留旧伤并新增一张世界伤口。核对试战和重复提交。
