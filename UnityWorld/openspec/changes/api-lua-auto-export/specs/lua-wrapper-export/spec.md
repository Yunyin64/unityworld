## ADDED Requirements

### Requirement: ExportLua 按 APIType 分文件生成

APIMgr SHALL 在 Init() 完成后，将所有已注册的 API 按 APIType 分组，每组生成一个独立的 `.lua` 文件到 `Data/LuaScripts/` 目录。

#### Scenario: 正常生成所有类型
- **WHEN** APIMgr.Init() 执行完成且存在 Action/Condition/Contest 类型的 API
- **THEN** `Data/LuaScripts/` 下生成 Action.lua、Condition.lua、Contest.lua 文件，每个文件包含对应 APIType 的所有包装函数

#### Scenario: 某 APIType 无注册函数
- **WHEN** 某个 APIType（如 Aura）没有任何已注册的 [APIFunc]
- **THEN** 不生成该类型的 .lua 文件

### Requirement: Action/Contest/Aura 类型生成模板

对于 APIType 为 Action、Contest、Aura 的函数，生成的 Lua 包装函数 SHALL 按以下模式：设置所有输入参数到 ctx → 调用 API:Execute → 无返回值。

#### Scenario: 生成简单 Action 函数
- **WHEN** 存在 `[APIFunc("Heal", APIType.Action, ..., "HealValue:Int")]`
- **THEN** 生成的 Lua 为：
  ```lua
  Heal = function(ctx, HealValue)
      ctx:Set("HealValue", tonumber(HealValue))
      API:Execute("Heal", ctx)
  end
  ```

#### Scenario: 生成多参数 Contest 函数
- **WHEN** 存在 `[APIFunc("Attack", APIType.Contest, ..., "Element:String", "PhysicalType:String", "AttackValue:Int")]`
- **THEN** 生成的 Lua 为：
  ```lua
  Attack = function(ctx, Element, PhysicalType, AttackValue)
      ctx:Set("Element", Element)
      ctx:Set("PhysicalType", PhysicalType)
      ctx:Set("AttackValue", tonumber(AttackValue))
      API:Execute("Attack", ctx)
  end
  ```

### Requirement: Condition 类型生成模板

对于 APIType.Condition 的函数，生成的 Lua SHALL 剔除名为 "Result" 的参数（视为输出），并在末尾追加 `return ctx:GetObject("Result")`。

#### Scenario: 生成 Condition 函数
- **WHEN** 存在 `[APIFunc("IsFabao", APIType.Condition, ..., "Target:CombatCard", "Result:Bool")]`
- **THEN** 生成的 Lua 为：
  ```lua
  IsFabao = function(ctx, Target)
      ctx:Set("Target", Target)
      API:Execute("IsFabao", ctx)
      return ctx:GetObject("Result")
  end
  ```

### Requirement: 类型转换规则

生成的 ctx:Set 调用 SHALL 根据 ParamDef 的 Type 字段应用转换：Int/Float 类型使用 `tonumber()`，其他类型直接传值。

#### Scenario: Int 参数用 tonumber 包装
- **WHEN** ParamDef Type 为 "Int" 或 "Float"
- **THEN** 生成 `ctx:Set("Name", tonumber(Name))`

#### Scenario: String/Object 参数直接传
- **WHEN** ParamDef Type 为 "String"、"Bool"、"CombatNpc"、"CombatCard" 等
- **THEN** 生成 `ctx:Set("Name", Name)`

### Requirement: 可选参数守卫

以 `?` 前缀标记的可选参数 SHALL 生成 nil 检查守卫，仅在参数非 nil 时设置。

#### Scenario: 可选参数生成 if 守卫
- **WHEN** ParamDef 为 "?Duration:Float"
- **THEN** 生成：
  ```lua
  if Duration ~= nil then ctx:Set("Duration", tonumber(Duration)) end
  ```

### Requirement: 文件头自动生成标记

每个生成的 .lua 文件 SHALL 以注释标记开头，声明为自动生成文件。

#### Scenario: 文件头包含标记
- **WHEN** ExportLua() 生成任何 .lua 文件
- **THEN** 文件首行为 `-- AUTO-GENERATED by APIMgr.ExportLua(), DO NOT EDIT`
