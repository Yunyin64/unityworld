# Tasks

执行顺序固定：**先素材，再属性配置与只读接入，再做前端 UI，最后做一点必要检查，交给用户看。** 第一组完成前不开始写探索场景、控件或会话代码；允许先整理素材清单和展示配置。

本次真实周历、逐格移动、自动行动不做。三个红圈区域只留白。唯一已获准的核心数据新增是 `UnityWorld/Data/Stat/NpcExplorationStat.json`；其他后端改动遇到卡点先通知用户，不能自己扩大范围。代码写必要注释，改原文件的地方要说明原因。

验收例子按默认值：显示半径 5 圈最多 91 格；速度 50、邻格距离 100，对应两个静态预览阶段。不要把这些例子实现成新的行动执行器。各任务的轻检查随任务完成；最后一组只做集成，不补一套大测试。
