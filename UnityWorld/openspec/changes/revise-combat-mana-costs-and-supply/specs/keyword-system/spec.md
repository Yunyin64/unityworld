# 临时卡的战后结算

## ADDED Requirements

### Requirement: Temp 标记参战卡的临时归属

`Temp` SHALL 作为可与任一合法 Main 组合的普通 Keyword 注册。参战卡在本场按原有 Main 和其他关键词正常运转。正式战斗向世界角色提交结果时，系统 SHALL 逐实例处理临时卡：本场新增的临时卡不进入角色持有，原已持有并参战的临时卡从角色持有和对应备战记录移除。清理发生在胜负确定后。试战只使用战斗快照。

#### Scenario: 临时伤口与普通伤口同场

- **WHEN** 同一角色本场获得一张「灵力耗尽」和一张普通伤口，两者结算时均未治愈
- **THEN** 在场时各按自身体量占格、计入 SP。提交到世界时，仅保留普通伤口的一个实例，临时伤口不出现在世界持有或备战布局中

#### Scenario: 临时关键词可用于其他卡

- **WHEN** 一张带有 `FaShu + Temp` 的法术从世界角色的备战布局参战并完成正式战斗
- **THEN** 本场按法术规则发动。结算后世界持有、备战选择和占格记录均无该实例，卡牌定义仍可供其他实例使用

#### Scenario: 临时清理晚于胜负判定

- **WHEN** 「灵力耗尽」入场使角色 SP 占用超过上限并导致战败
- **THEN** 世界结算按已确定的战败结果提交。随后清理临时卡不改变本场胜负，也不计作一次战斗内治愈

#### Scenario: 试战与重复结算

- **WHEN** 在试战中获得临时卡与普通伤口，或重复提交同一份正式战斗结果
- **THEN** 试战结束后源角色的卡牌和备战布局保持开场前的状态。同一正式结果只提交一次，普通伤口不重复加入，其他卡不受重复清理影响
