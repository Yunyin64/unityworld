# 模板库外观变更

## MODIFIED Requirements

### Requirement: 展示设置与玩法模板分离

个人模板的头像、临时预览动作和 UI 状态 SHALL 作为客户端展示设置保存。供角色出生装配的逐槽相对地址与可选染色 SHALL 随标准 NPC JSON 导入和导出，省略的插槽 SHALL 保持省略。已有图片 SHALL 可复用。缺少展示素材时 SHALL 使用既有回退和可读诊断，保留草稿和原始配置，试战按原有玩法规则执行。

#### Scenario: 更换头像

- **WHEN** 用户为同一草稿更换可选头像后导出
- **THEN** 玩法 JSON 不增加贴图字段，卡牌、属性与装配结果不因头像改变

#### Scenario: 导出配置了脸型的模板

- **WHEN** 用户在草稿中指定染色脸型和原色前发、保留后发随机，导出标准 NPC JSON 后再次导入
- **THEN** 脸型和前发的相对地址及染色选择保留，后发仍按缺省规则在 NPC 出生时抽选

#### Scenario: 打开旧版个人草稿

- **WHEN** 用户打开只有旧展示外观的草稿
- **THEN** 原来由同一款式控制的前发和后发转换为两个明确的插槽配置，恢复旧款式与适用染色，保存并重开后保持选择
