# Tasks

本清单仅为新变更实施计划，当前任务均未执行。依据 proposal、design 和七份 delta specs；测试与说明随对应组落地，最后一组只负责集成验收。开发预设的密度／幅度可调，不能通过调低海平面、减少必需湖数或修改锁定拼图来绕过硬约束。

## 1. 水域数据与类型迁移

- [ ] 1.1 扩展地图候选、导出与运行时只读投影，分别表达水域类别／体归属、中心线、汇水量、宽度、自然与辅助高度；验证湖心和宽河侧格无方向仍有正确类型，深拷贝与跨位面隔离不回退，并补数据字段说明。
- [ ] 1.2 用批量脚本将 river_lake、旧枚举映射、布局、过滤、邻接和水文引用统一迁为 river，调整 ocean 的水域 Fill 资格；审计未知／冲突引用、转换幂等、原始备份及元气数值不变，更新作者工具和迁移文档。
- [ ] 1.3 在普通生成参数与严格校验中增加海平面、环境变化、湖体角色、河宽／汇水阈值、全局间隔及有限预算；用非法范围、非有限值、零／负预算和不一致端口夹具验证定位明确，确认不恢复额外世界 Define/Manager/JSON。

## 2. 连续环境与自然地形保护

- [ ] 2.1 优化按世界六边形坐标采样的多尺度环境，并让固定地区在基准和允许范围内有逐格变化；验证同配置同坐标复现、固定内部三轴非零变化、固定环境跨种子稳定和重复模板不重置纹理，补噪声参数说明。
- [ ] 2.2 用多影响连续混合替代最近单锚点过渡；建立普通边、跨地区边及模板接缝的平滑夹具，预先记录差分上限后验证通过，报告显式断崖例外，不能把所有地区边界排除。
- [ ] 2.3 将排水填洼与消歧秩移入独立辅助数据，温度依赖最终自然海拔；用真实洼地及湖盆夹具逐格验证水文计算前后自然海拔／温度不被辅助抬平，并用普通地区后置调整夹具验证跨海平面／破坏水位拒绝、局部温度同步重算，更新三种高度说明。

## 3. 海平面与水域填充资格

- [ ] 3.1 在普通拼图前按自然海拔严格小于0.05建立非固定海域掩码；验证0.049判海、0.05不强制、无活动中心线仍判海、内陆低地无隐藏连通门槛，以及固定陆地覆盖的诊断，补边界值配置说明。
- [ ] 3.2 重做水域资格与 Fill 候选结合：Ocean/Lake/River 各匹配合法正权重类型，陆地保留环境和邻接乘积权重；验证高陆地权重不能抢海域、水类型不能随机落普通陆格、零候选不兜底，并保留权重解释记录。

## 4. 三份大湖地区与湖体流路

- [ ] 4.1 扩展地区生成用途的水文阶段及湖体／出口声明，接入海域之后、河网之前的完整候选提交／回滚；用占位、海域冲突、固定地标和 singleton 夹具验证无部分岸线或来源修正残留，补模板字段说明。
- [ ] 4.2 批量制作平原大湖、狭长山间湖、湖群湿地三份可读小模板，开发预设各MinCount=MaxCount=1且湖面至少25格；逐格对照类型、岸线、岛屿、地标、孔洞和稳定相对布局，记录文件规模，不展开世界坐标列表。
- [ ] 4.3 建立湖面归属、水位和整体流路节点，实现过流湖唯一出口与显式封闭终点；验证入湖后经出口继续、封闭湖可终止、水平湖面无假环、真实悬空／闭环仍失败，更新水文连接说明。
- [ ] 4.4 将必需湖泊数量纳入阶段预算及失败诊断；用大湖无解、端口不相容、失败后重新生成夹具验证不裁切、不偷减湖数、不覆盖旧世界或快照，提供可定位缺口报告。

## 5. 汇水支流与实际河宽

- [ ] 5.1 在含海域和湖体的排水图上计算稳定方向与无环处理顺序；验证相邻对侧、合法终点、等高消歧、湖体节点及自然洼地路径，保留旧真实流路断裂／环检测测试。
- [ ] 5.2 由湿润度贡献累计汇水量并按阈值产生支流与主干，替换仅追踪四条西部水源的限制；用已知两支汇流夹具验证下游水量和单一下游，确认小支流连到主干并补阈值说明。
- [ ] 5.3 将河宽等级落实为实际river占地和中心线归属，开发预设支持1格支流、2～3格主河；验证无障碍夹具横截面宽度、转弯和汇流连续性、侧格无伪造方向边，更新河宽的格数含义。
- [ ] 5.4 接入固定内容、湖泊岸线、作者窄峡端口及普通河谷的兼容选路与有界修补；验证主峰不可覆盖、默认主河不可静默缩成1格、显式窄段有诊断且下游恢复、失败回滚无残留。

## 6. 腹地拼图间隔与密度

- [ ] 6.1 按实际footprint加入跨类型地区间隔，开发默认2格并保留同类间距；用不同类型贴边、孔洞、奇偶行、合法2格过渡带和固定条带例外夹具验证，文档明确间隔等于最短六边形距离减1。
- [ ] 6.2 改为普通可放置陆地覆盖率，分别统计海域、河带、整个湖泊地区footprint和普通拼图；用重叠扣除、河谷水格不计分子、零可用面积夹具验证分子分母正确，目标不足保持软警告。
- [ ] 6.3 将开发覆盖目标调整为25%左右并让基础地块填充地区间过渡带；以200×200来源图和批量计数验证普通拼图更稀疏、必需内容完整、四周边界无缺口，记录可调预设而非正式地理设定。
