# Design

## Context

动机与范围见 [proposal.md](proposal.md)。前置变更为 `archive/2026-11-03-generate-region-puzzle-world`；它的 41 项任务和既有验收记录保留，不把本次计划当作已实现功能。

本次已只读核查实现、数据与地图测试：

| 位置 | 当前行为与影响 |
|---|---|
| `Generation/WorldMapGenerator.cs` | 固定地区→固定地标预留→环境→水系→普通地区→补空；水类型只由活动河图判断，无法表达没有中心线的海面、湖面和宽河侧格。 |
| `Generation/WorldMapEnvironment.cs` | 固定地区跳过噪声；非固定格只取最近的一个环境锚点；priority-flood 直接抬高自然海拔，随后不重算温度。 |
| `World/WorldGenerationPresets.cs`、`WorldGenerationOptions.cs` | 默认四个水源、要求入海、湖终点为空；普通地区软覆盖目标 42%，参数已是普通对象，不恢复额外 Define 加载器。 |
| `Data/TileDefines/` | `ocean` 禁止 Fill 且权重为零；`lake` 虽允许 Fill，但水文资格挡住普通低地；`river_lake` 实际 WaterKind 为 river。 |
| `Generation/WorldMapRegions.cs` | 普通拼图必须匹配已有水系，间距只检查同类锚点；单纯添加大湖模板会被现有水文资格拒绝。 |
| `Data/RegionDefines/` | 六份固定模板内部复制一份环境常量；普通样例的局部环境调整列表均为空，继承底图，并非全部按地区刷常量。 |
| `MapGeneratorTests.cs`、`MapRuntimeTests.cs` | 已覆盖重复生成、固定保护、流向／环、湖终点、失败回滚和地标阶段；需要更新这些夹具，不能用删掉保护断言换取新水域生成。 |
| `WorldMapExport.cs`、`WorldMapPreview.cs` | 导出环境和河图但没有湖体、汇水量、河宽；默认地区轮廓增强了块状观感。 |

只读样本种子 `20261031`（v2）有 500 个非固定格自然海拔低于 5%，海域仅 2000 个固定格，湖泊为 0。该统计是定位问题的历史证据；新噪声会改变低海拔格数量，不将 500 当成新版本的黄金结果。

## Goals / Non-Goals

**Goals:**

- 让水域占地、流向图和环境浓度各自具有明确含义，所有预览与运行投影共享同一数据。
- 固定内容保护的是类型、占地与作者约束；固定环境在创世环境阶段确定为逐格变化的数据，确定后不被后续阶段改写。
- 湖泊继续由 Region 拼图表达形状和固定内容；新增阶段字段只服务生成，不为地区引入游戏运行规则。
- 用有限搜索、确定性采样和数值指标验证效果，保留现有原子发布与元气阶段。

**Non-Goals:**

- 不模拟实时天气、季节水量、蒸发、侵蚀、洪水或地下水，不改变游戏 Tick。
- 不做地图尺寸扩展、球面、客户端美术资产或角色旅行；不把 HTML 的平滑配色当作修复生成数据。
- 不复原旧导出格式为游戏存档，也不承诺新旧生成器地理结果相同。

## Decisions

### 1. 明确水域占地，与有向流路分开

在候选结果中增加水域分类 `None/Ocean/Lake/River`、稳定水体标识、河道中心线归属、汇水量及宽度信息；自然海拔仍保存在环境数据，另存排水辅助高度与水面高度。命名在实施时遵循现有 DTO，不另建全局水文 Manager。

类型资格以水域分类筛选：海域只允许 ocean，湖体只允许 lake，河带只允许 river，普通陆地不随机长出这些类型。中心线负责六方向有向连接、源头、汇流和终点；宽河侧格与大片湖面通过水体归属关联流路，不要求每个水格都有入出方向。这样既可保留现有六边形方向规则，也避免把相邻水格全部连线造成假环。

海域及河带非地区格仍标为 Fill，并记录水文选择原因；湖模板中的格仍标为 Region。`IsFixed`、`HasForcedLandmark` 与现有来源语义保留。定义的基础填充资格仍有效，海水样例改为允许水域 Fill 并给合法正权重，不能靠隐式兜底绕过坏配置。

### 2. 海平面是水域硬规则，环境权重继续用于陆地选择

使用环境阶段完成后的自然海拔，严格 `<0.05` 判定非固定格为海域；恰为 0.05 不由本规则强制判海。海域掩码先于湖泊和普通地区建立，不能再被陆地拼图或填充覆盖。固定地区已有类型优先，低于海平面的固定陆格保留并在诊断列为显式覆盖，不把强制固定规则失效处理。

遵从用户的海拔规则，不另加“必须与东海连通”的隐藏条件；因此内陆低于海平面的封闭水域也属于 ocean。大湖模板选择海域掩码以外的湖盆，允许高海拔湖泊。海域可有不规则海岸，不对源 JSON 展开世界格列表。

陆地继续使用现有硬范围筛选和环境／邻接乘积权重。水域形成不依赖把海水权重调大，海水、湖泊也不以“有无活动中心线”决定资格。

### 3. 连续环境覆盖固定地区内部

按六边形世界平面坐标采样大尺度大陆起伏、中尺度山盆和小幅细节的多层连续噪声。固定地区提供基准、允许范围、变化幅度和过渡距离；自身环境来自世界坐标，而不是每复制一份模板就从局部坐标重新开始。默认给六份固定样例非零的小幅变化，固定海域海拔限制在海平面以下。

固定地区内部采用独立、稳定的环境种子及世界坐标，使同一配置的固定逐格环境跨世界种子保持一致；腹地使用世界环境随机流。多个固定影响区用连续距离权重归一化混合，替代只选最近格。边界交接处也混合基准，只有作者明确的陡崖、长城等允许陡变，不能将所有地区边界排除出连续性验收。

湿润度由宏观趋势和连续噪声构成；温度使用纬向趋势、最终自然海拔与小幅连续扰动。物理断崖／海岸允许显式说明，不对整图做会削平地理特征的无差别平均。模板的逐格地块类型保持固定，不因噪声再次随机。

### 4. 排水辅助数据不覆盖自然地形

保留原始自然海拔；priority-flood 的填洼结果、等高消歧秩写入独立排水数组。湖面水位用于湖体连通与出口选择；温度不再建立在随后被排水偷偷修改的地形上。

流向按排水有效高度及严格递减的排水秩确定，不以“天然海拔每步必须下降”否决合法湖盆路径。自然地形、水面、辅助高度在诊断中分别展示；辅助高度不得被显示为真实山地或再次参与海平面判断。真正修改自然海拔仍只能走作者显式环境调整及原有预算／回滚。 普通地区在水域规划后申请局部调整时，预检不得跨越既定海陆阈值或破坏湖水位／排水关系；调整自然海拔须同步重算局部温度并复查环境条件。无解则整块候选拒绝，不在已接受拼图之间事后重刷海域。

### 5. 三份大湖作为提前放置的水文地区

复用地区实际 footprint、环境条件、完整提交／回滚和固定地标预留，增加生成用途的水文阶段标记及湖体／出口声明；不将“只含一个 lake 格”当作大湖。湖泊地区在海域掩码之后、流路规划之前放置，普通河谷与其他地区继续在流路确定后匹配。

开发预设提供三份小文件：开阔平原湖、狭长山间湖、湖群湿地；各 `MinCount=MaxCount=1`，选择锚点可随机，内部类型、岸线、地标与显式端口不随机。建议跨度约 10～20 格，湖面各至少 25 格；具体造型为开发样例。湖群模板以连通水道连接主湖和湾汊，湿地／岛屿按显式类型保留。

每个湖体有稳定标识和一致水位。过流湖声明唯一合法出口，由湖体这个整体节点连接入流与下游；封闭湖明确标为允许终点，不能因普通的“优先入海”设置被误判失败。三份样例至少覆盖过流与封闭两类，入流口可按作者端口连接，不能让随机河道重画岸线。仅把湖的汇流节点参与有向图校验，湖面相邻不等于方向边，避免水平湖面的假环。

必需大湖无处可放时有限回退／重试并明确报告缺失模板；不能裁掉岸线、偷偷减为两个湖或改成随机水点。

### 6. 汇水量生成支流，并在普通拼图前确定河宽

将湖体与海域作为排水图中的整体出口／终点，建立无环方向和处理顺序。每格湿润度转换为非负局部汇水贡献，沿下游累积；通过可调汇水阈值选择源头、细支流和主干，不把全部河网限制为原先四条西部水源路径。

河宽由汇水等级单调选择，开发预设先用支流 1 格、主河 2～3 格。宽度是横向占水格数；离散六边形中按稳定方向、最近中心线及排水秩裁定交叠归属，不能简单画屏幕粗线。河带须连续并与中心线连通，汇流合并水量，入湖／入海处保留正确体归属。

固定地区和湖模板先占位，生成器选择兼容流路、作者端口和可容纳宽度的位置，之后普通地区再与整条河带匹配。锁定内容阻断流路时先在预算内选择其他路径；仍无解则失败，不覆盖拼图或把配置的主河宽度静默缩成 1 格。作者明确的窄峡模板可声明合法窄段，必须单独诊断，不作为全图无约束缩宽策略。

### 7. 地区间隔与覆盖率按实际占地衡量

普通地区增加跨类型 footprint 间隔，默认建议留 2 格未归属的基础过渡带；孔洞只按实际格参与距离检查。同类 MinSpacing 保留，不能用不同类型相邻绕过全局间隔。四周强制固定条带免于该间隔，保持边界连续；河流连接、湖体与自身岸线是一个整体，不用普通间隔拆开。

普通陆地覆盖率分母为非固定格中扣除已预留海域、河带及整个湖泊地区 footprint 后的可放置陆格，分子为普通地区在这些陆格中的实际占地。水文河谷可覆盖河带，但其水格不计入该分子；三份湖泊地区面积另外统计。开发预设覆盖目标建议 25%，仍是软目标，不能豁免必需地区或放松硬条件。

### 8. 分阶段、版本和观测

候选顺序调整为：固定地区布局及固定地标预留 → 全图环境 → 海域掩码 → 必需湖泊地区 → 排水、汇水、支流与主河占地 → 普通必需／可选地区 → 受约束填充 → 水系与间隔审计 → 地标计划 → 地块元气／自然地标 → 原初快照 → 人工地标 → 原子发布。结构校验的具体调用可合并，依赖顺序不能倒置。

普通参数新增海平面、环境频段／幅度、支流阈值／河宽、跨地区间隔和水文搜索预算。继续使用 `WorldGenerationOptions` 和代码默认值；不恢复 WorldGenerationDefines JSON。新增随机流按阶段和稳定 ID 派生，遍历次序固定；生成器升为 v3，摘要包含实际参数、水体、河宽和自然／排水高度等有效语义。

HTML 直接读取新结果：单列自然海拔与排水辅助图层，展示水体分类、湖水位、中心线／河带、流量及宽度；环境图层默认关闭地区轮廓，可手动开启。选格明确说明海拔阈值判海、湖模板、河带或普通环境权重的选择原因，不另写浏览器生成逻辑。

## Risks / Trade-offs

- [低海拔海域切掉大片候选区] → 固定内容优先，早建水域掩码，必需湖／地区无解明确失败；不为成功偷偷改 5% 海平面。
- [水体与现有六方向图混用] → 分开水域成员和中心线，湖体收缩为整体节点；既有真实闭环、悬空和对侧端口测试继续保留。
- [自然高程与排水方向看似矛盾] → 分别展示辅助高度和水位，湖盆路径按有效排水数据验证，不通过抬平自然地形掩盖问题。
- [固定环境范围交接过硬] → 世界坐标采样及多影响权重过渡；显式标记允许陡变的位置，普通地区边界不作为统计豁免。
- [湖泊／河带占地让作者河谷难匹配] → 水文阶段先留接口、提供多方向模板及预算诊断；不裁切或旋转作者拼图。
- [全图每格计算距每个固定格成本过高] → 以定义／影响场和有界距离传播组织采样，不采用 40000×固定格数的全配对循环；验收记录阶段耗时。
- [密度下降后仍显得块状] → 同时检查无轮廓环境图、真实相邻梯度及来源图，区分轮廓叠加和数值不连续。

## Migration Plan

1. 保留已归档 v2 结果为历史基线；用批量检查列出所有 `river_lake` 引用、端口、邻接权重和作者工具映射，预览迁移后再统一转换为 `river`。金木水火土初始值与旧 Modifier 不变，原文件备份不参与运行时加载。
2. 扩展候选水体与环境数据，升级严格校验和参数；固定环境基准字段可保留，新增变化参数采用显式默认值，六份样例启用非零变化。
3. 实现环境／海域、三湖、河网／宽度、地区间隔和填充资格；逐阶段保持完整回滚、固定地标预留和自然／人工元气顺序。
4. 更新 Console、HTML、批量审计和配置说明；用相同 v3 seed/config/version 复现，保留 v2 对照图而不比较 v2 与 v3 的结构相等性。
5. 验收至少包含 1..20 固定种子、参考种子 20261031、独立进程与真实世界入口一致性。回退时恢复同一边界的代码、配置和版本，不把新结果交给旧结构解释。

## Open Questions

仅以下内容造型和调优项可在不改变行为契约的情况下延后：三湖的具体岸线与名称、支流阈值、普通地区覆盖率和允许范围内的噪声幅度。25%／2 格／1～3 格均为开发预设初值，不是正式世界设定；海平面 5%、三份大湖模板、河湖海分离、固定内部有环境变化属于本次明确目标。
