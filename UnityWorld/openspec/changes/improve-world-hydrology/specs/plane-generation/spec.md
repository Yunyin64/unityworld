# Spec Delta

## MODIFIED Requirements

### Requirement: PlaneGenerator 支持完整5步世界生成
位面创建 SHALL 显式选择大陆或基础填充。大陆模式先固定布局／地标预留，再生成全图环境、海域、必需湖泊、排水汇水与河带，随后普通地区、填充及审计，最后按基础元气、自然地标、快照、人工地标顺序准备并发布。缺依赖必须失败，不自动降级。基础填充继续保留小位面、手工格和空位面兼容入口。

#### Scenario: CreatePlane 调用 Generate 而非 Fill
- **WHEN** 请求创建大陆模式主位面
- **THEN** 只有完整大陆生成流程成功并发布后才返回成功位面，而非仅填充坐标即返回

#### Scenario: 无 RegionMgr 时退化为仅填充+地形
- **WHEN** 请求大陆生成，但地区管理依赖或地标管理依赖未就绪
- **THEN** 请求明确失败并报告缺失依赖，不退化为仅坐标填充、不跳过地区和快照，也不发布不完整位面

#### Scenario: 显式基础填充保持已有手工地块
- **WHEN** 请求基础填充模式，并传入有效尺寸及部分已有地块
- **THEN** 已有地块的位置、内容与当前元气保持不变，仅补齐指定范围内的缺失地块，不套用主大陆边界或地区配置
- **AND** 创建成功时为该位面单独建立初始快照，不覆盖任何其他位面的原初值

#### Scenario: 基础填充允许明确的空位面
- **WHEN** 请求基础填充模式且尺寸明确表示现有空位面语义
- **THEN** 保持该空位面语义，不强制生成 200×200 地块或绑定大陆拼图配置
