# 战斗机制速查 + 数值参考

## 拼点类卡（Attack/Shield/Block）

CD 到后进入待发槽，等对方也出卡后对拼：
- **攻击赢** → 差值伤害打对方
- **盾赢** → 差值给自己加血
- **防赢** → 差值消失（纯减伤）
- **赢家通吃**：同物理类型攻击对打 → 赢方打全额数值（不是差值！）
- 射击(SheJi)不触发赢家通吃

## 效果类卡（Heal/SelfDamage/其他）

CD 到后直接结算，不进待发槽。

## 伤势卡

战斗中 HP 清零时自动生成，塞入卡组占空间，每次 CD 到时自伤。
