# Task 1 — 意向的抽象与具象

## 目标

围绕用户给出的 Tag 主题，从修仙、玄幻、科学、日常等多元文化作品和认知中，挖掘其意象与特性，最终产出：
- 5–10 个抽象的"意象"
- 5–10 个具象的联系"物品"

## 步骤

1. **确认主题**：明确用户想要设计的 Tag 是什么（一个词或短语）。
2. **意象发散**：从以下维度联想该主题的抽象意象，由底层到上层依次思考：
   - 本质类别：它最根本是什么？
   - 物理特性：它有什么显著的物理/感官属性？
   - 行为能力：它能做什么、会怎样作用于世界？
   - 文化象征：在修仙、玄幻、科学、日常等语境中的象征意义
   
   注意：不要跳过基础本质直奔文学象征。本质类别往往是游戏机制最直接的锚点。
3. **物品具象化**：从以下维度列举与该主题关联的具体物品：
   - **直接物品**：该主题本身的具体形态或变体
   - **间接物品**：与该主题相关但不等于它本身的事物，从多个角度发散：
     - 作用于它的工具
     - 由它制成的制品
     - 它所处的场景/建筑
     - 与它共生/伴生的事物
     - 它的副产物或残留
   - **可分离物品**（仅当主题是活物或复杂个体时）：可以从该个体上获取/分离的部件
4. **筛选精炼**：从发散结果中精选最有游戏设计价值的条目，控制在目标数量范围内。

## 输出格式

思考过程（维度分析、发散联想等）仅在内部进行，**不展示给用户**。
最终呈现给用户的结果必须是简洁的列表形式，不带维度标签、不带解释、不带表格：

```
抽象意象：
- 词1、词2、词3、...

具象物品：
- 直接：物品1、物品2、物品3
- 间接：物品1、物品2、物品3
- 分离：物品1、物品2、物品3
```

注意：
- 如果主题非活物/复杂个体，省略"分离"行
- 每行只列关键词/名称，不加括号解释

## 示例

**主题：酒**

抽象意象：
- 醉、祭祀、豪迈、发酵、谷物、可燃、饮料

具象物品：
- 直接：红酒、香槟、女儿红
- 间接：酒杯、酒庄、啤酒花
- （酒非活物，无可分离项）

**主题：蛇**

抽象意象：
- 缠绕、剧毒、蜕变、阴冷、诱惑、灵活、吞噬

具象物品：
- 直接：蟒蛇、毒蛇、蛟龙
- 间接：捕蛇网、蛇蜕、雄黄
- 分离：蛇牙、蛇皮、蛇胆

## 完成条件

将结果呈现给用户后，不要询问，自动进入 Task 2。
