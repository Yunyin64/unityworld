# 现有机制列表参考
ID	DisplayName	Desc	Rarity	Size	Cooldown	CardType	ManaCost	Tags

一张卡有


- Rarity：卡牌的稀有度，越大效果越复杂
- Size：卡牌占用的SP空间，1-3，越大数值越高
- Cooldown：卡牌想要走一轮效果的时间。被动卡没有CD。对拼数值和效果一般只有对有CD的卡持有
- 对拼数值：卡牌一般可以参与对拼，代表使用来进行攻防
- 效果：卡牌使用后产生的效果。如果有对拼，就是对拼后，否则直接生效
- ManaCost：卡牌的法力值消耗，消耗后才进入CD

//卡牌类型keyword
- 法宝：有弹药上限，冷却满消耗弹药出牌，弹药归0则卡住不转
- 装备：提供招式卡进入卡组，自己有攻防属性，供其他卡调用
- 阵法：作用与敌我全场的效果
- 丹药：有消耗层数，用一次减一层，归0移除卡牌
- 法术：常规冷却循环的攻防卡牌
- 招式：装备附带的基础攻防卡，效果简单
- 功法：核心效果卡，效果强大而有特色
- 物品：物品，有价值，效果简单

//卡牌运作keyword
- 被动：不参与冷却循环.一般都是“触发后XXX”，“单纯数值变化”，不会带攻防对拼属性，也就很少会有“此卡XXXX”

- 金：五行之一，锋利、坚硬、肃杀、收敛、沉重、导电、冰冷、光泽、永恒、铸造
- 木：五行之一，生长、扎根、年轮、庇护、柔韧、腐朽、春生、沉静、通天
- 水：五行之一，流动、润泽、柔软、侵蚀、净化、寒冷、深渊、包容、循环、溶解
- 火：五行之一，燃烧、温暖、光明、毁灭、净化、爆发、蔓延、炼化、狂暴
- 土：五行之一，承载、厚重、孕育、沉稳、封埋、腐化、塑形、吞没、丰饶


- 基础八维：角色的八项基础属性，影响战斗数值、修炼速度、社交等各方面能力上限
- 体魄：肉体强度，影响HP上限、物理伤害抗性、近战基础威力
- 气血：内气充沛程度，影响MP上限、灵元转化效率、续航能力
- 气感：对灵气的感知灵敏度，影响五行亲和权重、灵元产出质量
- 灵机：灵感与反应速度，影响卡牌冷却速度、出牌优先级
- 悟性：领悟与学习能力，影响功法修炼速度、技能解锁条件
- 神识：精神力与感知范围，影响SP上限、被动触发判定、探查能力
- 魅力：外在气质与影响力，影响社交判定、NPC好感度、交易价格
- 机缘：气运与际遇，影响随机事件触发概率、掉落品质、奇遇频率


- 对拼：双方待发槽各弹出一张，比较数值决定胜负和伤害
- 对拼输赢：对拼输赢为0则平局，负数为输家，正数为赢家
- 拼点类型：斩、刺、打、射击、盾、格挡
- 斩：近战攻击，同类型对拼赢家通吃，异类型差值伤害
- 刺：穿刺攻击，同类型对拼赢家通吃，异类型差值伤害
- 打：打击攻击，同类型对拼赢家通吃，异类型差值伤害
- 射击：远程攻击，异类型差值伤害
- 盾：防御拼点，赢了将差值叠为护甲
- 格挡：防御拼点，赢了差值直接消失
- 直击：对方槽空且直击冷却就绪时，全额伤害无对拼

- HP：健康度。归零不死亡，恢复X%并塞入伤势卡
- 伤势：HP归零时塞入卡组的负面卡牌，占用SP且无正面效果，需要治疗手段移除
- MP：灵气资源。按五行亲和权重转化为灵元供卡牌消耗
- 灵元池：储存已转化灵元的容器，按五行分类存放，卡牌出牌时从中扣除对应元素的灵元
- SP：灵魂负载。所有卡体量之和，超上限即败北

- 冷却循环：等待资源→冷却中→就绪→待发→结算完毕→循环
- 充能：直接增加目标卡牌冷却进度
- 冻结：暂停目标卡牌冷却计时
- 减速：降低目标卡牌冷却速度。减速10 = 慢100%。在使用后会归零
- 加速：提高目标卡牌冷却速度。加速10 = 快100%。在使用后会归零

- 添加：向卡组加入卡牌（如伤势卡塞入）
- 移除：从卡组移除卡牌
- 位移：将卡牌移到首位/末位/随机位置
- 相邻：可查询目标卡上方/下方\所有\最上最下的卡牌

- 增益：正面Buff，如加速、充能等效果，或者如力量、敏捷等属性强化
- 异常：负面Buff，如冻结、减速等影响卡牌运转，或者如中毒、灼烧这些状态
- Buff目标：状态效果可能对敌人也可能是对自己人
- 转化：将灵元池的资源变成蓝条
- 抽取：将蓝条变成灵元池的资源
- 回复：恢复生命值，不超过上限
- 治疗：去除伤势卡
- 护盾：额外生命层，先于生命值被消耗
- 弹药：法宝类卡牌的使用次数，归0则无法出牌但仍可触发
- 数量：丹药类卡牌的消耗层数，用完直接移除卡牌
