# 随机摘取 Markdown 原文

使用本技能自带的 [scripts/extract_md_excerpt.py](scripts/extract_md_excerpt.py)，不要自行改写摘录。需要 Python 3.10+，只依赖标准库。
脚本路径相对于本 `SKILL.md` 所在目录解析，不依赖项目名称、仓库结构或当前工作目录。不要到项目的 `tools/` 目录寻找脚本。

先根据本技能的实际安装位置确定脚本绝对路径，再将用户指定的文档路径按用户当前工作目录解析为绝对路径。运行时给路径加引号，例如（将占位路径替换为实际路径）：

```powershell
python "<技能目录>/scripts/extract_md_excerpt.py" "<文档绝对路径>"
```

若环境只有 `python3`，使用 `python3`。用户未指定文档时，先从当前对话确定目标；仍有多个可能的文件时再询问。

可选参数：`--max-chars 400` 调整细分阈值，`--seed 42` 复现抽取结果，`-o "输出路径.md"` 保存 UTF-8 文件。默认只输出，不修改源文档；输出路径不能指向源文件。

向用户展示脚本标准输出中的摘录并注明源文档。标准错误流中的标题、字数是运行信息；若提示超长，简要说明实际保留了完整段落。仅在用户要求保存摘录时指定输出文件。如果字数太多，比如最后结果1000字以上，就只截取部分有意思的片段显示出来，避免浪费token。

之后用通俗的白话来解释文本意思。再用脑暴发散一个，将讲的东西，对应到游戏里面的一种小巧思、小设计（主要是卡牌、slg、
模拟、叙事类游戏）
