# 试战人形分件原画

使用内置 ImageGen 生成透明 PNG，以项目原有水墨武侠角色的比例、深色轮廓和赛璐璐明暗为风格参考。

- `jade.png`、`cinnabar.png`、`indigo.png`、`violet.png` 分别重画灰蓝白衣、朱红交领、靛蓝武服和梅紫短袍。每套包含无袖衣身、颈部、衣摆、远侧大臂、小臂、持握手、近侧大臂、小臂、张手。
- `lower-dark.png` 和 `lower-light.png` 分别绘制两套腿脚组件。上排近侧，下排远侧。每排按大腿裤、护腿、鞋排列。
- `cape.png` 包含灰蓝披风和短朱披风。每件是单独完整的布料，前端从肩部下方延伸，展示时放在躯干后。
- `torso-neck.png` 重画四套衣装的上身，接替旧衣身和颈片。提示词要求把喉颈皮肤、交领和腰封画成连续的单张插图，颈部顶端留在下巴后，远近两侧只画袖片能盖住的肩口。

## 生成提示词

四套上身的共同制作要求是独立绘制完整图形，隐藏接头也保留颜色和结构。透明画布以宽空隙放 3 × 3 个部件。第一排是无袖交领衣身、独立颈部和带腰结的分片衣摆。第二排为远侧大臂袖、对应护腕小臂、持握手。第三排为近侧大臂袖、对应护腕小臂、张开手。统一暖黑墨线和左上方柔光，近侧袖片更宽，远侧稍收暗，肩、肘和腕都有可遮住的搭接。服装配色分别使用米白与灰蓝玉饰、低饱和朱红与奶油色、靛蓝与灰紫、梅紫与旧麻布色。

腿脚的制作要求是在 3 × 2 透明素材板上分别画出裤腿、从膝到踝的护腿和独立足部便鞋。近侧略宽，远侧稍暗。两套分别用炭灰配暗青灰绑带、灰褐配米色绑带。两件披风分别绘制成从右上肩口向左下方飘动的布料，保持完整布边、内衬和衣缘，各自采用灰蓝玉白或烟红铜色。
